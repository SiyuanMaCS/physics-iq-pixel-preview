# 0197 方法与实际检查记录

## 输入与生成方式

只读取本例 first_frame.png、prompt.txt、case_config.json 和共享输出 helper。首先实际查看原首帧，并在编写生成器之前保存 OBSERVATION.md；随后又查看放大首帧 first_frame_detail.png。没有读取其他例、参考续写、旧生成器或记忆，没有联网、模型调用、学习权重、物理引擎、三维网格或法线渲染。

帧00直接保留原图的 uint8 RGB。后续背景以原摄影图为底，只在原球与其投影所在的小区域，用左右相邻完好木桌的逐行颜色、固定细微木纹恢复露出的桌面。此修补固定于桌面位置。黑管、壶铃、鸭子、沙发和其余桌面保持静止。

动态球逐帧在4倍局部二维栅格中直接计算新的 RGB 和覆盖率：近椭圆的柔轮廓、轻微轮廓不规则、灰蓝色二维色素场、随滚动相位变化的低频云斑、非对称断续淡斑和斜向浅色绒束、不规则下半部暗绒、断续弯曲浅缝及细纤维扰动。宽范围光照与表面毛斑分别计算，避免用单一中心亮区表达全部材质。每帧独立求值，不裁切、移动、缩放或镜像首帧球的贴图，也不从另一例搬用代码。接触帧横向宽度略压缩、纵向略伸长，随后恢复。球的右向软投影与下方接触阴影逐帧重绘。撞击时保留静止壶铃的可见深色轮廓作为遮挡边界。

二维像素运动安排采用重壶铃不动、小球反弹并在桌面摩擦减速的假设。球的桌面底部约 y=63，碰撞时球右缘约 x=155，与壶铃左边界相接。没有人为加入鸭子移动、壶铃倾倒或球离桌弹起。

## 实际视觉检查与修正

实际打开了首帧及其4倍放大图。首轮生成后实际打开了 transition_check.png、contact_check.png 和 inspection.png：00/01/02放大对比，以及00、01、02、03、05、08、12、19八个时点的接触局部和完整画面。inspection.png另包含00、02、05、08、11、14、17、19八个时点。

首轮查看发现新绘球较原图边缘偏清晰，投影比首帧淡。修改 generate.py，略增常态横向半径、拓宽边缘覆盖过渡并增加色素场柔化，同时增强和略延长右向软投影，之后重新保存所有输出。

修正后再次实际打开 transition_check.png 与 contact_check.png，逐项查看：

- 00保持摄影首图；01的球宽度、灰蓝色范围和接触高度与首帧接近，旧位置没有第二个球或成块残影。
- 02放大检查球的右缘与壶铃左缘接触，球底仍贴桌；壶铃仍位于原支撑点，鸭子不动。
- 03检查反弹后球与壶铃分离、圆轮廓恢复，无穿过壶铃的残块。
- 05、08检查回滚路径和接触阴影随球回移，没有浮起或多个轮廓。
- 12、19检查减速与静止，没有桌面轮廓涂抹、尺寸跳变或静止物件抖动。

检查并没有依赖像素差数量或新颜色数来判定质量。

## 仍可见的局限

返修后新球已有非对称浅斑、下部暗绒和低频云斑，但摄影首帧中逐像素的绒面分布仍不能准确重建；局部仍较平滑，轮廓比原图更规则，放大比较仍能辨认出首帧与解析重绘之间的质感差异。柔投影近似了首帧方向，但未完全复现原投影略不规则的边界。原球处露出的木桌是局部二维修补，细木纹无法从遮挡下准确恢复，放大时有轻微平滑。网球的微弱旋转接缝在256×144尺寸下不容易辨识，运动主要由滚动轨迹、接触与回弹表达。碰撞只被0.25秒采样到一次，不呈现更细的毫秒级压缩过程。没有声轨。
