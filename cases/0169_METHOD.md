# 0169 独立像素续写

## 方法和输入

仅使用本目录 first_frame.png、prompt.txt 作为场景输入；读取本目录 case_config.json 与公共保存 helper。先实际打开首帧及4倍放大，写 OBSERVATION.md 后独立写 generate.py。未读取其他案例、参考续写、旧结果、掩码、评测分数、记忆或其他线程；无联网、AI API、学习权重、物理引擎、三维场景、网格、法线或渲染器。

00逐像素保留首图，01作为0.25秒原位停顿也保留首图。02至19每帧重新计算二维轮廓内的RGB：

- 篮侧为带底缘弧线的二维覆盖区域。横织条、竖短条、交叉亮纤维及微小色差由当前位置、编织行列和确定性的细纹函数求值。顶部另画同一深棕色材料的压扁椭圆编织表面、磁铁附近暗凹区和约2像素厚的前滚边；侧壁向底部内收，底沿有柔暗和弧形卷边。并未裁取或移动原篮贴图。
- 磁铁为黑色二维弧底侧面和灰银椭圆帽；吊链由不对称、局部折弯的长环与扭斜下环逐帧重新画出，并分段添加金属亮点。篮、磁铁、链环共同上升，画框自然截掉越界部分。宽度、编织条尺度和厚度固定，无随机摇晃。
- 橙球按固定圆形边界、二维亮度函数、细绒变化与一条浅色曲线接缝求新RGB。球心始终(132,117.2)，半径10.7像素。先画球，后画篮，实现真实遮挡次序。不是根据露出程度缩放球。
- 阴影先于物体写入桌面：球接触阴影固定；篮下方阴影随高度减弱、轻微变宽。无重复对象、旧篮残影或跟着篮上升的球影。
- 静态摄影背景在可见区域保留。原遮挡区域以可见灰墙/木桌的低频二维颜色拟合修补；细木纹仅取同首帧明确可见的静态桌面残差。桌面后的直边按可见边缘推断，并以约一像素混合防止硬台阶。没有用原物体贴图合成运动。
- 在4倍二维像素网格直接写RGB后用Lanczos得到256×144。所有动态像素均来自当前帧重绘，没有镜像、物体裁块平移或缩放。

3. 实际查看 transition_check.png 中00/01/02的4倍近景及03、04、05、06、07、10、14、19全帧。首版织纹过度规则且过平，修正为有轻微弯曲、交叉纤维、每小段亮暗变化的细编织纹；00→01完全一致，02保持棕色编织篮材质与同一外轮廓尺寸。
4. 实际查看 contact_details.png 的03、05、07、19放大图：03只有球极小下缘；05篮遮住球上半部；07球已与篮分离；19球下缘与桌面小阴影接触，无浮空。
5. 原静态修补区域有矩形边界和横向木纹涂抹。修改为真实遮挡掩码、灰墙/木桌低频颜色拟合、可见静态木纹细残差，并修正桌后缘约1像素偏差及其混合边缘。磁铁直角底面改为弧底，链环加细厚度。
6. 最后一次重存后再次实际打开8时点检查表、00/01/02及关键接触放大图。检查没有原篮残影、第二个球、物体大小突变、球随篮运动或大块单色物体覆盖。检查以图像为依据，不以帧差和颜色数替代。

## 真实可见局限

- 原图编织材料的每根纤维相位无法从单张图精确续写。02之后虽保留暖棕编织材质、尺度、厚度和密度，仍比首图略均匀，01→02可看到细织纹排列和局部光泽的变化；没有声称逐纤维摄影一致。
- 重画链环已有折弯、左右不对称和金属亮点，但局部扭斜与接头亮暗仍非逐像素复刻，磁铁高光较简化；升高时不模拟额外复杂摆动。
- 原来篮遮住的球、木纹和墙面都不可见。球尺度/接缝与隐藏桌面纹理是明确假设；局部木纹接续和灰墙明暗仍可辨认出修补，4倍查看更明显。
- 球在22像素左右显示，绒毛和接缝只有有限像素；球明暗为二维近似。没有借助不可用的三维真值。

## 根审返修后的重存与实际复查

根代理指出首版01→02由原深棕粗纵肋变成浅棕细网格、侧壁直筒、上沿厚度不足、吊链规则。收到意见后再次实际打开唯一首帧与4倍放大，先在 OBSERVATION.md 追加结构观察，再独立重写 basket 和 suspension 的新RGB函数。没有搬运源篮贴图，也没有通过源篮纹理平移来掩盖差异。

- 侧面改为约12条宽度不等的纵肋，每条有轻微不齐与局部扭转；横条改为短织段，各小段宽度、粗细、亮暗独立变化。新生成的低频纤维不规则值与细亮线补足粗编织层次。去掉原来的均匀浅网格配色，改为原图较深的棕色与近中性的亮暗纤维。
- 外形向底部明显内收；左右边缘与底弧具有柔暗，底沿保留略厚织层。顶编织面增加凹暗、较粗织条和独立前滚边，避免薄盖板观感。
- 链环改为手观察记录的不对称折弯线轮廓：长环顶端偏右、左边弯曲、底端收窄；下环扭斜成不规则近菱形，并有不连续灰银亮点。磁铁保留黑色弧底侧面与局部细高光。
- 00/01原位摄影首帧、球固定桌面支撑、提升距离和前后遮挡事件不变。

返修最后一次重存后实际查看：transition_check.png的00/01/02四倍放大以及03、04、05、06、07、10、14、19；inspection.png的00、02、05、08、11、14、17、19；contact_details.png的03、05、07、19；新增material_check.png的00/02/05吊链、磁铁、篮整体四倍图，以及00/02/05/10篮织层三倍图。深棕材料、宽纵肋、顶层与底部柔暗比首版接近首图，不再表现为浅棕均匀细网格。球露出次序和桌面支撑保持。

真实余差仍存在：原摄影纵肋的逐根位置、交错相位和局部粗纤维形状不能通过独立二维公式完全重建；首图至重画像素之间仍有细织纹排列的差异，原图编织起伏比新像素更复杂。根审的视觉结论需要以新增material_check.png与transition_check.png复核，未以均值、帧差或颜色数替代该检查。
