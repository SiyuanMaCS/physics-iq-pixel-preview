# Case 0025 — 从木桌滚上玻璃板

唯一输入是本目录 `first_frame.png` 与 `prompt.txt`。背景为固定白墙、木桌与透明玻璃板，保留原始像素。首帧球心约 (131, 76)、半径约 11.5 像素，桌面接触位置约 (131, 87)；玻璃左边界由 (163, 65) 斜向 (202, 117)，球的支撑路径约在 y=87。右上方向的漫射照明使球左上面较亮、下缘较暗。玻璃在整个序列中静止。

事件安排：第 0 帧原样保留；1–4 帧球向右滚动接近玻璃左侧；5–8 帧跨越桌面/玻璃交界；9–15 帧在玻璃表面继续滚动；16–19 帧到达画面右边，最后逐渐离开。没有证据说明可见范围内玻璃结束，因此不虚构坠落或反弹。速度随摩擦小幅降低。以球的行进距离除半径设置缝线顺时针滚动相位，接触高度保持在支撑面。

`generate.py` 在 NumPy RGB 数组中直接重画每帧。只对首帧原球/阴影范围做相邻木纹逐行插值修补，其余静态背景保留。每帧重新求二维软边轮廓，绘制稍有毛毡起伏的边界、二维渐变明暗、程序生成的毛毡纤维和随转动改变朝向与弯曲程度的缝线。球底在接触处轻微压平。支撑阴影随球移动，透明玻璃区域减弱，并加入很弱的蓝色接触透射/反射。没有提取、平移、缩放或镜像首帧球贴图，没有三维模型、投影、模型调用、物理引擎或参考视频。

输出为 20 帧 256×144 RGB、4 fps、5 秒，通过公共 `artifact_io.save` 生成 PNG、uint32 0xRRGGBB 张量、接触表和 HTML 播放器。

可见局限：原始首帧分辨率低且失焦；逐行木纹修补不能恢复被球遮住的真实木纹。球的缝线与绒毛为二维外观近似，不能表达完整三维转动与真实光学。玻璃厚度和真实摩擦未从单帧得知，假设薄玻璃近乎与桌面平齐，因此跨界只出现亚像素级高度改变。透明表面的阴影和接触蓝光仅作低强度二维近似。

## 实际视觉检查及修正

已实际查看首帧放大图、公共 8 时刻接触表（00、02、05、08、11、14、17、19），以及补充关键接触表（01、04、05、06、07、08、10、15）和原球位置/跨界球的局部放大图。首轮修补遗漏了原球右侧阴影，出现暗色圆弧残影；扩大原球与阴影修补范围，并把右侧木纹采样沿桌边移到未受阴影影响处后，重新生成并复查，暗色圆弧和重复球影已消除。球轮廓、毛毡和缝线增加软化，接近输入的低分辨率失焦。检查了桌边到玻璃过渡：球下缘一直在同一支撑高度附近，没有浮空跃迁或大幅尺寸改变。透明玻璃上的接触阴影仍偏弱，是当前可见局限。
