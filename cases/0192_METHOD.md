# 0192 生成方法与检查记录

## 输入与实现

仅读取本 case 的 first_frame.png、prompt.txt；读取 shared/GENERATION_RULES.md 和输出 helper artifact_io.py。无其他 case、参考续写、掩码、分数、历史结果、联网、模型、学习权重、物理引擎或三维渲染。

generate.py 用 NumPy 直接求值二维 RGB 场，以4倍采样后降采样抗锯齿。壶铃主体与提手使用独立编写的二维 Bézier 边界；动态铁面由坐标相关的低亮度颜色、两处提手亮边与非学习正弦颗粒重新计算。蓝绿“30 LB”用明确的3×5字形重新绘制，随壶铃附着运动。杯子用当前承重点、桌面底线及压缩程度重新构造外边界、白色泡沫明暗、杯沿厚边、灰色内折线和局部屈曲轮廓。先杯后壶铃的绘制顺序保证壶铃遮挡杯上侧，软阴影贴近桌面支撑。

没有裁切原物体贴图后平移、缩放或镜像。初始被遮挡的背景用原图外侧可见墙面逐行插值，以及邻近桌面的颜色和新算的低振幅木纹补齐。这个背景修补只用于旧轮廓退开后露出的区域。未受动态物体、旧遮挡或接触阴影影响的像素从首帧原坐标保留。00逐像素等于首图。01与02在相同原坐标上以16%和55%引入新算的像素，平滑极小载荷建立阶段；未将首图像素移动到新位置，03起完全使用重新绘制的物体像素。

## 实际视觉检查与修正

1. 先实际打开256×144原图及 first_frame_enlarged.png 的4倍放大图，确认杯横躺、壶铃宽度约57像素、杯宽约41像素，接触在杯上壁。
2. 生成后实际打开 inspection.png，逐格检查00、02、05、08、11、14、17、19八个时点。观察到杯连续压缩、壶铃保持直立向下而不横向滑动，最终静止，无第二个对象或浮空。
3. 实际打开 transition_check.png 的00/01/02四倍局部放大，比较提手边缘、球腹轮廓、蓝绿字样、杯厚沿与摄影明暗。01与首帧形状相近；02只出现亚像素级位置与光泽过渡，没有白杯变色或黑铁突然变成其他材料。
4. 实际检查同图05、08、10、12的杯与壶铃接触放大，并检查03、07、11、19全景。初稿提手露出的内孔中有一条残留暗线。扩大原始抗锯齿轮廓的擦除掩码后仍有该线，查明逐段修补端点采到另一段黑色轮廓；改为统一使用该行最外侧的可见背景取样，重新生成并实际复查，暗线已消除。
5. 初稿杯中段轮廓过方正、最终承托层过薄；增加杯右侧屈曲轮廓、边缘软化、斜折线和底部展开厚度。重新打开两张检查图，05与08可见折线；10与12的薄杯片接触桌面，壶铃下侧遮挡正确。
6. 将动态重算限制在轮廓、旧遮挡和接触阴影区域，复查最终版本两张检查图，背景保持锁定；14–19静止。

## 真实不足

- 新绘制铸铁有连续明暗与颗粒，但比首帧摄影平滑，尤其提手亮边和“30 LB”字形只能近似；02到03可感到细节简化。
- 横躺杯的泡沫褶皱是二维线条与边界近似，中段仍较整齐，不能表现真实泡沫材料细密的破裂和层间遮挡。
- 首帧提手上缘在画外，后续露出的顶部形状按现有两侧走势补全，无法由首帧唯一确定。
- 旧遮挡处墙面与桌纹采用非学习修补，局部墙面更平滑；大范围摄影投影阴影没有精确重新估计。桌面接触阴影随压缩重新求值。
- 压缩时序属于与首帧和重量相容的手工物理假设，没有经过力学求解。

## 保存与校验

调用 artifact_io.save(frames, CASE) 保存20张RGB PNG、pixels.npz、inspection.png及独立index.html。另保存 transition_check.png。执行验证：数组为 uint8 (20,144,256,3)，pixels 为 uint32 (144,256,20)；逐帧将PNG打包为0xRRGGBB与tensor对应切片完全相等，00与first_frame.png逐像素完全相等。以上验证在最终修改后的实际运行中通过。
