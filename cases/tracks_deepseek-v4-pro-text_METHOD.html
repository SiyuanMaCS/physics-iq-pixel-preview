Method

Inspection Modality

Programmatic pixel analysis using Python with NumPy, PIL/Pillow, and SciPy. No visual inspection or image generation models were used.

Approach

Scene Analysis

  • Loaded first_frame.png as uint8 RGB array (144×256×3)
  • Analyzed pixel color distributions to identify distinct regions:
    • Wall background: Light beige (R≈164-170, G≈154-163, B≈150-160), rows 0-60
    • Grabber tool: Very dark blue-black pixels (brightness < 25), rows 0-56, cols 100-162
    • Blue tennis ball: Blue-dominant pixels (B > R+15, B > G+5, brightness > 20), rows 0-28, cols 109-155, center at (132, 13), radius ≈22
    • Green kinetic sand: Green-dominant (G > R+5, G > B+5), rows 84-125, cols 89-181
    • Wooden table: Brown tones (R≈100-135, G≈75-95, B≈40-55), below sand

Ball Extraction

  • Created ball core mask using blue-dominant color threshold
  • Dilated mask 3 iterations to capture dark ball outline
  • Built ball sprite combining original visible pixels with synthesized occluded regions (top of ball hidden behind grabber arms)
  • Ball sprite is 29×47 pixels with alpha channel

Background Inpainting

  • Removed ball from frame 0 by filling dilated ball mask with wall-like colors
  • For each row, interpolated between left and right wall edge colors with noise (σ=1.5)
  • Ensured seamless edges through linear interpolation of boundary colors

Physics Simulation

  • Gravity: g = 150 px/s² (scaled for pixel space)
  • Free fall until ball bottom reaches sand top (row 84)
  • Impact time: t = sqrt(2d/g) ≈ 0.81 seconds (frame 3-4)
  • Post-impact: damped bounce (4px, damping=3.0, period=0.25s) + exponential settling into sand (max penetration=17px, settle rate=0.9)
  • Ball sinks gradually from frame 4 through frame 19

Sand Deformation

  • On contact: push sand pixels down and outward from impact center
  • Deformation weight: (1 - dist/crater_radius)²·², crater radius = ball_radius × 2.8
  • Vertical displacement: up to 1.5× penetration
  • Horizontal displacement: up to 0.75× penetration
  • Lighting: shadow (×0.45) directly under ball, crater rim highlight (×1.25) at edge
  • Per-frame Gaussian noise (σ=1.5) added to sand for grain settling effect

Output Verification

  • Frame 0 confirmed pixel-identical to first_frame.png
  • All 20 frames verified unique
  • pixels.npz tensor verified against individual PNGs using 0xRRGGBB packed uint32 encoding

Revisions

  • v1-v3: Initial ball mask extraction, simple gravity, basic sand deformation
  • v4: Added damped bounce and exponential settling physics
  • v5-v7: Iteratively improved wall fill to reduce edge seams
  • v8: Refactored with cleaner ball mask dilation (iterations=2→3) to eliminate fill boundary artifacts
  • v9 (final): Zero visible seams at fill boundaries, all frames unique with continuous motion

Known Limitations

  • Wall fill uses interpolated colors rather than actual wall texture, resulting in slightly smoother appearance than original
  • Ball top (rows occluded by grabber in frame 0) uses synthetic shading rather than original pixels
  • Sand deformation is a 2D displacement map without true granular physics
  • No lateral ball movement - purely vertical fall
  • Grabber arms remain stationary (no mechanical release animation)
  • Camera is static locked-off as specified
