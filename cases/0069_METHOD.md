# 0069 静止续写方法与核验（根审修正版）

## 输入与场景判断

本例唯一场景输入为 first_frame.png 与 prompt.txt。Caption 明确指定 stationary，首帧未提供流柱、滴落、液面余波或其他动作证据。透明分饮器保持篮上支撑，半杯红液体的玻璃杯保持桌面接触，所有玻璃高光、液面、材质与阴影均静止。

初稿加入摄录前余波，并用多项式重算杯内液面颜色，该假设缺乏输入证据。按根审纠正，generate.py 已删除全部微波、液面多项式、纹理重算与反射变化，重新保存所有输出。

## RGB 生成方式

generate.py 读取首图为 uint8 (144,256,3)，在20个采样时刻逐像素保持该RGB数组，输出 uint8 (20,144,256,3)。本例没有动态区域需要重绘；整幅摄影画面保持不变是明确 stationary 场景的续写。没有对物体作裁切贴图平移、缩放或镜像，也没有引入无证据的摄录前运动。

artifact_io.save 保存 pixels.npz、20张PNG、inspection.png 与 index.html。transition_check.png 是输出帧的放大审查图，其裁剪与缩放只用于检查，未参与生成。没有使用其他案例、参考续写、AI API、学习权重、联网、物理引擎或三维渲染。

## 实际局限

本例输出完全静止。首帧本身的分辨率、轻微摄影模糊、玻璃透明折射细节与顶部裁切都原样保留。不能据单张首帧判断未描述的后续动作，因此未生成注水或任何微动。
