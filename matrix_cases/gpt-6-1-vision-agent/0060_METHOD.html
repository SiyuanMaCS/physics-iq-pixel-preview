+def harmonic_fill(rgb, hole):
+    """Solve the discrete Laplace equation using the original wall at the boundary."""
+    yy, xx = np.nonzero(hole)
+    ids = np.full(hole.shape, -1, dtype=np.int32)
+    ids[yy, xx] = np.arange(len(yy))
+    a = lil_matrix((len(yy), len(yy)), dtype=np.float64)
+    rhs = np.zeros((len(yy), 3), dtype=np.float64)
+    for i, (y, x) in enumerate(zip(yy, xx)):
+        degree = 0
+        for dy, dx in ((0, -1), (0, 1), (-1, 0), (1, 0)):
+            ny, nx = y + dy, x + dx
+            if not (0 <= ny < H and 0 <= nx < W):
+                continue
+            degree += 1
+            j = ids[ny, nx]
+            if j >= 0:
+                a[i, j] = -1
+            else:
+                rhs[i] += rgb[ny, nx]
+        a[i, i] = degree
+    out = rgb.astype(np.float64).copy()
+    out[yy, xx] = spsolve(a.tocsr(), rhs)
+    return out
+

+def extract_layer(source, background, support):
+    """Blue-channel matte: both the yellow rubber and warm dark tool have low blue."""
+    deficit = background[:, :, 2] - source[:, :, 2]
+    alpha = np.clip(deficit / np.maximum(background[:, :, 2], 1), 0, 1)
+    # Suppress noise in the photographed wall while keeping the original soft edge.
+    alpha *= np.clip((deficit - 2.0) / 6.0, 0, 1)
+    alpha *= support
+    residual = source - background * (1 - alpha[:, :, None])
+    foreground = np.clip(residual / np.maximum(alpha[:, :, None], 1e-6), 0, 255)
+    return np.dstack((foreground * alpha[:, :, None], alpha))

+def warp_layer(layer, pivot, angle=0.0, dx=0.0, dy=0.0):
+    """Inverse affine sampling of premultiplied RGBA, with subpixel translation."""
+    theta = np.deg2rad(angle)
+    c, s = np.cos(theta), np.sin(theta)
+    qx, qy = XX - pivot[0] - dx, YY - pivot[1] - dy
+    sx = c * qx + s * qy + pivot[0]
+    sy = -s * qx + c * qy + pivot[1]

METHOD.md

Generation method

This is a continuation made from the supplied photograph with local Python pixel operations. No network, other scenes, references, external models, rendering engines, or subagents were used. The only scene inputs were first_frame.png and prompt.txt. OBSERVATION.md records the measurements and twenty-frame plan written before implementing the generator.

Pixels and animation

The source photo supplies the entire static setting and the moving-object textures. The generator detects the duck using its yellow/orange chroma within its measured bounds and the two grabber prongs using their darker green/blue channels within separate measured bounds. Small dilated removal masks cover the original focus blur. A sparse discrete Laplace solve reconstructs the gray wall in these holes from the original surrounding pixels. It affects 571 source pixels. Nothing outside the small action area is repainted.

The duck and tool receive soft blue-channel mattes. Low-blue yellow, orange, and warm-black object colors are separated from the gray background, and foreground RGB is recovered before compositing. Premultiplied RGBA affine warps use bilinear sampling. The prongs pivot outward by nine degrees around their respective anchors at the clipped top edge; their opening ends at 0.20 seconds, and the tool then remains suspended.

The duck center follows y(t) = 26.5 + 0.5 * 1400 * t**2, with x fixed at 129.5 pixels. The assumed image scale is about 143 pixels/m; it is a plausible calibration, not a measured real-world dimension. The duck rotates four degrees during the visible descent. Seven sub-exposure samples over 1/100 second create short motion blur. At 0.25 seconds, its center is at y = 70.25. A front-rim visibility function prevents the duck from being painted on the opaque box wall. By the 0.50-second sample it has passed into the box and is fully hidden. The generator renders the visible ballistic descent and then omits the hidden duck; it does not explicitly simulate or draw its unseen floor collision or settling. There is no visible bounce or motion of the box.

At this scale the drop completes between two 4-fps samples, so there is one visible falling frame. Frames 02–19 hold the same photograph with the open grabber and the duck out of view inside the box. The source camera, table, shelf, box, lighting, and background remain fixed.

Output and checks

generate.py creates twenty RGB PNGs, each 256 × 144, with frame 00 copied directly from the source image. pixels.npz contains the key pixels, a uint32 array of shape (144, 256, 20) with each pixel packed as 0xRRGGBB. artifact_io.py is used solely for output serialization and the standalone HTML player. The player advances every 250 ms, so the twenty frames display for five seconds. inspection.png shows all twenty frames with sample times. transition_check.png shows frames 00–03, enlarged action crops, and their next-frame absolute RGB differences multiplied by three. Temporary diagnostics remain in .tmp/.

The generator verifies every saved PNG against the corresponding tensor slice and verifies that frame 00 exactly equals the source RGB pixels. It also verifies that all changes are confined to x = 117–142, y = 0–88 and that frames 02–19 are identical. The final changes per transition are 897 pixels for 00→01, 342 for 01→02, and zero for subsequent transitions. Results are recorded in verification.json.
