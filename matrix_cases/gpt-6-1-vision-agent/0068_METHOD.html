glass-stays-same · 生成方法

This sequence is a deliberate static continuation of the supplied setup. The prompt describes a stationary dispenser over a half-filled glass, with no specified pouring or valve action. Visual inspection of the supplied image found no visible jet or falling droplet. The continuation therefore holds the scene in quiescent equilibrium for the complete five-second duration.

generate.py uses local Python, NumPy, and Pillow. It reads the source RGB array and copies those exact pixels into each of 20 frames. No region is painted, warped, synthesized, or replaced. No external model, reference, network service, simulation engine, or additional scene input is used. This is pixel copying, not a fluid simulation. Keeping both liquid levels fixed corresponds to zero flow in the chosen continuation.

Output format

  • 20 RGB PNGs: frames/00.png through frames/19.png, each 256 × 144.
  • Timing: 4 fps, 0.25 seconds per frame, total playback duration 5 seconds. Frame start times span 0.00–4.75 seconds; the final frame is held through 5.00 seconds.
  • pixels.npz: key pixels, dtype uint32, shape (144, 256, 20). Each value is packed as 0xRRGGBB.
  • index.html: standalone player with embedded first-frame pixels and 19 delta packets, playback controls, and a 250 ms frame interval. The packets are empty because the continuation is stationary.
  • inspection.png: eight representative frames. Its helper labels show the end of each frame's 0.25-second interval.
  • transition_check.png: frames 00, 01, and 19; an absolute-difference image; and numerical checks for all 19 adjacent transitions. This sheet labels frame start times.
  • OBSERVATION.md: scene measurements and the full 20-frame plan, written before generation code.
