+def build_trajectory():
+    ramps = [
+        ('upper_blue', -.143, 26.5 + .143 * 174.4, 126.8),
+        ('yellow', .143, 43.1 - .143 * 72, 141.6),
+        ('lower_blue', -.120, 70.0 + .120 * 132, 131.3),
+        ('green', .120, 81.0 - .120 * 70, 137.6),
+    ]
+    segments = []
+    time, x, vx = 0.0, float(ORIGIN[0]), 0.0
+    for i, (name, slope, intercept, end) in enumerate(ramps):
+        y = slope * x + intercept
+        ax = G * ROLL_FACTOR * slope / (1 + slope * slope)
+        root = math.sqrt(vx * vx + 2 * ax * (end - x))
+        duration = max(t for t in ((-vx + root) / ax, (-vx - root) / ax) if t > 0)
+        segments.append(dict(name=name, kind='roll', start=time, duration=duration,
+                             x=x, y=y, vx=vx, vy=slope * vx, ax=ax, ay=slope * ax))
+        time += duration
+        x = end
+        vx += ax * duration
+        vy = slope * vx
+        y = slope * x + intercept
+        target_slope, target_intercept = ramps[i + 1][1:3] if i < 3 else (0.0, 113.8)
+        linear = vy - target_slope * vx
+        constant = y - target_slope * x - target_intercept
+        duration = (-linear + math.sqrt(linear * linear - 2 * G * constant)) / G
+        segments.append(dict(name='drop_' + name, kind='flight', start=time, duration=duration,
+                             x=x, y=y, vx=vx, vy=vy, ax=0.0, ay=G))
+        time += duration
+        x += vx * duration
+        y += vy * duration + .5 * G * duration ** 2
+        vy += G * duration
+        vx = IMPACT_RETENTION * (vx + target_slope * vy) / (1 + target_slope ** 2)
+    # Only the original receiving piece catches the marble; tiny damped bounce.
+    return segments, dict(start=time, x=x, y=y, vx=vx)

METHOD.md

Method and verification

This is a local procedural pixel continuation of the supplied scientific demonstration. Source analysis used Pillow and NumPy to inspect numeric RGB values, color connected components, pixel coordinates, and sloping boundaries. No image Read/View tools were used, and no visual review is claimed. All scene content comes from first_frame.png and prompt.txt.

Scene reconstruction

The fixed photograph supplies the entire background and all magnetic ramps. The yellow glass marble is measured near (174.4, 26.5), approximately 5.9 pixels in diameter, poised above the upper blue/purple ramp. The source already establishes its release location. The marble rolls left along that ramp, drops onto the yellow ramp, travels right, drops onto the lower blue ramp, travels left, drops onto the green ramp, travels right, and falls into the existing purple receiver.

For frames 01–19, the original marble's small occluded region is filled with source pixels sampled 15 columns to either side and vertically aligned to the photographed ramp slope. A row interpolation between nearby unoccluded board pixels restores the local illumination gradient above the edge. A compact feathered mask blends the reconstructed area. This is local pixel interpolation, not generated content from an external model.

The moving marble uses the original sphere's sampled RGB texture. A soft circular alpha matte removes the original background contamination from its edge. Bilinear texture translation, 8 × 8 subpixel integration, a weak transmitted background tint, and a subtle changing internal inclusion maintain its small glass appearance. The photographed reflection pattern remains fixed relative to illumination. A compact soft shadow supplies contact, and a 10 ms exposure is averaged over three trajectory samples. There are no changes to camera position, zoom, whiteboard, ramp placement, or illumination beyond these local overlays.

Motion calculation

The marble center lines are measured approximately three pixels above each ramp's upper running edge. Image-space gravity is 850 pixels/s². Tangential ramp acceleration is calculated as g × (5/7) × slope / (1 + slope²); each free flight uses constant horizontal velocity and gravity in the vertical direction. Quadratic intersection with the next measured center line determines landing time. Ramp impact retains 10% of the incoming velocity projected onto the new tangent, allowing a short uphill drift before gravity reverses the direction. These are chosen image-space dynamics and dissipative contact parameters; physical dimensions and material coefficients are not calibrated from the single frame.

The receiver catches the marble at 4.379 seconds near (149.30, 113.80). A rebound smaller than 0.4 pixels and a short horizontal damping interval settle it. The exact 20-frame centers and revised event plan are recorded in OBSERVATION.md; segment timing and sample values are also in .tmp/trajectory.json.
