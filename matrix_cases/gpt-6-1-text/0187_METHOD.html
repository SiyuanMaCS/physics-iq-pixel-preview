+def top_clean_plate(source):
+    """Extrapolate wall RGB only behind the two cropped top fragments.
+
+    The big central region x=102..154 is the original iron handle and is
+    preserved. The occluder is extracted as a signed RGB residual so its
+    photographed edge shading travels with it.
+    """
+    result = source.copy()
+    # Left fragment occupies mostly row 0 and a small area of row 1.
+    # Rows 3..5 at these x positions supply an unobstructed local wall.
+    for x in range(44, 102):
+        reference = np.mean(source[3:6, x], axis=0)
+        slope = np.clip((np.mean(source[6:9, x], axis=0) - reference) / 3,
+                        -1.0, 2.0)
+        edge_weight = smoothstep((x - 44) / 9)
+        for y in range(3):
+            # Remove the occluder's soft shadow along the upper margin too.
+            target = reference + (y - 4) * slope
+            weight = edge_weight * (1 if y < 2 else .45)
+            result[y, x] = source[y, x] * (1-weight) + target * weight
+    # Right fragment is clearly separated from the iron handle at x>=155.
+    reference = gaussian_filter1d(np.mean(source[10:15], axis=0), .6, axis=0)
+    # x=155 is one pixel outside the right handle; use its wall neighbor.
+    reference[155] = np.mean(source[10:15, 156:158], axis=(0, 1))
+    slope = np.clip((np.mean(source[16:20], axis=0) - reference) / 6.0,
+                    -.4, .7)

+        strength = 1.0 - smoothstep((y - 8) / 2)

+    return np.clip(result, 0, 255)

Actual pixel operations

generate.py uses NumPy, Pillow, and SciPy's local numeric interpolation utilities. It copies the input directly for frame 00. Later frames retain the original photographed colors, texture, and lighting.

The top-edge occluder is inferred from the source's dark silhouette. The hidden narrow wall strip is reconstructed from adjacent unobstructed rows of the same photograph. On the left, rows 3–8 provide local RGB values and a bounded vertical slope for the first three rows. On the right, rows 10–19 provide RGB values, a small horizontal smoothing operation, and a bounded vertical slope for the upper ten rows. The original iron handle between x=102 and x=154 is preserved. The original image minus this clean plate forms a signed RGB residual that is translated upward and right by up to 14 pixels using bilinear interpolation and zero residual outside the frame. Its retreat follows a smoothstep curve over the first second. This is a source-pixel animation of a cropped occluder, not an articulated hand reconstruction.

The kettlebell movement is an inverse-coordinate warp about the contact point (130,73). Its nominal angle is

theta(t) = 0.36 degrees * exp(-1.35*t) * sin(2*pi*0.85*t)

with a smooth taper to zero from 2.75 to 3.5 seconds. The final translations are 0.18 pixel right and 0.12 pixel down, smoothly reached over 0.75 second; a further decaying horizontal oscillation has a maximum coefficient of 0.055 pixel. These small values model settling of a load already touching the rim, rather than free fall. At the sampled times the upper silhouette displacement stays below one pixel.

A local displacement window covers the kettle and its handle opening. It fades across a small surrounding background annulus and reaches zero at y=76 and outside x=95–161. Bilinear source sampling maintains the photographic surface. This technique slightly resamples the wall immediately around and through the handle, and the two rim rows in the fade region. The rest of the scene, including the mug's main walls, its handle below the rim, the mug base, wood grain, and distant wall, remains at the original pixel positions. It is an image-space continuation with prescribed analytic motion; it does not simulate ceramic stress or solve rigid-body contact. The contact shadow is inherited from the photograph with only the same tiny local resampling.

A 30 lb load is about 134 N. The prompt does not specify an impact or a broken mug, and the input already shows broad contact between the centered kettle base and the mug rim. Maintaining intact ceramic support is the chosen physically plausible continuation. Identifying the cropped top shape as the placing occluder is an interpretation of its source silhouette, and the unseen background reconstruction is an approximation from local source colors.
