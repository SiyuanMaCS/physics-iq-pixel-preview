+#!/usr/bin/env python3
+"""Generate the 20-frame locked-shot tennis-ball rotation sequence.
+
+Only local pixel operations are used.  The animation inverse-maps the original
+ball appearance through a clockwise image-plane rotation.  A robust, smooth
+illumination estimate is used to stop the broad highlight from rotating with
+the painted face and felt texture.
+"""
+
+from pathlib import Path
+
+import cv2
+import numpy as np
+from PIL import Image, ImageDraw
+
+import artifact_io
+
+
+ROOT = Path(__file__).resolve().parent
+W, H = 256, 144
+N_FRAMES = 20
+CX, CY = 139.0, 75.0
+RX, RY = 17.5, 17.5
+DEGREES_PER_FRAME = 3.0
+
+
+def bilinear_sample(image: np.ndarray, sx: np.ndarray, sy: np.ndarray) -> np.ndarray:
+    """Sample a float RGB image at floating coordinates with reflected edges."""
+    maps_x = sx.astype(np.float32)
+    maps_y = sy.astype(np.float32)
+    return cv2.remap(
+        image.astype(np.float32),
+        maps_x,
+        maps_y,
+        interpolation=cv2.INTER_LINEAR,
+        borderMode=cv2.BORDER_REFLECT_101,
+    )
+
+
+def make_frames(source: np.ndarray) -> np.ndarray:
+    assert source.shape == (H, W, 3) and source.dtype == np.uint8
+    source_f = source.astype(np.float32)
+
+    # Median filtering removes the small eyes, mouth and most of the seam from
+    # the lighting estimate.  Gaussian filtering leaves only broad shading.
+    illumination = cv2.medianBlur(source, 9).astype(np.float32)
+    illumination = cv2.GaussianBlur(
+        illumination, (0, 0), sigmaX=3.2, sigmaY=3.2,
+        borderType=cv2.BORDER_REFLECT_101,
+    )
+
+    yy, xx = np.mgrid[0:H, 0:W].astype(np.float32)
+    dx = xx - CX
+    dy = yy - CY
+    radial = np.sqrt((dx / RX) ** 2 + (dy / RY) ** 2)
+
+    # Full motion through most of the sphere, then a narrow subpixel feather.
+    # The silhouette and contact boundary therefore stay locked to frame 00.
+    alpha = np.clip((1.035 - radial) / (1.035 - 0.935), 0.0, 1.0)
+    alpha = alpha * alpha * (3.0 - 2.0 * alpha)
+    alpha3 = alpha[..., None]
+
+    result = []
+    for index in range(N_FRAMES):
+        if index == 0:
+            result.append(source.copy())
+            continue
+
+        angle = np.deg2rad(DEGREES_PER_FRAME * index)
+        c, s = np.cos(angle), np.sin(angle)
+
+        # Inverse map for visually clockwise rotation in image coordinates.
+        sx = CX + c * dx + s * dy
+        sy = CY - s * dx + c * dy
+        rotated = bilinear_sample(source_f, sx, sy)
+        rotated_light = bilinear_sample(illumination, sx, sy)
+
+        # Additive illumination transfer keeps the broad, camera-fixed light
+        # while retaining high-frequency painted and felt texture from source.
+        corrected = rotated + (illumination - rotated_light)
+        corrected = np.clip(corrected, 0.0, 255.0)
+        composed = source_f * (1.0 - alpha3) + corrected * alpha3
+        result.append(np.rint(composed).astype(np.uint8))
+
+    frames = np.stack(result)
+    frames[0] = source  # explicit pixel-exact first-frame contract
+    return frames

OBSERVATION.md

Observation and event plan

Scene measurements

  • Source: 256 x 144 RGB PNG, locked camera and fixed perspective.
  • The tennis ball is centered at approximately (139, 75) with a visible radius of about 17 pixels. Its measured colored silhouette spans roughly x=122..156, y=58..92.
  • The black platform is centered near x=139; its dark visible extent is approximately x=103..175, y=78..124. It is rotationally symmetric enough that no platform motion needs to be synthesized.
  • The ball has a yellow-green body, dark smiley features, a pale curved tennis seam, stationary left/front illumination, and a contact shadow at its base.
  • The background wall, wood tabletop, platform, framing, exposure, and shadows must remain pixel-locked. Motion will be confined to the ball silhouette.
  • Rotation is interpreted in the image plane because the prompt specifies a visible clockwise direction. The total turn is deliberately modest (57 degrees over 4.75 seconds) to read as slow, continuous rotation.

20-frame event plan

The camera and every non-ball pixel remain fixed in every frame. Angles are clockwise relative to frame 00.

Planned synthesis

Use inverse-mapped bilinear rotation within a soft circular ball mask. Preserve the stationary sphere illumination with a low-frequency illumination field: rotate the source appearance, then compensate by the ratio between fixed and rotated illumination. The smile, seam, and fine felt texture consequently rotate while the dominant highlight, silhouette, contact shadow, platform, table, and wall stay fixed. Frame 00 is copied byte-for-byte at the pixel-array level.

METHOD.md

Method

Actual generation method

generate.py reads only first_frame.png and generates the complete sequence with local NumPy/OpenCV/Pillow pixel operations.

  1. The source frame is converted to a floating-point RGB array.
  2. A low-frequency illumination field is estimated with a 9-pixel median filter followed by a Gaussian blur. The median stage suppresses the compact black smile and eyes; the blur retains the broad sphere lighting.
  3. For each frame, coordinates inside the measured tennis-ball silhouette are inverse-mapped through a 3-degree-per-frame clockwise image-plane rotation about (139, 75). RGB values are bilinearly sampled from the source.
  4. To avoid making the light source rotate with the painted face, the rotated low-frequency field is subtracted and the fixed low-frequency field is added. This leaves the broad lighting approximately camera-fixed while rotating the smile, seam, and small felt variations.
  5. The result is composited through a smooth elliptical mask: fully animated over the ball interior and feathered only near the silhouette. Pixels outside the ball are copied unchanged from the source, so the wall, table, platform, shadow, exposure, and camera remain locked.
  6. Frame 00 is explicitly replaced with the original source array. artifact_io.save writes the packed uint32 0xRRGGBB tensor, the 20 RGB PNGs, contact sheet, and standalone player. A separate diagnostic montage shows three consecutive-frame pairs and amplified pixel deltas.

The animation contains 20 frames at 256 x 144 and is intended for playback at 4 fps (5 seconds). The final ball angle is 57 degrees clockwise.

Numeric verification

  • PNG stack: (20, 144, 256, 3), uint8, RGB.
  • Packed tensor: (144, 256, 20), uint32.
  • Frame 00 and first_frame.png: pixel-exact, maximum channel error 0.
  • Re-unpacked tensor and all 20 PNGs: pixel-exact.
  • Changed pixels outside the ball silhouette across all generated frames: 0.
  • Consecutive transitions change 942 to 966 pixels, all localized to the ball.
  • Mean absolute full-frame consecutive delta is stable (approximately 0.103 to 0.107 channel levels after the first source-to-generated transition), supporting uniform motion with no cuts or holds.
  • A dark-detail centroid measured after subtracting broad illumination advances about 62 degrees in image-coordinate phase from frame 00 to frame 19, confirming clockwise motion consistent with the planned 57-degree transform.

Generated frames were not opened with an image viewing tool. Later-output inspection was performed only by reading pixel arrays and reporting numerical measurements, as requested.
