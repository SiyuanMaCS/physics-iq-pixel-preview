+    frames = np.repeat(base[None, ...], FRAME_COUNT, axis=0)

+
+    # Analytic illumination fields. There is no geometric warp: the scene and
+    # all liquid boundaries stay locked. Integer amplitudes are intentionally
+    # capped at two red levels and one green level.
+    for t in range(1, FRAME_COUNT):
+        phase = 2.0 * np.pi * t / 10.5
+        decay = 0.90 - 0.018 * t
+
+        dispenser_wave = (
+            np.sin(0.19 * xx + 0.12 * yy + phase)
+            + 0.42 * np.sin(0.07 * xx - 0.23 * yy - 0.65 * phase)

+            + 0.35 * np.sin(0.11 * xx - 0.17 * yy - 0.52 * phase)
+        )
+

+        t_delta = np.rint(1.20 * decay * tumbler_wave).astype(np.int16)
+        d_delta = np.clip(d_delta, -2, 2)
+        t_delta = np.clip(t_delta, -2, 2)
+
+        out = frames[t].astype(np.int16)

METHOD.md

Method

The sequence is a conservative pixel-level continuation of the supplied frame. No generative model, external engine, external image, mask, score, or network resource was used.

generate.py loads first_frame.png as RGB and repeats it into a 20-frame tensor. It derives two conservative red-pixel masks using fixed RGB inequalities inside manually measured rectangles: one mask lies inside the dispenser liquid and one inside the tumbler liquid. The metal spigot, liquid boundaries, glass outlines, basket, wall, and table are excluded.

For frames 01 through 19, the script evaluates two low-amplitude analytic sine fields with slightly different phases. Within the masks only, the sine fields adjust red by at most two 8-bit levels and green by at most one level. This represents tiny stationary illumination/refraction changes in settled red liquid. It does not warp, translate, resample, or change the fill surfaces. Frame 00 bypasses the effect and is explicitly restored from the source array.

artifact_io.save packs the RGB data into the required uint32 0xRRGGBB tensor, writes the 20 PNG frames and inspection contact sheet, and builds the standalone HTML player. generate.py also writes transition_check.png, whose five panels are amplified absolute-difference maps for selected adjacent transitions; labels report changed-pixel counts and maximum channel deltas.

Validation is performed numerically: exact frame-00 equality, PNG/tensor equality, RGB shape and dtype, file counts and dimensions, changed-pixel containment, maximum delta, temporal transition metrics, and HTML payload reconstruction. Later outputs are not visually inspected with image viewing tools.
