+def bilinear_sample(field, sample_y, sample_x):
+    """Bilinearly sample an HxWxC float field on a regular output grid."""
+    h, w = field.shape[:2]
+    sy = np.clip(sample_y, 0.0, h - 1.001)
+    sx = np.clip(sample_x, 0.0, w - 1.001)
+    y0 = np.floor(sy).astype(np.int32)
+    x0 = np.floor(sx).astype(np.int32)
+    y1 = np.minimum(y0 + 1, h - 1)
+    x1 = np.minimum(x0 + 1, w - 1)
+    fy = (sy - y0)[..., None]
+    fx = (sx - x0)[..., None]
+    top = field[y0, x0] * (1.0 - fx) + field[y0, x1] * fx
+    bottom = field[y1, x0] * (1.0 - fx) + field[y1, x1] * fx
+    return top * (1.0 - fy) + bottom * fy

OBSERVATION.md

Observation and event plan

Source measurements

  • Source frame: RGB PNG, 256 x 144 pixels.
  • Camera: fixed, level, and already composed as a close tabletop shot. No camera motion is described or introduced.
  • Background/table boundary: the pale wall occupies most of the upper image; the wooden tabletop rises diagonally from roughly (0, 126) at the left edge to (72, 101), then remains behind the holders across the lower portion.
  • Left candle: red wax body approximately x=83..95, y=23..94; brass holder/cup approximately x=68..116, y=90..134.
  • Left flame: luminous footprint approximately x=84..92, y=10..26, with its white core centered near x=86..87, y=15..21. The wick/flame base meets the candle around y=24..26.
  • Right candle: red wax body approximately x=141..152, y=21..103; brass holder approximately x=127..181, y=98..143. It is unlit.
  • Lighting: soft neutral wall light plus a small warm local contribution from the lit left candle. The flame is the only naturally time-varying element called for by the prompt.
  • Safety margins: the animated region stays inside x=78..99, y=6..31; candle bodies, holders, tabletop, wall outside this region, and the unlit right wick remain fixed.

Interpretation

The text describes a static scientific-demonstration setup and does not specify ignition, extinguishing, melting, movement, or human interaction. The continuation therefore holds the locked-off scene for five real-time seconds. Only subtle flame flicker and its very faint local glow vary. This avoids inventing an event that is absent from the prompt.

20-frame event plan (4 fps)

Frame 00 is copied byte-for-byte from first_frame.png. Subsequent frames use a smooth, deterministic flicker cycle; offsets are deliberately subpixel or one-pixel scale to remain physically plausible at this resolution.

METHOD.md

Method

The continuation is a deterministic local pixel animation derived only from first_frame.png.

  1. The source PNG is loaded as RGB. Frame 00 is copied without modification.
  2. For wall rows above the left candle, a per-channel linear wall gradient is fit from pixels on both sides of the flame (x=71..77 and x=99..105). This estimates the small patch of wall hidden by the flame.
  3. The photographed flame is represented as the RGB residual between the source and that estimated wall, tapered by a soft mask that follows the flame from its narrow tip to its wider base.
  4. For frames 01–19, this original residual is inverse-warped with bilinear sampling. A height scale, width scale, subpixel bend, and intensity factor produce restrained flicker. Every warp is anchored at y=24, so the flame remains attached to the same wick/candle top.
  5. The warped residual is composited over the reconstructed wall. The animated area is then hard-limited to x=72..103, y=4..24; every pixel outside that rectangle is restored exactly from the source.
  6. artifact_io.save writes the uint32 packed tensor, PNG sequence, inspection contact sheet, and standalone HTML player. transition_check.png shows 5x-amplified absolute RGB differences between consecutive flame crops.

No external model, engine, reference image, mask, network resource, or image-generation service was used. No visual inspection tool was used on generated outputs; verification is performed through array equality, numeric difference statistics, PNG decoding, and packed-tensor comparison.
