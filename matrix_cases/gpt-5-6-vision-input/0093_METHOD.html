lit-candle · 生成方法

The continuation is a deterministic local pixel animation derived only from first_frame.png.

  1. The source PNG is loaded as RGB. Frame 00 is copied without modification.
  2. For wall rows above the left candle, a per-channel linear wall gradient is fit from pixels on both sides of the flame (x=71..77 and x=99..105). This estimates the small patch of wall hidden by the flame.
  3. The photographed flame is represented as the RGB residual between the source and that estimated wall, tapered by a soft mask that follows the flame from its narrow tip to its wider base.
  4. For frames 01–19, this original residual is inverse-warped with bilinear sampling. A height scale, width scale, subpixel bend, and intensity factor produce restrained flicker. Every warp is anchored at y=24, so the flame remains attached to the same wick/candle top.
  5. The warped residual is composited over the reconstructed wall. The animated area is then hard-limited to x=72..103, y=4..24; every pixel outside that rectangle is restored exactly from the source.
  6. artifact_io.save writes the uint32 packed tensor, PNG sequence, inspection contact sheet, and standalone HTML player. transition_check.png shows 5x-amplified absolute RGB differences between consecutive flame crops.

No external model, engine, reference image, mask, network resource, or image-generation service was used. No visual inspection tool was used on generated outputs; verification is performed through array equality, numeric difference statistics, PNG decoding, and packed-tensor comparison.
