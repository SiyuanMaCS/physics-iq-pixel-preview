cut-orange · 生成方法

The continuation is a deterministic local Python pixel composite; no external model, engine, reference image, or generated asset is used.

  1. first_frame.png is loaded as the sole source image. Frame 00 is copied directly and never passed through a resampler.
  2. Two visible tangerine portions are isolated from the source with an HSV orange seed, connected-component analysis, morphological closing, contour filling, and the measured diagonal cut line. This preserves the source peel/pulp texture while preventing knife pixels from entering a fruit layer.
  3. The knife silhouette is a hand-measured polygon matching the diagonal blade in the source. Measured visible fruit regions are assigned exclusively to the fruit layers, preventing peel/pulp pixels near the blade boundary from moving with the steel. Fruit and knife masks receive subpixel feathering.
  4. Frames 01–12 translate the source-derived knife texture smoothly toward the lower-left by 12×10 pixels. Frames 13–19 add a small, eased rebound. Starting at frame 06, the two fruit portions separate in opposite directions perpendicular to the blade, reaching only a few pixels of displacement.
  5. Every frame starts from the untouched source. Only source-object pixels newly exposed by the transformed layers are locally inpainted, keeping the invented background to a narrow strip. Restrained blurred contact shadows, plus thin orange/cream cut-edge highlights, maintain contact and communicate the completed cut. The fruit is composited first and steel last to preserve correct occlusion.
  6. artifact_io.save writes the packed uint32 0xRRGGBB tensor, PNG sequence, inspection sheet, and standalone HTML player. generate.py additionally writes transition_check.png and prints changed-pixel and temporal-difference statistics for numeric inspection.

No later generated frame was opened with an image Read/View tool. Validation is performed by array dimensions, equality checks, masks, deltas, and file/tensor comparisons.
