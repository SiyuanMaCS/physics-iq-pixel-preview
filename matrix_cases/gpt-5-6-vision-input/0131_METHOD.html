paint-on-glass · 生成方法

The animation is a local 2D pixel construction derived only from first_frame.png and prompt.txt.

  1. I measured the brush axis, red dollop, acrylic boundary, and platform attachment directly in the source pixels.
  2. I extracted the photographed brush with a narrow antialiased geometric mask along its measured axis. Strongly red source pixels were excluded from this moving layer so the original dollop would not be duplicated.
  3. I made a static clean plate by OpenCV Telea inpainting only the original brush/brush-shadow strip. The source dollop, acrylic, tabletop, platform, and green clamp remain fixed.
  4. For frames 01-19, I rotate the extracted source brush at a constant rate from 0 to 11 degrees clockwise around (231, 49). A soft offset mask provides the moving contact shadow. The photographed green clamp is restored as a foreground layer at the pivot so the handle stays visually mounted beneath it.
  5. I composite a persistent, narrow red arc following the measured bristle-tip trajectory and a small dark-red coating on the moving bristles. This depicts the brush passing through the dollop, transferring wet paint, and moving beyond it.
  6. Frame 00 is copied byte-for-byte from the RGB source. artifact_io.save writes the PNG sequence, packed uint32 tensor, inspection sheet, and standalone player; the generator also writes adjacent-frame difference panels to transition_check.png.

No external images, models, engines, masks, or visual review tools were used. Generated results were checked only with local code and numeric image statistics.
