The scene was generated with local Python pixel operations only.

generate.py decodes first_frame.png as a 256 x 144 RGB uint8 array and duplicates that exact array for all 20 time samples. No interpolation, redraw, filtering, external model, external engine, or synthesized imagery is used. This is intentional: the prompt explicitly locks the camera and says the rubber duck sits stationary, while specifying no event that would produce motion.

The shared artifact_io.save helper packs each RGB triplet into a uint32 value in 0xRRGGBB order, writes pixels.npz, writes frames/00.png through frames/19.png, builds the contact sheet, and embeds the sequence in the standalone player.

transition_check.png is generated programmatically as a diagnostic panel containing frame 00, frame 10, and an 8x-amplified absolute difference between frames 19 and 00. The difference maximum is zero. The generator then reloads every PNG and the NPZ tensor and verifies exact equality with the in-memory frame arrays; it also verifies that frame 00 exactly equals the supplied PNG and that every inter-frame delta is zero.

No generated output was visually inspected with an image viewing tool. Validation is by array shape, dtype, equality, packed-pixel comparison, and numeric temporal-difference checks.
