The sequence uses the supplied first_frame.png as its only visual source. generate.py loads it as an unmodified 256 × 144 RGB uint8 array and repeats that exact array 20 times. This implements a 5-second hold at 4 fps.

The zero-motion result is deliberate. The prompt says the yellow rubber duck is stationary and the camera is locked off in real time, so no object animation, camera motion, lighting change, synthesized texture, or random sensor noise is introduced.

artifact_io.save serializes the frames into the required uint32 0xRRGGBB tensor layout, individual PNGs, inspection sheet, and standalone HTML player. generate.py also creates transition_check.png from computed consecutive-frame changed-pixel counts. It reports the expected zero changed pixels and zero peak channel delta for all 19 transitions.

Validation is performed with local array and file checks only. The generated images are not visually opened or reviewed.
