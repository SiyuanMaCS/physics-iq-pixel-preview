+def isolate_wrench(source: np.ndarray):
+    """Return a reconstructed platform and the wrench's signed RGB residual."""
+    gray = cv2.cvtColor(source, cv2.COLOR_RGB2GRAY)
+
+    # The search gate excludes the nearby magnet and the bright platform rim.
+    candidate = np.zeros(gray.shape, np.uint8)
+    candidate[46:72, 141:183] = (gray[46:72, 141:183] > 55).astype(np.uint8)
+    count, labels, stats, centroids = cv2.connectedComponentsWithStats(candidate, 8)
+    if count < 2:
+        raise RuntimeError("Could not isolate the wrench")
+
+    target = np.array(PIVOT)
+    valid = []
+    for label in range(1, count):
+        area = int(stats[label, cv2.CC_STAT_AREA])
+        x = int(stats[label, cv2.CC_STAT_LEFT])
+        if 120 <= area <= 350 and x >= 141:
+            distance = float(np.linalg.norm(centroids[label] - target))
+            valid.append((distance, label))
+    if not valid:
+        raise RuntimeError("No wrench-shaped connected component found")
+    wrench_label = min(valid)[1]
+    core = (labels == wrench_label).astype(np.uint8)
+
+    # Include antialiased boundary and the original one-pixel contact shadow.
+    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
+    removal = cv2.dilate(core, kernel, iterations=1)
+    removal = cv2.morphologyEx(
+        removal, cv2.MORPH_CLOSE,
+        cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3)),
+    )
+
+    # Reconstruct only the small patch hidden by the tool. TELEA interpolates
+    # the surrounding dark platform texture without touching the fixed scene.
+    platform = cv2.inpaint(
+        cv2.cvtColor(source, cv2.COLOR_RGB2BGR), removal * 255, 4.0,
+        cv2.INPAINT_TELEA,
+    )
+    platform = cv2.cvtColor(platform, cv2.COLOR_BGR2RGB)
+
+    # A signed residual preserves the exact metallic shading and its faint
+    # contact shadow. At zero degrees, platform + residual equals source.
+    residual = (source.astype(np.float32) - platform.astype(np.float32))
+    residual *= removal[..., None].astype(np.float32)
+    return platform, residual, removal

OBSERVATION.md

Scene observation and event plan

Source-frame observations

  • Canvas: 256 x 144 pixels, RGB, locked-off landscape view.
  • Background: a light brown wood tabletop fills the frame. Grain runs mostly left-to-right with mild perspective curvature. Illumination is soft and comes from upper left; no hard moving shadows are present.
  • Black platform: a low, round/elliptical black puck occupies approximately x=139..215, y=25..88. Its visible top is an ellipse-like dark surface with a subtly brighter upper-left rim and a darker lower/right wall.
  • Small wrench: a pale silver wrench lies fully on the platform, approximately x=141..179, y=49..70. It is initially close to horizontal, with the open jaw at the left and the handle pointing toward the lower-right. Its working rotation center is estimated near (160, 59) so the tool remains on the platform.
  • Magnet: the compact metallic magnet assembly sits left of the platform, approximately x=96..132, y=42..85, aimed toward the wrench/platform. It remains stationary.
  • Purple tape/marker: a diagonal violet strip lies on the tabletop at approximately x=83..116, y=49..113. It remains stationary.
  • No people enter the shot and there is no camera motion, zoom, cut, or change of lighting.

Motion and compositing plan

The first frame is copied byte-for-byte. For subsequent frames, the source wrench is isolated from its dark platform, the vacated pixels are reconstructed from nearby platform texture, and the isolated tool is rotated clockwise about (160, 59) with bicubic resampling. A faint transformed contact shadow moves consistently beneath it. All pixels outside a tight platform/wrench work region remain identical to frame 00.

The action uses a gentle ease-in followed by steady magnet-driven rotation, totaling about 155 degrees during the five-second shot:

METHOD.md

Method

The continuation is a source-derived 2D photographic composite made with Python, NumPy, OpenCV, and Pillow. No external images, masks, models, engines, or reference cases are used.

  1. first_frame.png is loaded as RGB. Frame 00 is retained as the unmodified source array.
  2. Within a deliberately tight platform region, the wrench is selected as the connected component above grayscale 55 whose area and centroid match the measured tool. This excludes both the magnet and the platform's bright left rim.
  3. The selection is expanded by two pixels to include antialiasing and the small contact shadow. OpenCV's local TELEA inpainting reconstructs the dark platform patch covered by the wrench.
  4. The exact signed RGB difference between the original image and that reconstructed platform is retained. It carries the source wrench's real metallic gradients, blue-gray reflections, edge antialiasing, and contact shading.
  5. For frames 01 through 19, that source-derived residual is rotated clockwise about (161, 58) using bicubic affine resampling. The planned cumulative angles are 2, 6, 12, 20, 29, 39, 50, 61, 72, 83, 94, 105, 116, 127, 137, 145, 151, 154, 155 degrees. It is then added to the clean local platform and clipped to RGB range.
  6. All pixels outside the platform/wrench work area remain source-identical, preserving the locked camera, fixed magnet, tape, wood grain, shadows, and lighting.
  7. artifact_io.save packs the 20 frames as uint32 0xRRGGBB, writes the PNG sequence, creates the inspection contact sheet, and builds the standalone HTML player. A separate transition sheet is computed from selected consecutive-frame absolute differences.

Validation checks enforce the exact 20 x 144 x 256 x 3 uint8 frame tensor, exact frame-00 pixel equality, nonzero motion at every transition, confined motion bounds, unchanged background pixels, PNG/tensor equality, and HTML delta reconstruction equality.
