marble-run-x · 生成方法

The animation is a deterministic local Python pixel construction. No external model, renderer, engine, reference image, mask, or network resource is used.

  1. first_frame.png is loaded as the sole scene input. Frame 00 is copied from it exactly.
  2. For frames 01–19, the original marble's tiny footprint is removed with OpenCV's local Telea inpainting over a 5-pixel-radius ellipse. This propagates only immediate neighboring board/ramp texture; the camera and apparatus remain locked.
  3. The marble follows an explicitly authored 20-sample piecewise route across the measured ramp surfaces. Free-flight samples bridge ramp ends under gravity-like increasing vertical displacement; impact samples receive a subtle one-pixel squash.
  4. The new marble is drawn with NumPy analytic pixel shading: an antialiased elliptical silhouette, translucent yellow-green body, darker glass rim, upper-left specular highlight, lower caustic, and a small soft contact/drop shadow. Only fast airborne samples receive a restrained two-sample exposure trace.
  5. artifact_io.save writes the packed uint32 0xRRGGBB tensor, 20 RGB PNGs, inspection sheet, and standalone player. The script also creates a representative transition/difference sheet and then reloads every saved PNG and asserts exact equality against the matching tensor plane.

Run with:

python generate.py
