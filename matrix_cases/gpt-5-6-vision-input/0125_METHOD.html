mug-breaks · 生成方法

The animation is generated deterministically by generate.py using only local Python pixel operations and the supplied first_frame.png.

  1. The initial RGB image is loaded at its native 256×144 resolution. Frame 00 is an untouched array copy of that image.
  2. The mug is isolated inside a measured 26×31 crop by its warm yellow-versus-blue color contrast. Morphological closing joins the ceramic body, and a lightly feathered alpha edge retains the source blur.
  3. The original mug footprint is removed with OpenCV Telea inpainting over a tightly dilated local mask. A fixed-seed sub-pixel-strength grain is added only inside that footprint so the repaired projection screen remains consistent with the photographed texture.
  4. Frames 01–05 affine-warp the actual mug RGB pixels along an accelerating downward path. Rotation increases during the fall, vertical motion blur increases with speed, and a soft contact shadow strengthens as the mug approaches the block. Frame 05 adds two one-pixel crack accents at contact.
  5. For frames 06–19, mutually exclusive source-space polygon masks partition the same mug pixels into left body, right body, rim, handle, and two smaller chips. These masks follow hand-timed ballistic paths with outward velocities, gravity-like vertical arcs, short damped bounces, rotation, and stable resting positions. Four tiny ceramic-colored particles supplement the masked shards.
  6. The camera and every background element remain fixed. No external image, model, engine, reference, or network source is used.
  7. artifact_io.save writes the packed uint32 0xRRGGBB tensor, PNG sequence, inspection sheet, and standalone player. transition_check.png is generated as labeled adjacent-frame difference heatmaps, and a final verification checks all PNGs against the tensor.

The generated sequence is 20 frames at 4 fps (5 seconds), RGB, 256×144.
