+def smoothstep01(v: np.ndarray) -> np.ndarray:
+    """Cubic 0..1 easing, used only to feather an antialiased silhouette."""
+    v = np.clip(v, 0.0, 1.0)
+    return v * v * (3.0 - 2.0 * v)
+

+def ellipse_alpha(
+    xx: np.ndarray,
+    yy: np.ndarray,
+    cx: float,
+    cy: float,
+    rx: float,
+    ry: float,
+    inner: float,
+    outer: float,
+) -> np.ndarray:
+    radius = np.sqrt(((xx - cx) / rx) ** 2 + ((yy - cy) / ry) ** 2)
+    return smoothstep01((outer - radius) / (outer - inner))

+def translate(array: np.ndarray, dx: float, dy: float, interpolation: int) -> np.ndarray:
+    """Subpixel translation with a zero border, suitable for masks/layers."""
+    matrix = np.float32([[1.0, 0.0, dx], [0.0, 1.0, dy]])
+    return cv2.warpAffine(
+        array,
+        matrix,
+        (W, H),
+        flags=interpolation,
+        borderMode=cv2.BORDER_CONSTANT,
+        borderValue=0,
+    )

OBSERVATION.md

Scene observation and event plan

Locked scene measurements

  • Source: first_frame.png, RGB, 256 × 144.
  • Camera: static, wide, low tabletop view; no camera motion or cuts are permitted.
  • Background: mustard-yellow sofa occupies the upper half; the coffee table occupies most of the lower half. Lighting is soft and constant.
  • Table: light laminated wood. Its rear edge is near y=65–68. The visible right edge is a diagonal running approximately from (220, 64) to (255, 134). At the ball's travel height (center y≈76), the usable tabletop ends near x=226.
  • Pipe: dark/black pipe assembly is partially cropped at the far left, around x=0–16 and y=46–79; it remains static.
  • Ball in frame 00: blue-grey tennis ball, approximately x=101–119 and y=68–84, with center near (109, 76), radius about 8 px. It is already on the table and moving away from the left-side pipe.
  • Motion constraint: continue the observed state rather than teleporting the ball back into the pipe. The ball follows the tabletop toward screen-right, staying around y=76 and reaching the right lip at the end.

METHOD.md

Method

This continuation is produced entirely by generate.py with local Python pixel operations (NumPy, Pillow, and OpenCV). No external model, engine, image, mask, or scene reference is used.

  1. The source frame is loaded as RGB and retained unchanged as frame 00.
  2. The source ball is measured at approximately center (109, 76), with an 8–9 px radius. Analytic feathered ellipses describe its visible silhouette and shallow contact shadow.
  3. A clean tabletop plate is reconstructed only within the original ball/shadow footprint using OpenCV's local Telea inpainting. Pixels outside this small mask remain bit-exact source pixels.
  4. The ball's appearance comes from the source pixels. Broad shading and the highlight stay fixed in screen/world lighting; only fine spatial detail is rotated according to traveled arc length. This gives a subtle rolling cue without rotating the illumination.
  5. The ball and its source-derived contact shadow are translated at subpixel precision across the tabletop. Centers advance from x=109 to x=219 at y=76, almost uniformly, with mild frictional slowdown in the last three frames. Each output frame is composed independently from the clean plate, preventing trails or cumulative resampling.
  6. artifact_io.save writes the PNG sequence, packed tensor, inspection sheet, and standalone player. transition_check.png is a programmatically generated difference diagnostic. The generator then reloads every PNG and pixels.npz, verifying exact agreement with the uint32 0xRRGGBB tensor and exact equality between frame 00 and first_frame.png.

No later output was visually reviewed with an image-viewing tool; quality control uses local code and numeric measurements only.
