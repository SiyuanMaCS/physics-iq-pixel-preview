glass-stays-same · 生成方法

The sequence is an exact static hold of the supplied source image.

generate.py reads first_frame.png as an RGB uint8 array and repeats that array 20 times along the time axis. This is deliberate: the prompt specifies a locked-off, constant-framerate shot with the dispenser stationary over an already half-filled glass, and it describes no pouring, tap actuation, fill change, object motion, camera motion, or lighting change. Introducing any such change would add an action absent from the prompt.

The generated duration is 20 frames at 4 fps (five seconds). artifact_io.save packs RGB pixels to uint32 0xRRGGBB, transposes them to the required 144 x 256 x 20 tensor, and writes pixels.npz, the PNG frames, the inspection contact sheet, and the standalone HTML player. Afterward, frame 00 is copied from the source file byte-for-byte so it is both file-identical and pixel-identical to first_frame.png.

transition_check.png is produced analytically. Its upper row contains frames 00, 09, and 19; its lower row contains eight-times-amplified absolute differences from each selected frame's predecessor (with a black baseline under frame 00). All differences are zero, as required for the stationary hold.

The generator verifies:

  • exact shape (20, 144, 256, 3) and uint8 RGB type;
  • frame 00 equals the source pixels and source PNG bytes;
  • every frame equals frame 00;
  • every saved PNG decodes to its corresponding generated array;
  • pixels.npz has uint32 shape (144, 256, 20) and exactly matches the generated 0xRRGGBB values.

No external assets, models, masks, engines, or references are used. No later output was visually inspected; output review is performed through array equality, hashes, shapes, dtypes, and per-frame numeric differences.
