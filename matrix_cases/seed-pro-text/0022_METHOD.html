+def build_seam_points(theta):
+    """Front-hemisphere projected tennis seam (Viviani curve), spun clockwise
+    by theta about the view axis (no-slip roll to the right)."""
+    a = 0.5
+    t = np.linspace(0.0, 4.0 * math.pi, 1440, endpoint=False)
+    X = a * (1.0 + np.cos(t))
+    Z = a * np.sin(t)
+    Y = 2.0 * a * np.sin(t / 2.0)
+    # tilt the sphere so seam arcs meet near the left/right limbs
+    beta = -3.0 * math.pi / 8.0
+    cb, sb = math.cos(beta), math.sin(beta)
+    Xp = X * cb + Z * sb
+    Zp = -X * sb + Z * cb
+    front = Zp >= 0.0
+    u0, v0, z0 = Xp[front] / 1.0, Y[front] / 1.0, Zp[front]
+    # visible-face spin: clockwise in screen coords (top moves right)
+    c, s = math.cos(theta), math.sin(theta)
+    u = u0 * c - v0 * s
+    v = u0 * s + v0 * c
+    return u, v
+
+
+def seam_distance(U, V, su, sv):
+    """Distance from points (U,V arrays) to the seam polyline (chunked)."""
+    pts = np.stack([su, sv], axis=1)
+    seg = np.diff(pts, axis=0)
+    length2 = np.sum(seg ** 2, axis=1)
+    out = np.full(U.shape, 1e9)
+    flatU, flatV = U.ravel(), V.ravel()
+    for i0 in range(0, len(flatU), 4096):
+        u = flatU[i0:i0 + 4096][:, None]
+        v = flatV[i0:i0 + 4096][:, None]
+        p = pts[:-1][None, :, :]
+        tt = np.clip(((u - p[:, :, 0]) * seg[None, :, 0]
+                      + (v - p[:, :, 1]) * seg[None, :, 1]) / length2[None, :],
+                     0.0, 1.0)
+        qx = p[:, :, 0] + tt * seg[None, :, 0]
+        qy = p[:, :, 1] + tt * seg[None, :, 1]
+        d = np.min(np.hypot(u - qx, v - qy), axis=1)
+        out.ravel()[i0:i0 + 4096] = d
+    return out

METHOD.md

METHOD — case_0022

Task

Locked-off, fixed-frame, real-time (5 s, 4 fps, 20 frames, 256×144) shot of a grey tennis ball rolling out of a black pipe at the left end of a light wood coffee table and crossing the whole tabletop toward the right. Frame 00 is the provided first_frame.png; the ball is not visible in it (still inside the pipe).

Scene measurement (numeric only)

first_frame.png was inspected exclusively with local Python (numpy/PIL): per-pixel RGB statistics, row/column extents, and ASCII luminance/colour-class maps printed to the terminal. No image Read/View tool was used.

Findings (full details in OBSERVATION.md):

  • Black pipe = near-black circular end at x 0–28, y 71–99, centre ≈ (13.5, 85), outer radius ≈ 14; the right rim of the mouth is the dark column at x ≈ 25; bluish-grey mouth interior centred ≈ (18, 83). Pipe axis (travel line) is horizontal, y ≈ 84–86.
  • Coffee table = neutral light surface (R≈G≈B ≈ 132–160) filling the foreground; along the travel line, y 84–97, x 32–205, mean ≈ (140→151, 138→148, 133→144) with per-pixel std ≈ 8–16.
  • A static near-black furniture block occupies the background at x ≈ 208–256, y ≈ 42–82; the ball track stays just below its diagonal lower edge.

Generation method (generate.py)

Every frame is built from a fresh, exact copy of frame 00, so the wall, table, pipe and background furniture are pixel-static (matching the locked-off brief); the only changes are the ball and its contact shadow, and the original table texture is restored behind it each frame.

  1. Motion physics. Constant-velocity roll on a flat tabletop (no deceleration assumed; the shot covers a smooth hard surface): centre x(f) = 30.0 + 11.83·(f−1), y = 86, radius r = 5.2 px (47.3 px/s ≈ 4.5 diameters/s; ≈ 7.2 rotations over the clip). At f = 19 the centre is x ≈ 243, still on the table.
  2. Emergence. Frame 01 is hard-clipped at the mouth rim x = 25.5, so only the crescent of the nose that has left the pipe is drawn; the part still in the dark mouth stays hidden. From frame 02 onward the full ball is visible.
  3. Ball rendering (analytic, 5×5 sub-pixel supersampling).
    • Sphere shading from a fixed upper-right key light (Lambertian diffuse, ambient 0.42) on neutral grey felt (146,148,144).
    • Tennis-ball seam from a Viviani curve on the unit sphere (x = ½(1+cos t), z = ½ sin t, y = sin(t/2)), tilted −3π/8 about the vertical axis so the two arcs meet near the limbs; back-hemisphere points are culled, and each sample is blended toward a darker seam grey by its point-to-polyline distance. The visible face then spins about the view axis by θ = distance/r radians per frame (no-slip rolling).
    • Low-amplitude two-octave hash mottling in the ball's rotating frame for felt texture, and a faint light nap ring hugging the silhouette.
  4. Contact shadow. A soft multiplicative elliptical shadow (semi-axes 1.18r × 0.40r, Gaussian falloff, max darkening 32%) just under the ball, clipped at the rim in frame 01.
  5. Outputs. Frames are saved through the provided artifact_io.save, which writes pixels.npz (uint32 0xRRGGBB tensor, shape 144×256×20), frames/00.png–19.png, inspection.png, and the standalone index.html player. A separate transition_check.png overlays ball positions on frame 00 and shows per-frame red change masks versus frame 00.

Verification (numeric)

  • frames/00.png is byte-identical to first_frame.png (np.array_equal → True).
  • All 20 PNGs, when packed as (R<<16)|(G<<8)|B, exactly equal the stored pixels.npz tensor (all 20 match).
  • Replaying the run-length delta streams in index.html with a numpy reimplementation of the player's decoder reproduces all 20 tensor frames exactly.
  • Per-frame change masks against frame 00 stay inside the expected moving footprint (bbox y 80–94, ~186–190 px/frame); frame 01's bbox starts at the rim x = 25. Centre positions advance monotonically, ~11.8 px/frame.
  • Ball silhouette (round, diameter ≈ 10–11 px) and seam/shadow were checked frame by frame via terminal luminance grids.

Assumptions / limitations

  • Constant rolling speed with negligible friction over the 5 s clip.
  • Travel line is horizontal at y = 86 (constant depth → constant apparent size), consistent with the pipe axis; the ball ends at x ≈ 243, still on the tabletop rather than leaving frame.
  • Ball radius 5.2 px is inferred from the ~13 px pipe mouth opening.
  • All visuals are local analytic pixel operations; no external models, engines, references or image-viewing tools were used.
