METHOD — case_0047

Pipeline overview

  1. Build a clean background plate (wood + mug with the liquid undisturbed and no tool/domino/streak).
  2. Extract RGBA sprites (left rod, right rod/finger, domino, liquid streak) by plate-relative colour distance with un-blended object colours.
  3. Compose 20 frames: plate → moving reflection → splash/ripples → domino → re-posed rods. Frame 00 is the untouched input PNG (asserted np.array_equal).

1. Clean plate (build_plate)

Mask union from strict colour rules inside tight geometric boxes (so the shaded wood gap between the prongs is never consumed):

  • rods: not "wood-like" (r>95 and r-b>15) inside left (y0–23, x107–124), upper-right (y0–16, x133–149) and bent-finger (y15–23, x123–138) boxes;
  • domino: b>150, g>145 in y17–46, x122–135;
  • liquid reflection streak: b>105, b>r+22 in y45–66, x123–136;
  • 3×3 dilation, then a bootstrap Telea inpaint and a second pass that adds pixels differing from the bootstrap by >28 (RGB L1), excluding wood-like pixels.

Filling (Telea alone failed: it pulls bright lit wood into the shaded gap and collapses the dark liquid to black):

  • Wood band y<38: every masked run is re-filled per row by 1-D linear interpolation between its unmasked anchor pixels (same row), which preserves the local shade (bright lit wood vs. the greyer gap wood) instead of Telea's over-saturated tan.
  • Mug band y≥38: rows 38–45 across the rim use the same 1-D row interpolation; liquid rows use a symmetric radial fit about x=131 — both mirrored samples at ±k must be clean, a distance-weighted line is fitted to their average, and the fill is evaluated at |x−131| (this kills one-sided navy/dark-red bias). A 3×3 median plus σ=0.9 Gaussian is applied inside the eroded fill mask only.
  • Grain: wood residuals (image − σ≈5 Gaussian) are copied from clean donor pixels ≥3 px inside the clean region, clipped to ±10; the mug fill gets zero-mean Gaussian noise scaled to 0.55× the local clean residual std per channel.

Plate liquid interior then matches the measured original (mean RGB ≈ (34,6,4) vs (33,6,4); the liquid is genuinely a warm near-black, median (36,6,3)).
