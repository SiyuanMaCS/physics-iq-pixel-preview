ball-hits-duck · 生成方法

Overview

The 20-frame animation shows a brown tennis ball rolling out of a black pipe, across a beige coffee table, and hitting a yellow rubber duck. All work is done in pure Python using numpy, PIL/Pillow, and scipy.ndimage — no external engines, AI models, or network access.

Scene Analysis

The scene was measured from first_frame.png using numeric RGB inspection (no image viewing tools). Key elements:

Element Location Method
Coffee table y=55–120, beige (R~125–148) Mean color analysis per row
Black pipe x=0–18, y=40–57, dark Dark pixel clustering on left edge
Yellow duck x=182–205, y=46–67, bright yellow Color threshold (R>100, G>60, B<0.6R)
Couch (bg) y=0–36, mustard yellow Color threshold (R>60, B<10)

Frame Generation

Frame 00

Exact byte-for-byte copy of first_frame.png. Verified via np.array_equal.

Frames 01–10: Ball Rolling

  • Starting position: Ball emerges from pipe exit at x≈18, y≈53.
  • Trajectory: Straight horizontal line at y=57 (table surface).
  • Speed: Approximately 16 px/frame (constant velocity across table).
  • Drawing method: Anti-aliased circle with radius 6 pixels drawn via numpy.
    • Interior pixels: solid brown RGB(145, 93, 38).
    • Edge pixels: alpha-blended with background for smooth edges.
    • Seam lines: Two orthogonal great-circle arcs drawn in light beige RGB(225, 210, 175).
    • Seam rotation: Δθ = Δx / radius (rolling without slipping). Accumulated distance tracked across frames.

Frames 11–19: Duck Impact and Reaction

  • Contact: Ball center reaches x=176 (ball right edge at 182 touches duck left edge).
  • Ball deceleration: Ball slows from 16 px/frame to ~1 px/frame after impact.
  • Duck rotation:
    • Extracted from frame 00 using color segmentation (yellow + beak orange).
    • Mask dilated once with scipy.ndimage.binary_dilation to include soft edges.
    • Rotated around base pivot (x=193.5, y=67) using scipy.ndimage.affine_transform.
    • Rotation matrix: CCW in math coordinates = right-tilt in image space.
      • M = [[cos θ, -sin θ], [sin θ, cos θ]] operating on [row, col] indices.
    • Bilinear interpolation (order=1), zero constant fill.
    • Background fill: Duck area replaced with sampled table color + deterministic noise (RandomState(42)) before compositing rotated duck.
