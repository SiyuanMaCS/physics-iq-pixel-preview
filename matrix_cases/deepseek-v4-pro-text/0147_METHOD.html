+def make_tennis_ball(diameter, rotation_angle=0.0):
+    """Create a grey tennis ball sprite with spherical shading and seams."""
+    r = diameter / 2.0
+    # Coordinate grid centered on ball
+    yy, xx = np.mgrid[-r:r, -r:r]
+    dist = np.sqrt(xx**2 + yy**2)
+    
+    # Alpha mask (1 inside circle, 0 outside with soft edge)
+    alpha = np.clip((r - dist) / 1.5, 0.0, 1.0)
+    
+    # Base grey color
+    sprite = np.zeros((diameter, diameter, 3), dtype=np.float64)
+    
+    # Spherical shading: dot product with light direction (from top-left)
+    # Light direction: normalize(-1, -1, 2) ~ light from upper-left-front
+    lx, ly, lz = -0.4, -0.4, 1.0
+    lnorm = np.sqrt(lx**2 + ly**2 + lz**2)
+    
+    # For pixels inside the sphere, compute z-coordinate of surface
+    z_surface = np.sqrt(np.maximum(0, r**2 - xx**2 - yy**2))
+    dot = np.clip((lx * xx + ly * yy + lz * z_surface) / (r * lnorm), 0.0, 1.0)
+    
+    # Ambient + diffuse
+    ambient = 0.25
+    diffuse = 0.55
+    specular_power = 16
+    # Specular highlight (Phong)
+    # View direction is (0, 0, 1)
+    # Half vector
+    hx, hy, hz = lx / lnorm, ly / lnorm, (lz / lnorm + 1.0)
+    hnorm = np.sqrt(hx**2 + hy**2 + hz**2)
+    hx, hy, hz = hx / hnorm, hy / hnorm, hz / hnorm
+    spec_dot = np.clip(hx * xx / r + hy * yy / r + hz * z_surface / r, 0.0, 1.0)
+    specular = 0.20 * (spec_dot ** specular_power)
+    
+    shade = np.clip(ambient + diffuse * dot + specular, 0.0, 1.0)
+    
+    # Apply to ball
+    for c in range(3):
+        sprite[:, :, c] = BALL_COLOR[c] * shade

Rendering approach:

  1. Start from exact copy of first_frame.png for every frame.
  2. Procedurally generate grey tennis ball sprite (14 px diameter) with:

    • Fresnel-like rim light for edge definition
    • Two great-circle tennis ball seams, rotating with rolling motion
    • Soft antialiased alpha edge
  3. Tube occlusion: per-pixel mask suppresses ball pixels to the left of the cylindrical tube opening with 3-px soft transition (frames 0–2).
  4. Drop shadow: soft elliptical shadow composited below the ball (opacity 0.45).
  5. Alpha-composite ball on top.

METHOD.md

Method — case_0147

Approach

Local Python pixel operations (NumPy + PIL). No external models, engines, or network.

Algorithm

  1. Scene analysis: Loaded first_frame.png, measured object positions via numeric RGB inspection. Black tube: left side cols 0–30, rows 0–55. White lampshade: cols 75–142, rows 20–110. Wooden table: warm brown, full width from row ~10.

  2. Ball sprite: Procedural 14-pixel-diameter grey tennis ball with:

    • Spherical Blinn-Phong shading (ambient + diffuse + specular), light from upper-left
    • Fresnel-like rim light for edge definition
    • Two great-circle seam lines (tennis ball pattern) that rotate with rolling motion
    • Soft antialiased edges via distance-based alpha falloff

  3. Motion: Constant horizontal velocity 12 px/frame at row 42 (tube center height). Ball travels from x=10 (frame 0, inside tube) to x=238 (frame 19, near right edge).

  4. Tube occlusion: For frames 0–2, per-pixel tube mask suppresses ball pixels to the left of the cylindrical tube opening boundary, with soft 3-pixel transition zone.

  5. Drop shadow: Soft elliptical shadow composited under the ball (opacity 0.45, offset 3 px below ball center) for grounding on the table surface.

  6. Compositing: Standard alpha blending. Frame 0 verified pixel-identical to input.

Dependencies

Python 3, NumPy, PIL (Pillow). No network, external models, or subagents.
