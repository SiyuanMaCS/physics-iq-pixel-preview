METHOD.md

METHOD.md — Technical Approach

Overview

This artifact set generates a 20-frame animation (256×144 RGB, 4 fps, 5 seconds) of a grey tennis ball emerging from a black pipe, rolling across a wooden table, and impacting a 30lb kettlebell. All generation is done via local Python pixel operations — no external engines, AI models, or network access.

Scene Analysis

The initial frame (first_frame.png) was analyzed purely through numeric RGB inspection in NumPy. Key measurements:

  • Pipe interior: cols 0–17, rows 22–49 (very dark, RGB < 15)
  • Kettlebell (30lb): cols 17–154, rows 28–66 (medium grey, RGB 70–140)
  • Yellow duck: cols 200–220, rows 47–66 (yellow, R>150, G>130, B<60)
  • Table surface: rows 48–120 (light warm grey, RGB 140–156)

Object boundaries were determined by color-range thresholding and run-length analysis across rows and columns.

Frame Generation Method

Technique: Alpha-composited sprite over static background

  1. Base frame: first_frame.png loaded as a NumPy uint8 array (144, 256, 3).
  2. Ball sprite: Programmatically generated as a radial-gradient circle using NumPy meshgrid distance fields.
    • Radius: 5 px (10 px diameter)
    • Center color: RGB(190, 185, 175) — lighter grey
    • Edge color: RGB(85, 80, 70) — darker grey for outline contrast
    • Soft alpha feather at the outer 25% of the radius for anti-aliased compositing
  3. Compositing: Standard alpha blending (result = sprite_rgb * alpha + background * (1 - alpha)) at sub-pixel placement.

Motion Path

Ball center positions are defined via keyframes indexed by frame number:

Frames Motion
00 Hidden inside pipe
01–03 Emerging from pipe opening (col 12→25)
04–07 Rolling right toward kettlebell (col 29→38)
08 Impact — ball contacts kettlebell at col 39, row 43
09 Rebound with horizontal squash (0.7× width, 1.3× height)
10–13 Bouncing back leftward (col 34→22)
14–19 Ball at rest near pipe exit (col 19–16)

The ball travels approximately 27 px horizontally (col 12→39) over 1.75 seconds, then rebounds. The kettlebell (30lb) is too heavy for visible displacement at this resolution — the ball bounce alone communicates the impact.

Impact Deformation

Frame 09 applies an elliptical squash transform: the ball sprite is rendered with squash_x=0.7, squash_y=1.3, producing a vertically elongated shape that simulates compression on impact before rebound.

Output Verification

  • Frame 00: Asserted identical to first_frame.png via np.array_equal.
  • All PNGs: Re-read from disk and compared against in-memory arrays.
  • pixels.npz: Stored as uint32 0xRRGGBB packed values; verified round-trip match against PNG files.
  • inspection.png: 4×5 contact sheet grid (1280×576) of all 20 frames for visual scan.
  • transition_check.png: Side-by-side display of frames 07–11 with inter-frame difference maps (amplified 5×) showing the impact transition.

Dependencies

  • Python 3 with NumPy and Pillow (PIL)
  • No external models, network calls, or subprocess agents
