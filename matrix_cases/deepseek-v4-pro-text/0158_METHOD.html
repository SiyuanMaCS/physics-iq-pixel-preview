METHOD.md

METHOD.md — Case 0158: Silk Fabric Covering Teapot

Summary

A crimson silk fabric descends from above and drapes over a blue ceramic teapot on a wooden table. The animation runs for 5 seconds at 4 fps (20 frames, 256×144 RGB).

Technique

Approach

Pure pixel-level compositing with procedural texture generation. No external AI models, physics engines, or image inpainting tools were used. All pixel operations are deterministic NumPy array computations.

Steps

  1. Scene Measurement (OBSERVATION.md): The first frame was analyzed by reading RGB values at grid positions to locate the teapot body (ellipsoid centered at x=141, y=84 with radii rx=36, ry=28), the spout (white, x=45-80, y=5-75), the handle (right side), the wooden table (below y≈79), and the background wall.

  2. Teapot Mask Generation: Three masks are precomputed for the areas where fabric drapes differently:

    • Teapot body: An ellipsoid distance field using the measured center and radii
    • Spout region: Elliptical mask on the left side
    • Handle region: Rectangular mask on the right side

  3. Procedural Silk Texture: Each pixel's fabric color is computed from:

    • Fold texture: Sinusoidal horizontal draping folds with secondary fine wrinkles and edge-bunching modulation
    • Teapot highlight: Where fabric covers the teapot body, a specular highlight proportional to 1 - distance_from_center simulates fabric stretched tight over the curved ceramic surface
    • Color mapping: Brightness values (0-1) are mapped through a 3-point RGB ramp: SHADOW (dark crimson) → BASE (crimson) → HIGHLIGHT (bright warm red)

  4. Frame Animation:

    • Frame 0: Unmodified first_frame.png
    • Frames 1-19: The fabric bottom edge descends from y=-15 to y=155 using cubic ease-out easing (t = 1 - (1 - raw_t)³)
    • The bottom edge follows a sinusoidal wave profile for realistic draping
    • A 2-pixel soft transition zone blends fabric with background at the moving edge
    • Frames 14-19 add subtle settling (shadow deepening in fold valleys only)

  5. Output Generation:

    • 20 RGB PNG frames (256×144)
    • pixels.npz: uint32 packed tensor (0xRRGGBB format, shape H×W×20)
    • inspection.png: 8-keyframe grid sheet
    • transition_check.png: Horizontal strip stack showing temporal continuity
    • index.html: Standalone HTML player with delta-compressed frame data

Tools Used

  • Python 3.11, NumPy, PIL/Pillow
  • Standard library: base64, json, pathlib

Verification

  • Frame 0 byte-identical to first_frame.png
  • All 20 frames individually verified against the uint32 packed tensor
  • Tensor roundtrip verified: PNG → pack → tensor → unpack → PNG
  • No pixel recession (covered area only grows, never shrinks)
  • 100% frame coverage by final frame
