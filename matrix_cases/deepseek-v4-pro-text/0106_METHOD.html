METHOD.md

METHOD.md — Marble Run Animation (case_0106)

Method Overview

This animation simulates a yellow glass marble sliding down magnetic ramps attached to a whiteboard. The 20-frame sequence (4 fps, 5 seconds) was generated using local Python pixel operations based on analysis of first_frame.png and the scene description in prompt.txt.

Scene Analysis

Measurements from first_frame.png

  • Dimensions: 256×144 pixels
  • Whiteboard background: RGB(156, 148, 143) ± 4, warm off-white
  • Left frame edge: Dark vertical band at x≈30–42, RGB ~20–40
  • Magnetic ramps: Amber-brown diagonal bands across the whiteboard, sloping down-right
  • Yellow glass marble (frame 0):
    • Center: (y=53.5, x=68.0)
    • Core color: RGB(130–141, 110–140, 20–44) — bright yellow-green glass
    • Radius: ~9 pixels

Ramp Geometry

The ramp surface forms a diagonal plane sloping at approximately 30° from horizontal, running from the upper-left toward the lower-right of the whiteboard. The marble slides along this surface under gravity.

Generation Technique

1. Marble Extraction

  • Identified the marble using strict color thresholds on the bright yellow-green glass pixels
  • Located the marble core center of mass: (y=53.5, x=68.0)
  • Created a circular alpha mask around the marble (radius ~9 px) with soft edges (1–2 px feather)

2. Background Clean Plate

  • Inpainted the marble's starting area using distance-weighted color sampling from surrounding non-marble pixels
  • Applied a light Gaussian blur (radius=1.5) to the inpainted region, feather-blended with the surrounding area
  • This provides a clean background for compositing the marble at new positions

3. Physics Simulation

  • Model: Frictionless sliding on an inclined plane
  • Ramp angle: θ = 30° from horizontal
  • Acceleration along ramp: a = 8.8 px/s² (calibrated so the marble travels ~100 px over 5 seconds)
  • Equation: s(t) = ½·a·t² (constant acceleration from rest)
  • Trajectory: The marble follows a straight diagonal path down-right along the ramp direction

4. Frame Rendering (20 frames)

  • Frame 0: Exact copy of first_frame.png (verified pixel-identical)
  • Frames 1–19:
    • Start from the clean background plate
    • Composite the marble at the computed position using the circular alpha mask with smooth alpha blending
    • Add motion blur streaks for frames where displacement > 1.5 px (renders ghost copies at intermediate positions with fading opacity)

5. Motion Blur

  • When the marble displacement between consecutive frames exceeds 1.5 pixels, intermediate ghost copies are rendered along the motion path
  • Each ghost has opacity α = 0.35 × (1 − i/(n+1)), creating a smooth fade trail
  • This simulates the temporal integration of a real camera's finite exposure

Output Verification

  • frames/00.png matches first_frame.png with zero pixel difference (max diff = 0)
  • pixels.npz contains the full 20-frame tensor as uint32 RGB packed values (144×256×20)
  • inspection.png shows frames 0, 2, 5, 8, 11, 14, 17, 19 in a grid
  • transition_check.png overlays the full trajectory on frame 0
  • index.html provides a standalone interactive player

Tools Used

  • PIL/Pillow for image I/O and Gaussian blur
  • NumPy for all pixel operations, math, and array manipulation
  • artifact_io.py (provided) for output packaging
  • No external AI models, network access, or subprocesses were used
