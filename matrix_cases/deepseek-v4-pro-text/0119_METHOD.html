METHOD.md

METHOD.md

Approach

3D sphere back-projection — The tennis ball is modeled as a sphere of radius 34 px centered at (169, 109) in the 256×144 frame. Frame 0 serves as the ground-truth color source. For each subsequent frame, every pixel in the ball's projected circle is mapped back to its 3D surface point, which is then counter-rotated by the frame's rotation angle to find where that surface point was located in frame 0. The color at that position is sampled via bilinear interpolation and copied to the current frame.

Rotation

Clockwise rotation (as seen from above) at 9° per frame, totaling ~171° over 20 frames. The rotation is applied about the ball's vertical axis (Y-axis in camera space). The back-projection uses:

dx0 = dx·cos(α) + dz·sin(α)
dz0 = -dx·sin(α) + dz·cos(α)
dy0 = dy

If the rotated point faces the camera in frame 0 (dz0 > 0), its color is sampled directly. Otherwise, the symmetric front-side point (-dx0, dy0, |dz0|) is used as a fallback, equivalent to mirroring the ball's surface texture across the YZ plane.

Mirror Reflection

The mirror occupies the left portion of the frame (x ≤ 114). Its reflection is rendered using the same back-projection approach, working with a virtual ball image behind the mirror:

  • Virtual ball center: virtual_cx = 2 × MIRROR_EDGE - BALL_CX = 59
  • For each pixel within the frame-0 mirror-ball mask, the corresponding real-ball surface point is found via back-projection through the mirror
  • Key correction: left-hemisphere back-projections (real_dx < 0) map to dark edge pixels in frame 0 (the camera's view). Since the mirror sees these surfaces head-on, they are remapped to their right-hemisphere symmetric equivalents (-real_dx → +|real_dx|) where frame 0 provides properly lit colors
  • A brightness floor (sum < 60) triggers a second sampling attempt slightly closer to the ball center

Background

Static regions (wall, table, platform) are preserved. Ball-affected areas (direct ball circle + mirror ball mask from frame 0) are inpainted using iterative 3×3 convolution smoothing (60 iterations) to provide seamless transitions at the rotating ball's edges.

Limitations

  • Only the front hemisphere of the ball is visible in frame 0; back-hemisphere colors are approximated by mirror symmetry
  • Mirror reflection is masked to the original frame-0 mirror-ball region (preserving occlusion by the table/counter surface)
  • Small brightness variations exist at some mirror pixels where even the corrected back-projection produces dim samples
