METHOD.md

METHOD.md – Case 0021

Approach

Core strategy: Extract the yellow tennis ball from frame 0 as a sprite with alpha mask, inpaint the background behind it, then composite the ball at new positions along the ramp for frames 1–19 using simple kinematics.

Ball Extraction

The ball is identified using a yellowness metric:

yellowness = (R + G - 2*B) / (R + G + B + 1)
  • Core mask: yellowness > 0.35, R > 100, G > 80, B < 90 → alpha = 1.0
  • Edge mask: yellowness > 0.20, R > 85, G > 65, B < 105 → alpha = feathered by yellowness
  • Ball sprite: 18×15 pixels extracted from frame 0

Background Inpainting

The hole left by the ball is filled using vertical column interpolation:

  1. For each column in the ball's x-range, source pixels are found above and below the ball mask
  2. Target pixels are linearly interpolated between the closest above and below source colors
  3. A narrow edge zone (2 px) is blurred with σ=0.8 Gaussian to soften seams

This preserves the ramp's vertical texture while filling smoothly.

Physics Model

The ball rolls along the ramp with:

  • Initial position: center (62.5, 44.5) – from ball mask centroid in frame 0
  • Initial rightward velocity: 22 px/s (from pipe exit)
  • Deceleration: 0.4 px/s² (friction and/or gentle incline)
  • Ramp slope: ~0.012 (nearly horizontal, slight downward to the right)

Kinematics: x(t) = x₀ + v₀·t − ½·a·t², y(x) = y₀ + slope·(x − x₀)

The ball never reaches zero velocity within the 5-second window; it is still rolling at frame 19.

Frame Rendering

For each frame t ∈ [1,19]:

  1. Start from the inpainted background
  2. Composite ball sprite at computed (cx, cy) using pre-multiplied alpha
  3. Clamp to [0,255] uint8

Frame 0 is the unmodified first_frame.png (verified exact match via np.array_equal).

Outputs

  • frames/00.png–19.png – 256×144 RGB PNGs at 4 fps
  • pixels.npz – packed uint32 tensor (144×256×20) per artifact_io spec
  • inspection.png – 8-frame contact sheet
  • transition_check.png – per-frame difference visualization
  • index.html – standalone pixel player
  • generate.py – reproducible generation script
