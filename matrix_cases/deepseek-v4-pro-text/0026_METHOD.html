ball-rolls-on-glass · 生成方法

Approach

Method: Alpha-composited sprite animation with background inpainting and background-subtracted ball extraction.

The scene is a static locked-off shot. Only the blue tennis ball moves; everything else remains unchanged. The clear glass is already present in the static background (frame 0), visible as a subtle darkening of the wall area behind it.

Pipeline

1. Scene Analysis (numeric RGB inspection)

  • Sampled pixel values across the 256×144 frame at regular intervals to identify scene regions.
  • Detected the ball using blue-color dominance (B > R+12, B > G+6) combined with spatial clustering.
  • Located table edge at x≈149 via vertical gradient magnitude (sum |Gx| peak = 2336).
  • Identified glass area as the darker wall region x=150–200 (luminance ~30 lower than bare wall).

2. Background Inpainting

  • Created a binary mask of ball pixels from frame 0 using color + radial distance criteria.
  • Dilated mask by 1 iteration to include edge transition pixels.
  • Filled masked region using k-NN distance-weighted interpolation from boundary pixels (k=16, weights ∝ 1/distance).
  • This produces a clean table surface where the ball was, matching the surrounding wood grain.

3. Ball Sprite Extraction (Background-Subtracted)

  • Extracted a 22×24 sprite region around the ball.
  • Created a feathered radial alpha mask (radius=10px, feather=1.5px).
  • Background-subtracted each sprite pixel: ball_clean = (raw - bg*(1-α)) / α
  • This prevents table-brown color leakage when compositing onto the lighter wall/glass area.

4. Frame Generation (20 frames, 4fps, 5s)

  • Ball center moves from (104.5, 67.5) to (175.0, 67.5) at constant velocity (3.71 px/frame).
  • For each frame: composite ball sprite onto clean background using alpha blending.
  • Frame 0 is overwritten with the exact original first_frame.png.

5. Glass Interaction Effects

  • Ball shadow: When ball center x > TABLE_EDGE_X (149), a soft elliptical Gaussian shadow is rendered beneath the ball on the glass/wall surface. Shadow center is offset (dx=-2, dy=+11) from ball center. Peak darkening ≈12%, sigma_x=13px, sigma_y=5px.
  • The shadow only appears when the ball is over the glass area (verified: zero diffs in wall area when ball is on table).

6. Output Encoding

  • Used artifact_io.save() to produce pixels.npz (uint32 packed RGB tensor), 20 PNGs, inspection.png sheet, and standalone index.html player with delta compression.

Libraries Used

  • NumPy: all array/math operations
  • PIL (Pillow): image I/O
  • SciPy: binary_dilation (morphology), cKDTree (efficient nearest-neighbor for inpainting)
  • artifact_io: output encoding and player generation

Limitations

  • Ball sprite is a single static extraction; no rotation or specular highlight animation.
  • Glass transparency effects are limited to the pre-existing static darkening baked into the background.
  • No physics simulation — pure kinematic translation at constant velocity.
