METHOD.md

METHOD.md — Teapot Clockwise Rotation

Approach

Cylindrical surface unwrap with mask-restricted pixel sourcing. No external models, 3D engines, or network access. Pure local pixel operations.

Algorithm

1. Teapot Mask Creation

  • Compute per-pixel local standard deviation (9×9 window) across RGB channels — captures surface texture
  • Compute color non-neutrality (sum of absolute pairwise channel differences) — distinguishes teapot (strong R≠G≠B) from wall (neutral beige)
  • Combined score = local_std × (neutralness + 10) / 100
  • Threshold at 40, restrict to rows 8–97
  • Morphological close (dilate→erode) to fill gaps
  • Keep only the largest connected component near image center
  • Final dilation to include edge pixels

2. Per-Row Cylindrical Parameters

For each row with mask pixels, compute:

  • Center (cx): median x-coordinate of mask pixels
  • Radius (R): half-width of mask extent + 2px margin

3. Cylindrical Rotation (frames 1–19)

For each output pixel at (x, y) within the teapot mask:

  1. Convert to cylindrical angle: φ = arcsin((x − cx) / R)
  2. Rotate clockwise: φ_src = φ + Δθ (surface at φ_src has rotated to φ)
  3. Map back to source position: x_src = cx + R · sin(φ_src)
  4. If source is beyond visible hemisphere (|φ_src| > π/2), keep original
  5. Bilinear sample from original frame at (x_src, y) — only if source is in teapot mask
  6. If source is not in mask, keep original color

This preserves the teapot silhouette while scrolling the surface texture. Background pixels are never modified — only teapot-mask pixels source from other teapot-mask pixels via cylindrical shift.

4. Frame 0

Exact copy of first_frame.png — verified pixel-identical.

Rotation Direction

Clockwise when viewed from above: the surface texture scrolls right-to-left in the image. The right side of the teapot body (bright bronze highlight) scrolls into the center, while the center (dark reflection) scrolls left toward the spout area.

Parameters

  • Total rotation: 30° over 5 seconds
  • Frame rate: 4 fps
  • Per-frame angular step: 1.58°
  • Resolution: 256×144 RGB uint8
  • Frame 0: exact copy of input

Verification

  • Frame 0 byte-identical to first_frame.png
  • Background pixels unchanged across all frames
  • Platform and table regions unchanged
  • Only teapot mask pixels modified
  • Smooth frame-to-frame transitions (7–11% pixels changed per step)
  • All 20 frames valid uint8 RGB (144×256×3)
