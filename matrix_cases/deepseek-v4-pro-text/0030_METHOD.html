ball-train · 生成方法

Approach

Pixel-level compositing with inpainting and simple elastic collision physics. All rendering done with NumPy array operations and PIL for PNG I/O.

Scene Analysis

  • Table: Light grey gradient surface (RGB ~100–150) filling most of the 256×144 frame.
  • Black pipe: Dark structure in top-left (x:0–30, y:0–44), opening at x≈80–96, y≈44–58 with blue-ish specular highlight.
  • Brown tennis ball: Center (121, 55), radius ~7.5 px, RGB ~45–65/25–45/15–35.
  • Orange tennis ball: Center (135, 57), radius ~7.5 px, RGB ~150–230/100–140/60–100.
  • Grey tennis ball: Generated synthetically with 3D Phong-like shading, seam line, and slight texture at same scale.

Frame Generation Method

Frame 00

Exact byte copy of first_frame.png.

Clean Background

Iterative inpainting (10 iterations of 8-neighbor averaging) fills the original brown/orange ball regions. This creates a smooth table surface for the "erase" step.

Ball Templates

  • Brown/orange: Extracted from frame 00 as RGBA templates with feathered alpha edges (1.5 px feather radius). Pixels inside ball radius have alpha=1.0; pixels in the feather band blend from 1.0→0.0; everywhere else alpha=0.
  • Grey: Procedurally generated with:
    • Sphere normals for diffuse lighting (light from upper-left)
    • Specular highlight (Blinn-Phong, exponent 25)
    • Ambient term (0.28)
    • Tennis ball seam line (narrow band near equator)
    • Subtle sinusoidal texture variation

Frame Rendering (frames 01–19)

For each frame:

  1. Start from first_frame.png (preserves pipe, table edges, and all static details exactly).
  2. If the brown ball has moved >1 px from its original position, erase its original footprint by replacing those pixels with the inpainted clean background.
  3. Same for orange ball.
  4. Composite balls at their physics-computed positions using alpha blending (back-to-front: orange → brown → grey).
  5. For grey ball emergence (frames 01–02): clip rendering at x ≤ 86 to simulate occlusion by the pipe opening.

Physics Simulation

  • Grey ball: Constant velocity 6.0 px/frame (24 px/s at 4 fps) from pipe exit (86, 50). Visible starting frame 01.
  • Collision: Detected when grey–brown center distance < 14 px (2× radius). Equal-mass elastic: grey stops, brown receives ~80% of grey's velocity (some energy loss).
  • Brown–orange push: Brown pushes orange when overlapping. Brown retains 35% velocity, orange receives 65%.
  • Friction: 0.95 multiplier per frame on all velocities post-collision.
  • Timeline: Grey emerges frames 01–04, contacts brown frame 05, post-collision settling frames 06–19.

Pipe Occlusion

Grey ball emergence simulated by clipping composite to world-x ≥ 86 (pipe exit plane) while gx < 86 + ball_radius.

Output Verification

  • Frame 00 pixel-identical to first_frame.png (max diff = 0).
  • All 20 PNGs match pixels.npz uint32 0xRRGGBB tensor.
  • Stable background region (x:0–70, y:44–60) unchanged across all frames.
  • All frames 256×144 RGB.
