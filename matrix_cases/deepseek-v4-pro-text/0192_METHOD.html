Technical Approach

METHOD.md

Method

Overview

The 20-frame animation shows a 30lb cast-iron kettlebell crushing a white styrofoam cup on a wooden table. All frames are generated using pure Python pixel operations (NumPy/PIL) with no external models, engines, or network access.

Scene Segmentation

Three region masks are extracted from first_frame.png:

  1. Kettlebell mask: Pixels with RGB < (35,35,35), flood-filled from the image top to isolate the connected kettlebell component. Bounding box: y=[0,68], x=[107,182].

  2. Cup mask: Pixels with brightness > 105, R > 95, G > 75, B > 45, and (R-B) < 105, restricted to the region below the kettlebell (y ∈ [63,93], x ∈ [92,196]).

  3. Clean background: Both kettlebell and cup regions are inpainted via horizontal linear interpolation from the nearest non-masked neighbors in each row, creating a "clean plate" of the table and backdrop.

Physics Model

The crush dynamics are modeled as a piecewise function of time t (seconds):

Phase Time (s) Description
Elastic 0.00–0.25 Cup barely yields (~3% compression). Kettlebell drops ~0.5 px.
Plastic collapse 0.25–0.75 Rapid crushing. Compression follows smoothstep from 3% to 88%. Kettlebell accelerates downward to ~12 px.
Damped oscillation 0.75–2.50 Exponentially decaying sinusoidal oscillation (amplitude ~6% of cup height, frequency ~2.25 Hz) around 88% compression.
Static 2.50–5.00 Final stable state at 89% compression. Kettlebell at ~12.5 px below original position.

Kettlebell displacement is proportional to cup compression with slight inertial lag/overshoot.

Frame Rendering Pipeline

For each frame t ∈ {1,...,19}:

  1. Start from clean background: Begin with the inpainted plate (no kettlebell, no cup).

  2. Render compressed cup: For each column x in the cup mask, the original cup pixel column (height h) is vertically scaled by factor (1 - comp·0.96) and placed with its bottom near the original cup-base y-coordinate (plus a small downward shift from material spreading). Bilinear interpolation samples source pixels.

  3. Horizontal bulge: Cup-like pixels (brightness > 90, R > 85, R-B < 110) are displaced horizontally outward proportional to compression, distance from cup center, and vertical position within the cup (maximum displacement at mid-height). Displacement is sampled from the source image via bilinear interpolation.

  4. Translate kettlebell: Kettlebell pixels from the source image are copied to their new position (y + drop, x). Sub-pixel vertical blending between adjacent rows is applied using the fractional part of drop.

  5. Ghost cleanup: Dark pixels (RGB < 35) in the old kettlebell region that are not part of the translated kettlebell are replaced with clean background pixels.

  6. Styrofoam debris: Random white/cream particles (RGB 185–245, 165–225, 130–200) are alpha-blended near the cup edges. Particle count scales with compression (20–85 particles per frame during active collapse). Approximately 25% of particles spawn a neighboring debris pixel for clustering.
