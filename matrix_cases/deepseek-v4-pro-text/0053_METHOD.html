METHOD.md

METHOD.md — Newton's Cradle Animation

Approach

The animation is generated using a physics-based simulation with pixel compositing. The first frame (first_frame.png) is used as-is for frame 00. For frames 01–19, a clean background is created by removing the blue-black grabber tool and the two held balls, then procedurally rendered metallic balls and strings are composited on top at pendulum-computed positions.

Scene Analysis

  • The 256×144 image was analyzed via numeric RGB inspection (no image viewing tools).
  • Key measurements were extracted: ball pivot positions (x=[88,100,127,141,152], y=93), string length (18 px), ball radius (~8.5 px), and grabber extent (x=40–105, y=74–105).
  • The amplitude angle θ₀ was computed from the held-ball offset relative to the pivot: cos(θ₀) = 2/18 → θ₀ ≈ 1.46 rad.

Physics Simulation

  • Pendulum model: Each ball group follows θ(t) = θ_max · cos(ωt) (swinging from amplitude) or θ(t) = θ_max · sin(ω(t−t_collision)) (after collision).
  • Period: T = 2.5 s, ω = 2π/T ≈ 2.51 rad/s, giving ~2 complete cycles in the 5-second animation.
  • Collisions: Momentum transfers at quarter-swing intervals (t = 0.625, 1.875, 3.125, 4.375 s). Two incoming balls transfer momentum to two outgoing balls.
  • Damping: Amplitude multiplier of 0.88 per half-cycle, simulating energy loss.

Rendering

  1. Background preparation: The grabber region (x=40–105, y=74–105) is filled with wall color sampled from a clean strip above the grabber (y=66–72, column-matched). The held-ball region (x=80–115, y=86–104) is filled from above. Edge blending (5 px) smooths transitions.
  2. Ball rendering: Each ball is a procedurally generated metallic sphere (chrome/silver) using Phong-like shading with a sharp specular highlight, environment reflection hint, and edge darkening. Rendered at 2×radius+1 resolution with alpha channel for anti-aliased compositing.
  3. String rendering: Thin anti-aliased dark lines (RGB ~12,12,16) are drawn from each ball's pivot to its current position using a Wu-like line algorithm with sub-pixel positioning.
  4. Compositing: For each frame, strings are drawn first (behind balls), then ball sprites are alpha-blended on top.

Output Verification

  • Frame 00 verified bit-exact match with first_frame.png.
  • All 20 PNGs verified against the pixels.npz uint32 tensor.
  • Frame-to-frame pixel change counts show expected patterns (largest change at 00→01 due to grabber removal, periodic changes matching collision rhythm).

Tools Used

  • Python 3 with NumPy and Pillow (PIL)
  • No external AI models, rendering engines, or network access
  • All pixel operations are local: drawing, compositing, alpha blending, analytic shading
