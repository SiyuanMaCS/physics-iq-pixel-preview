Method

Overview

This PixelWorld-Text task generates 20 frames (256×144, 4fps) of a grey tennis ball rolling out of a black pipe and hitting a 30lb kettlebell on a light wooden table, with a yellow rubber duck nearby.

Approach: Frame-Differential Compositing

Each frame t > 0 is generated by starting from the original first_frame.png and applying layered modifications:

1. Background Fill

The ball's original position (center x=47, y=31, radius=14) is removed by filling the circular region with a per-row median color sampled from the clean table gap between the ball and kettlebell (columns 70–82). This preserves the vertical color gradient of the table surface while avoiding object contamination.

2. Object Extraction

  • Kettlebell (74×49 px sprite): Extracted from frame 0 using color discrimination. Pixels are classified as kettlebell if they differ from the warm table color (RGB ~130–155, 125–150, 120–145). The dark shadow on the right side is included with semi-transparent alpha.
  • Duck (26×20 px sprite): Extracted using the yellow color signature (high R and G, low B channels).
  • Tennis ball (32×32 px sprite): Generated procedurally as a 3D-shaded sphere. Base color is a medium grey (108, 106, 98) with Lambert-like shading, a specular highlight at the top-left, and slight per-pixel noise for texture. Radius 14 px.

3. Animation & Physics

  • Ball trajectory: Constant-velocity roll from pipe exit (x=47) to kettlebell contact (x=90), then elastic rebound leftward. Impact frames (10–11) include horizontal squash (0.75× and 0.87× scale).
  • Kettlebell: Shifts 2 px right on impact (frame 10), settles back by frame 12. Exposed edge strips are filled with table color.
  • Duck: Small wobble (±1 px) during frames 11–14 from table vibration.

4. Compositing

Sprites are alpha-blended onto the background using per-pixel alpha masks. The ball is drawn last so it renders in front of the kettlebell during approach and impact.

Pixel Operations Used

  • NumPy array manipulation for all pixel reads/writes
  • Per-pixel color comparisons for sprite mask generation
  • Procedural sphere shading (Lambert + specular highlight + noise)
  • Alpha blending for sprite compositing
  • Median filtering for background fill color estimation
  • Horizontal squash via nearest-neighbor resampling for impact compression

  • Pipe area (x=0–34, y=0–22) is verified unchanged across all frames
  • Ball trajectory and sprite colors are verified at the pixel level
  • All 20 PNG frames and the pixels.npz tensor are saved and validated

Limitations

  • The kettlebell and duck sprites use hard alpha thresholds which may create slight edge artifacts when shifted
