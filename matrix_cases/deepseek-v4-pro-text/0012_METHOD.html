METHOD.md

METHOD.md — case_0012

Approach

Method: Direct pixel compositing with 3D-shaded ball sprites and pipe occlusion.

No external AI models, engines, or pre-trained networks were used. All generation is done with pure NumPy/Pillow pixel operations.

Scene Analysis

The first frame (first_frame.png) was analyzed by programmatic RGB inspection to identify:

  1. Black pipe on the left side: per-row boundary detection identified where the pipe wall ends (brightness threshold > 55).
  2. Brown tennis ball at ~(37, 45): a round orange-brown cluster at the pipe mouth, about 14px diameter.
  3. Red ball at ~(97, 34): about 9px diameter, deep red color.
  4. Wooden table: warm gray-brown background tones across the right/center portion.

Frame Generation

Frame 0

Exact pixel copy of first_frame.png. Verified with np.array_equal.

Frames 1–19

For each frame:

  1. Start from the clean background (frame0).
  2. Composite a 3D-shaded orange tennis ball sprite at the ball's current (x, y) position using alpha blending.
  3. Apply pipe occlusion: restore all pixels from frame0 that fall within the pipe wall region (left of the per-row pipe boundary). This hides the part of the ball that should remain behind the pipe during emergence.

Ball Sprite Construction

Each ball sprite is procedurally generated:

  • Sphere geometry: For each pixel within the ball radius, compute the 3D surface normal from (x-cx)/r and (y-cy)/r.
  • Phong-like lighting: Ambient (0.18) + diffuse Lambertian (0.58 × dot(N, L)) + specular Blinn-Phong highlight (power 30, weight 0.40).
  • Light direction: Upper-left (~(-0.55, -0.35, 0.75) normalized).
  • Rim darkening: 0.52 + 0.48 × nz factor darkens edges.
  • Drop shadow: Elliptical dark patch (opacity 0.30) below the ball.
  • Motion blur: For faster frames (t ≥ 4), the ball sprite is horizontally stretched with multiple offset copies at reduced alpha.

Ball Trajectory

  • Frames 1–3: Ball emerges from the pipe. Position moves from behind the pipe wall (x=20, y=39) to fully emerged (x=37, y=44). Pipe occlusion handles the partial visibility.
  • Frames 4–19: Ball rolls rightward across the table at constant speed. Position interpolated linearly from x=48 to x=220 at y=45.
