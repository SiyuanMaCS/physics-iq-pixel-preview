METHOD.md

METHOD.md — Case 0022

Task Summary

Generate a 20-frame (4 fps, 5 seconds) animation of a grey tennis ball rolling out of a black pipe on a light wood coffee table, travelling rightward across the table.

Inputs: first_frame.png (256×144 RGB), prompt.txt

Outputs: frames/00.png–19.png, pixels.npz, inspection.png, transition_check.png, index.html

Method

Frame 00 (Baseline)

Frame 00 is preserved exactly as first_frame.png — no pixels are modified. The ball is assumed to be fully inside the pipe at time 0 and therefore invisible. The assertion frames[0] == first_frame.png is verified at generation time.

Scene Analysis

All scene measurements were taken via numeric RGB array inspection of first_frame.png — no image viewing tools were used.

  • Table surface: Light wood, rows ~65–143, mean RGB ≈ (155, 148, 142).
  • Black pipe: Left end of table, columns 0–27, rows 70–99. Cylindrical shape with dark body and metallic rim reflections.
  • Pipe opening: Right-facing, at approximately column 25–28.
  • Ball path: Center Y = 82 (aligned with pipe opening center). Horizontal trajectory from column 14 (inside pipe) to column 219 (near right table edge).

Ball Rendering

The tennis ball is drawn procedurally using pure NumPy pixel operations:

  1. Shape: A circle of radius 7 px (14 px diameter) with a soft alpha edge for anti-aliasing.

  2. 3D shading: Lambertian diffuse + ambient + specular highlight.

    • Light direction: upper-left (~(-0.5, -0.4, 0.77)).
    • Surface normals computed analytically from sphere geometry.
    • Fresnel-like rim darkening: 1 - 0.25 × (1 - nz).

  3. Seam lines: A white double-seam pattern characteristic of tennis balls, modelled as two orthogonal great-circle bands (|nx| < width, |ny| < width). The seam rotates as the ball rolls: angle = t × (dx / 110px) × 2π.

  4. Drop shadow: A dark, semi-transparent ellipse composited below and slightly right of the ball, with soft radial falloff.

  5. Compositing: RGBA alpha blending over the original background using blended = fg × α + bg × (1 − α). Clipped to frame bounds.

Pipe Occlusion

A pipe foreground mask is built by comparing each pixel in the pipe region (columns 0–27, rows 70–99) against a per-row reference table colour (sampled from columns 45–55). Pixels whose Euclidean colour distance from the reference exceeds 35, or whose brightness is below 35, are classified as pipe surface. The mask is dilated by 2 iterations to capture metallic rim reflections at the pipe opening.

After the ball is composited, the pipe mask is used to restore original pipe pixels from first_frame.png, ensuring the ball appears to emerge from behind the pipe rather than being drawn on top of it.

Motion Model

  • Horizontal: Constant velocity, dx = 11 px/frame. ball_cx(t) = 14 + t × 11.
  • Vertical: Subtle arc as the ball exits the pipe: frame 2 lifts by 1 px.

Outputs

  • pixels.npz: uint32-packed tensor (144, 256, 20), encoded as 0xRRGGBB.
  • frames/*.png: 20 individual RGB frames, each 256×144.
  • inspection.png: 8-frame contact sheet with timestamps.

  • index.html: Standalone interactive player with delta-encoded pixel data.

Tools Used

  • NumPy: Array manipulation, shading math, alpha compositing.
  • PIL (Pillow): PNG I/O, contact sheet assembly.
  • SciPy (scipy.ndimage.binary_dilation): Pipe mask edge dilation.
  • artifact_io.py: Project-provided helper for saving frames, pixel tensor, inspection sheet, and HTML player.
