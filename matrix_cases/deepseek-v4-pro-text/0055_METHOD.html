METHOD.md

Method

Scene

256×144, 4fps, 5s (20 frames). A wooden stick attached to a black platform rotates clockwise, knocking the first in a line of four dominoes. The chain reaction propagates rightward past a stationary yellow rubber duck on a wooden table.

Technique

Frame 00

Exact byte copy of first_frame.png (verified: MD5 match).

Frames 01–19

  1. Start from original first frame (all stationary elements intact).
  2. Erase exact stick-pixel positions using a pre-computed table/wall color map.
  3. Erase exact rectangles of tilted dominoes (same color map).
  4. Draw tilted dominoes procedurally:
    • Dark rectangular blocks with white pips (two pips per face).
    • Per-pixel noise for natural texture.
    • Clockwise rotation around base pivot. Corrected formula: nlx = lx·cos(θ) − ly·sin(θ), nly = lx·sin(θ) + ly·cos(θ).
    • For angles <15°, blending with original upright pixels for smooth transition.
    • Soft shadow cast on table surface.
  5. Draw stick at rotated angle (2D rotation around pivot (118,60)).
  6. Restore non-tilted domino regions from original (handles stick-overlap).
  7. Composite duck pixels on top last.

Stick

  • 930 pixels extracted by warm-brown wood color signature (R:85–175, G:40–135, B:0–50).
  • Pivot at (x=118, y=60). Rotates clockwise 0° → 78° over 13 steps.
  • Stick acceleration: fast initial swing, then slow approach to final position.

Domino Chain

  • 4 blocks defined with 3px gaps (x ranges: [165,175], [179,188], [192,203], [206,217]).
  • Staggered starts at frames 2, 5, 8, 11 (3-frame intervals).
  • Non-linear tilt curve: [0, 5, 15, 30, 50, 70, 85, 90, 90, 90]°.
  • All four dominoes reach 90° by frame 18.
  • No margin erasure: adjacent upright dominoes never corrupted (0 diff verified).

Duck

  • Stationary, 2211 pixels with yellow color mask (R>140, G>90, R−B>60).
  • Composited on top of all moving elements. 0 pixel integrity issues.

Key Design Decisions

  • No clean background layer: avoids horizontal-interpolation artifacts (duck-yellow bleeding into domino area). Uses original first frame as base.
  • Non-tilted restoration: after drawing stick, upright domino pixels are restored from original, preventing stick-overlap corruption.
  • No margin/edge erasure: eliminates flickering from adjacent-domino erasure. Only exact object interiors are filled.

  • pixels.npz: packed uint32 tensor, shape (144, 256, 20)
  • inspection.png: 8-frame contact sheet
  • transition_check.png: frame 00 vs 01 side-by-side
  • index.html: standalone web player with delta encoding
  • generate.py: reproducible generator
