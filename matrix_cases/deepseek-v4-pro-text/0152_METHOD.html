METHOD.md

METHOD.md

Approach

Pure Python pixel operations — no external AI models, engines, or network calls.

Scene Understanding (OBSERVATION.md)

The scene was analyzed by numerically reading first_frame.png as a numpy array and inspecting:

  • Row and column brightness profiles to identify horizontal and vertical boundaries
  • Color clustering (brown, olive green, dark) to locate objects
  • Transition detection (dark-to-light) to find object edges
  • Region-based RGB sampling to characterize each element

Key measurements:

  • Table: light wooden surface, y=40-143, mean RGB ≈ [125, 120, 118]
  • Tube: black tube on left, x=0-25, y=18-41, darkest pixels RGB ≈ [4, 0, 0]
  • Box: olive green fabric box, x≈215-255, y≈60-110, RGB with G > R and G > B (e.g., [33, 44, 28])
  • Ball: brown tennis ball, not visible in frame 0 (inside tube)

Frame Generation

Each frame (1-19) is generated by:

  1. Copying first_frame.png as the base layer
  2. Drawing a shadow ellipse beneath the ball position (darkens table pixels)
  3. Drawing a 3D-shaded tennis ball sphere with Lambertian diffuse + Phong specular + rim darkening

Frame 0 is an exact byte-for-byte copy of first_frame.png (verified via np.array_equal).

Ball Rendering

The tennis ball is rendered as a 10-pixel-radius sphere with:

  • Lambertian diffuse shading: surface normal dot light direction (light from upper-left)
  • Specular highlight: Phong model (exponent 40) for glossy tennis ball fuzz
  • Fresnel-like rim darkening: edges slightly darker for depth
  • Anti-aliased edges: alpha blend based on sub-pixel distance from sphere boundary
  • Color palette: base brown ~[130, 105, 75], with highlight and shadow adjusted for the scene's dark lighting

Shadow Rendering

A dark elliptical shadow is drawn below and slightly right of the ball:

  • Width: 1.3× ball radius, Height: 0.4× ball radius
  • Offset: +3px right, +9px down from ball center
  • Opacity: 55% darkening at center, fading to 0 at edges

Box Deformation (Frames 13-19)

On impact, the olive green fabric box deforms:

  • Shift map: pixels in the box region are shifted rightward
  • Falloff: exponential decay from impact center (σ = 25px)
  • Peak deformation: 6px shift at frame 15 (maximum fabric compression)
  • Recovery: gradual reduction to 0.5px by frame 19

Output Verification

  • All 20 frames verified at 256×144×3 uint8
  • Frame 0 verified byte-identical to first_frame.png
  • pixels.npz uint32 0xRRGGBB tensor verified against PNG files
  • inspection.png, transition_check.png, and index.html generated correctly
