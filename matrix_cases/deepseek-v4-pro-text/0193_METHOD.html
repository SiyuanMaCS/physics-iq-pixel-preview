Physics & Animation Concept

The scene demonstrates a classic physics concept: the relationship between mass/weight and surface pressure. A 30-lb kettlebell (heavy) and a green piece of paper (light) are placed simultaneously onto a soft pillow. The kettlebell sinks deep into the pillow due to its concentrated weight, while the paper barely indents the surface.

Key Physical Effects

  1. Kettlebell sinking: Due to 30-lb mass, the kettlebell compresses the pillow fabric significantly, creating a deep depression
  2. Paper resting: Negligible mass means almost no pillow deformation
  3. Pillow deformation: The pillow surface stretches and compresses locally around the kettlebell, forming a bowl-shaped depression
  4. Settling: The pillow material has internal friction, so the sinking motion decelerates (damped)

METHOD.md

Method Documentation

Overview

All frames are generated from first_frame.png using local Python pixel operations: sprite extraction, translation, background inpainting, pillow surface displacement, and shadow rendering. No external tools, AI models, or network access.

Methods

1. Sprite Extraction

  • Kettlebell: Pixels with brightness < 35 in region y=[0,59], x=[78,121] are treated as kettlebell. The sprite includes the full 60×44 region with an alpha mask where mask[y,x] = (brightness[y,x] < 35).
  • Green paper: Pixels where G > R+10 and G > B+5 in region y=[13,54], x=[174,203]. The sprite mask covers all green-dominant pixels.

2. Object Translation

For each frame t, the sprite is redrawn at (x_obj, y_obj + dy(t)) where dy(t) follows the event plan timing curve:

  • Kettlebell: dy_kb(t) = 26 * smoothstep(t / 3.0) for t ∈ [0, 3.0], constant thereafter
  • Paper: dy_paper(t) = 2 * min(1, t / 0.5) — quick 2px settle

The sprite's original position is erased from the frame before redrawing at the new position.

3. Background Inpainting

When the kettlebell moves downward, it vacates pixels that must be filled with plausible background. The method:

  • For each vacated pixel at (x, y): horizontally interpolate between reference columns
  • Left reference: column x = 77 (1px left of kettlebell region)
  • Right reference: column x = 122 (1px right of kettlebell region)
  • Blend weight: w = (x - x_left) / (x_right - x_left), linear interpolation
  • Same approach for green paper using its adjacent columns

4. Pillow Surface Deformation

The pillow deforms under the weight of the kettlebell using a displacement field:

For each pixel (x, y) in the pillow region (y ≥ pillow_top[x]):
    dx_contact = |x - 99|  # horizontal distance from kettlebell center
    dy_contact = |y - (59 + dy_kb)|  # vertical distance from contact point
    
    # Gaussian falloff horizontally
    h_weight = exp(-dx_contact² / (2 * 30²))
    
    # Linear decay vertically into pillow
    v_weight = max(0, 1 - dy_contact / 60)
    
    # Combined displacement
    local_dy = dy_kb * h_weight * v_weight
    
    # Sample from above (stretching fabric)
    output[y + local_dy, x] = input[y, x]

Areas at the top of the displacement (where fabric was pulled from) are inpainted using horizontal interpolation from adjacent columns.

5. Shadow Rendering

  • A dark shadow is rendered under the kettlebell to enhance depth perception
  • The shadow is a dark semi-transparent ellipse centered at (99, 59 + dy_kb)
  • Shadow opacity follows Gaussian falloff, blended using output = input * (1 - alpha) + shadow_color * alpha
  • Shadow color: RGB(30, 28, 28), alpha max 0.5

6. Paper Placement

  • Similar to kettlebell but with minimal displacement (2px max)
  • Minimal pillow deformation under paper (dy_paper * 0.1 max displacement)
  • Slight shadow under paper
