ball-in-sand · 生成方法

Overview

The scene shows a blue-black grabber tool releasing a blue tennis ball above a pile of green kinetic sand on a wooden table. We animate the ball falling under gravity, impacting the sand, and settling with a visible dent.

Approach: Background-gradient differencing + sprite transfer

1. Scene analysis (from first_frame.png only)

  • Background wall: Left-to-right gradient (~RGB 140→157), rows 0–72
  • Grabber tool: Blue-black metallic, X≈100–138, rows 4–17, stays static
  • Blue tennis ball: ~42×32 px, center at (115, 58), blue-excess signature vs wall
  • Green kinetic sand pile: Peak at rows 89–96, X≈110–120, mound shape
  • Wooden table: Rows 130–143, warm brown (R>G>B)

2. Ball extraction

  • Estimated per-row background gradient by linear interpolation of left/right wall samples
  • Differenced each pixel from estimated background; ball has elevated B and depressed R
  • Binary mask via thresholding + dark-core capture + morphological closing
  • Largest connected component selected as ball mask
  • Background behind ball inpainted via local unmasked-neighbor averaging
  • Edge feathering applied for seamless blending

3. Physics simulation

  • Constant gravitational acceleration: ball free-falls from rest for 1.75s (7 frames)
  • Gravity calibrated so ball bottom reaches sand surface at frame 7–8
  • Impact phase (frames 8–13): damped oscillation model for penetration and rebound
  • Settling phase (frames 14–19): ball at rest, partially embedded in sand
  • Only vertical motion (no horizontal drift)

4. Sand deformation

  • Gaussian-weighted dent applied to sand surface during impact
  • Deformation center tracks ball position; sigma widens during penetration
  • Cumulative deformation tracked; partial recovery during rebound
  • Persistent dent (≈3 px) remains in final frames
  • Deformation applied fresh to clean master background each frame to avoid accumulation

5. Frame generation

  • Frame 00: exact copy of first_frame.png
  • Frames 01–19: start from clean master (background with ball inpainted out), apply cumulative sand deformation, composite ball at physics position
  • Ball compositing via per-pixel alpha blending with edge falloff

6. Output verification

  • All 20 PNGs (256×144 RGB) verified against uint32-packed .npz
  • Frame 00 exactly matches first_frame.png
  • inspection.png: 8-frame contact sheet
  • transition_check.png: 20-frame side-by-side with per-frame delta counts
  • index.html: standalone player with deltas encoding

Tools used

  • Python 3 with numpy, scipy, Pillow
  • No external AI models, no network, no image viewing
  • Local pixel operations only
