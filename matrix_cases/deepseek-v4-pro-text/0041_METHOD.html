METHOD.md

Method — Case 0041: Knife Slicing Through Tangerine

Overview

Pure pixel-level animation using NumPy and PIL. No external AI models, engines, or networks. All operations are color-threshold segmentation, mask-based pixel shifting, and texture synthesis.

Scene Understanding

First Frame Analysis

The 256×144 RGB still image (first_frame.png) shows a top-down view of:

  • A glass cutting board with a diagonal edge spanning from upper-right to lower-left.
  • One half of a tangerine resting on the board, centered at approximately (x=88, y=81).
  • A kitchen knife entering from the top of frame, with its blade's left (cutting) edge visible around x=127.

Color Thresholds

The scene has 16,745 unique colors (photorealistic). Segmentation uses multi-condition thresholds in RGB space:

| Object | Conditions | |--------|-----------| | Tangerine flesh (bright) | R>105, G>45, B<95, R>G>B, R>B×1.15 | | Tangerine flesh (shadow) | 70<R<120, 28<G<80, B<70, R>G>B | | Tangerine pith | R>160, G>125, B>75, |R-G|<55, R>B+20, G>B+15 | | Tangerine rind (edge) | R>85, G>50, B>35, |R-G|<45, R>B+15 | | Knife blade | MX>135, saturation<0.12, constrained to right side, top rows |

Tangerine Mask

  1. Combine flesh_bright + flesh_shadow + pith into candidate mask.
  2. Apply center bias (exclude edges where similar colors might be background).
  3. Find the largest connected component.
  4. Close morphological gaps (3×3 structuring element, 2 iterations).
  5. Dilate once to capture edge pixels.
  6. Dilate further (5×5) and intersect with rind color check to capture fruit boundary.

Final tangerine mask: ~4,500 pixels covering approximately x∈[10,157], y∈[15,138].

Knife Blade Detection

  1. In top 8 rows (above tangerine), detect bright low-saturation pixels.
  2. Find the left edge (cutting edge) at ~x=127.
  3. Measure blade width as ~15 pixels (x∈[127,142]).
  4. Extract blade texture from these top rows to create a blade texture strip.
  5. Extend strip downward by repeating the top texture with slight Gaussian noise (±1.5 per channel).

Animation Method

Frame Generation (20 frames, 4 fps)

Frame 0: Exact copy of first_frame.png (verified via np.array_equal).

Frames 1–19: Each frame computed from the original base image:

1. Knife Translation

The knife blade is a rigid textured strip of height blade_h = t_bot - t_top + 50. It translates downward with linear timing over the 5-second duration. The knife tip position at frame f is:

knife_tip_y = int((f / 19) * (t_bot + 15))

The blade is drawn only from knife_top = knife_tip_y - blade_h to knife_tip_y (clipped to frame bounds).

2. Tangerine Split

When the knife tip has entered the tangerine (knife_tip_y > t_top):

For each row y from t_top to min(knife_tip_y, t_bot):

  • Compute separation sep = max_sep × (1 - (y-t_top)/penetration)^1.8
  • max_sep = min(8, 2.0 + penetration × 0.12)
  • For each pixel at x < cut_x: shift left by sep × 0.7 pixels
  • For each pixel at x ≥ cut_x: shift right by sep × 0.7 pixels
  • Fill the gap between shifted halves with a blended flesh/pith interior color

The quadratic falloff (exponent 1.8) creates natural-looking separation: widest at the top (cut first, more time to separate) and tightest near the knife tip (just being cut).

3. Blade Visibility

  • Above tangerine (y < t_top): Full blade is visible.
  • Inside tangerine (t_top ≤ y ≤ split_bottom): Blade is only drawn in the gap between the separated halves.
  • Below knife tip (y > knife_tip_y): No blade drawn; intact tangerine remains.

4. Gap Interior Color

The cut surface is a blend between:

  • Flesh color: RGB(195, 105, 58) — warm tangerine interior
  • Pith color: RGB(218, 192, 150) — inner white pith Blend ratio is based on distance from the cut center, creating a natural gradient from darker flesh at the cut line to lighter pith at the edges.

5. Blade Edge Highlight

A subtle brightening (+35 to +10) applied to the blade's left edge (cutting edge) to simulate light catching the sharp metal edge.
