METHOD.md

Method

Approach

Layer-based compositing with reference-based inpainting. The basket and cord are treated as a movable sprite extracted from the first frame. A background plate is built by filling the moving-object region with content from nearby clean areas. Each frame composites the sprite at a progressively higher position.

Steps

1. Moving mask construction

A binary mask identifies pixels belonging to the basket and orange cord:

  • Basket: Dark woven pixels (brightness < 115, R < 145) within bounding box y=58-70, x=126-157
  • Cord: Darker-than-wall pixels (brightness < 150, R < 160) within y=40-59, x=135-154
  • Orange cord connector pixels added at y=43-48
  • Horizontal gap-filling connects basket to cord within bounding rows

Result: 423 moving pixels.

2. Background plate

The background replaces masked pixels using reference-based fill:

  • Wall zone (y < 60): Each masked pixel copies from the clean wall reference column at x=110 (same row). This preserves the subtle vertical gradient of the wall.
  • Table zone (y >= 60): Each masked pixel copies from the nearest unmasked pixel to the right (same row). This preserves the natural table texture including ball patterns.
  • Boundary smoothing: 3 iterations of weighted blending with unmasked 4-neighbors (70% original fill, 30% neighbor mean).

No external models, no generative AI. All operations are pure pixel copy/composite.

3. Animation

Manual easing offsets produce smooth lift motion. Total displacement: 50 pixels upward over 20 frames. Offsets: [0, 0, 2, 4, 7, 11, 15, 19, 24, 28, 32, 36, 40, 43, 45, 47, 49, 50, 50, 50]

  • Frame 00-01: no motion (pause)
  • Frames 02-17: smooth accelerated lift
  • Frames 18-19: final position, stationary

4. Frame generation

For each frame with offset > 0:

  1. Start from background plate
  2. Composite all moving-mask pixels from original frame at new position (shifted up by offset)
  3. Pixels that move off the top of the frame are clipped

Frame 00 is the exact copy of first_frame.png.

  • Round-trip verified for all frames
