Approach

Direct pixel manipulation in Python (NumPy + PIL). No external models, engines, or network access.

Generation Method

Ball Extraction

  • Ball bounding box: y=[40,61], x=[77,102] (21×25 pixels)
  • Soft circular alpha mask centered at (cx=14, cy=10) in patch coordinates, radius 10
  • Alpha = clamp(1 - (dist - 5.5) / 5.5, 0, 1) — smooth falloff at edges

Clean Floor Synthesis

  • Tube floor to the left of ball (x=67–76): uniform light gray-brown
  • Tube floor to the right of ball (x=102–210): actual frame 0 pixels (naturally clean)
  • Ball start zone (x=77–101): filled by extending left-floor texture rightward with:
    • Cyclic sampling from left floor strip
    • Subtle Gaussian noise matching local floor statistics
    • Slight progressive darkening to match tube interior gradient

Frame Generation (frames 1–19)

  1. Start from first_frame.png (frame 0) copy
  2. Fill vacated tube floor behind ball with clean floor map
  3. Composite ball patch at new position using alpha blending
  4. Apply rotation effect: cyclically shift ball interior pixels vertically proportional to displacement
  5. Frames 18–19: apply box edge deformation (push box left 2–3px at contact zone)

  • Deceleration frames 16–17 (181 → 190)
