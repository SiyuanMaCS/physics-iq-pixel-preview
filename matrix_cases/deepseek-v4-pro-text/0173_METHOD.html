METHOD.md

Method

Approach

Layer-based compositing with background inpainting. The animation is generated by decomposing the first frame into separate layers (background, grabber tool, pink block), creating a clean background plate via inpainting, and then re-compositing the layers with animation offsets.

Techniques Used

Background Inpainting

The grabber tool and pink block from frame 00 were removed from a "clean plate" using 1D nearest-neighbor horizontal fill. For each row, contiguous masked segments are identified. The left half of each segment is filled by copying the nearest unmasked pixel to the left; the right half copies from the right. This preserves the wall's natural horizontal color variation without introducing interpolated intermediate colors. When an entire row is masked, rows above or below are copied instead.

Mask Extraction

Grabber tool: First, color thresholding identifies candidate pixels:

  • Blue body: B > R+15, B > G+8, B > 50
  • Black gripper tips: R,G,B < 30-35

Then connected component labeling (scipy.ndimage.label, 8-connectivity) isolates only the component touching the top row (y=0). This cleanly separates the grabber tool from the gate's blue lintel blocks, which share similar colors but are spatially disconnected.

Pink block: Strict color threshold (R > 155, R > G+25, B > 75) within the region above the gate lintel (y < 62), followed by a 1-pixel morphological dilation to capture soft edge pixels. This yields 347 pixels in an approximately 11x33 rectangular region.

Animation

Pink block descent: Linear 1-pixel downward displacement at frame 1. The block sits exactly on the blue lintel of the gate (moves from y=[29,61] to y=[30,62]). Remains stationary thereafter.

Grabber retraction: Frame 0-1 stationary during placement. Frame 2: 1-pixel initial step. Frames 3-19: smooth ease-in retraction using a power curve (frac^1.5) reaching 36 pixels total upward displacement, fully exiting the top of frame by frame 18-19.

Gripper release: Black tip pixels linearly fade from 100% to 0% opacity over frames 3-7, simulating the gripper jaws opening. Blend with background plate for intermediate frames.

Compositing

Per-frame, pixel-level overlay in order:

  1. Background plate
  2. Pink block (with vertical offset pink_dy)
  3. Grabber (with vertical offset grabber_dy, black tips alpha-blended)

All coordinates are clamped to frame bounds [0,143] x [0,255].

Frame 00 Verification

Frame 00 is explicitly compared against first_frame.png and forced to an exact match if any discrepancy is detected (zero discrepancies observed).

Limitations

  • Integer-pixel displacements only; no sub-pixel motion.
  • Background inpainting uses 1D horizontal nearest-neighbor only; no vertical or 2D texture synthesis.
  • Gripper opening modeled as opacity fade rather than geometric jaw separation.
  • 2 pixels of the gate's blue lintel are covered by the pink block's final resting position (the block sits on top of the lintel).
  • 1 pixel of inpainting artifact remains (slightly blue-tinted background fill at the grabber's original edge).
