METHOD.md

METHOD.md

Approach

Task: Animate a paintbrush rotating clockwise on a black platform, having already passed through a red paint dollop on a clear acrylic sheet.

Method summary: Geometric brush extraction with multi-pass weighted inpainting, sprite-based rotation, and alpha compositing.

Scene Analysis

From first_frame.png (256×144):

  1. Left side: Wooden table surface (warm browns, mean RGB ~110, 92, 58) transitioning to wall above
  2. Center: Clear acrylic sheet (light gray, mean RGB ~132, 128, 116) with slight reflections
  3. Bottom-right: Black platform (triangular dark shape, RGB < 40) spanning approximately rows 60–100, cols 216–255
  4. Red paint smear: Already deposited on the acrylic sheet from the brush's prior pass, spanning rows ~76–105, cols ~100–250

Key Parameters

Parameter Value Description
Pivot point (row=62, col=217) Brush attachment point on black platform
Handle tip (row=82, col=190) Where bristles meet handle, in frame 0
Bristle tip (row=92, col=182) End of bristles, in frame 0
Handle half-width 4.5 px Perpendicular distance to centerline
Bristle half-width 3.5 px Perpendicular distance
Total rotation 25° clockwise Over 5 seconds (20 frames)
Rotation per frame ~1.32° Uniformly distributed

Steps

1. Brush Mask Extraction

  • Define brush centerline from pivot to tip using geometric parameters
  • For each pixel: compute perpendicular distance to centerline and projection along it
  • A pixel belongs to the brush if:
    • It's within half-width of the centerline AND
    • Its mean RGB is below 115 (darker than bright acrylic sheet)
  • Additional bristle pixels: near centerline extension into red paint area, darker with red tint
  • Result: 370 brush pixels identified

2. Background Inpainting

  • 10-pass iterative weighted inpainting
  • For each brush pixel, replace with weighted average of non-brush neighbors in 7×7 window
  • Weights: inverse distance (1/d) with 1.5× preference for left-side neighbors (acrylic sheet side)
  • Non-brush areas remain untouched (verified: max diff = 0)

3. Red Paint Preservation

  • Red paint identified by: red channel > green+12 AND red > blue+12 AND red > 60 AND not brush
  • Dilated 2 iterations to capture edges
  • Painted back onto the inpainted background (static — paint is already deposited)

4. Brush Sprite

  • Alpha sprite extracted from first frame: brush mask pixels = opaque (alpha 255), others = transparent
  • Sprite is padded 25px on all sides to prevent rotation clipping

5. Frame Generation

  • Frame 00: exact copy of first_frame.png
  • Frames 01–19:
    • Rotate brush sprite clockwise by t × 1.32° around the pivot point using PIL bicubic rotation
    • Alpha-composite rotated brush onto the clean background with red paint
    • Animation region: rows 56–100, cols 185–223
    • ~430–460 pixels change per frame (smooth, consistent)

6. Output

  • 20 PNG frames (256×144), pixels.npz (uint32 0xRRGGBB tensor), inspection sheet, transition check, standalone HTML player

Libraries Used

  • numpy — array operations, pixel manipulation
  • PIL/Pillow — image I/O, sprite rotation (bicubic), compositing
  • scipy.ndimage — binary_dilation for red paint edge capture
  • artifact_io.py — provided output helper (save, player HTML)

No External Dependencies

No external AI models, networks, engines, or references were used. All operations are local Python pixel math.
