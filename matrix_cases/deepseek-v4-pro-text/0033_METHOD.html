METHOD.md

METHOD.md — case_0033

Scene description (from prompt.txt)

Static locked-off single-shot with fixed frame throughout filmed with constant framerate in real-time. The scene shows a realistic scientific demonstration. A light-coloured wooden tabletop with two pipes at the edges. The blue and the yellow tennis ball roll out of the pipes and collide with the same speed.

Methodology

Frame analysis

Scene structure was determined by numeric RGB inspection of first_frame.png (no visual tools). Key measurements:

Feature Position / extent
Wall / backdrop y = 0–20
Tabletop y = 20–143 (gradient: darker at top, lighter at bottom)
Left pipe / edge x = 0–30, dark upper region
Right pipe opening x ≈ 225–255, y ≈ 55–80
Blue tennis ball centroid (76.0, 49.8), r ≈ 7 px
Yellow tennis ball centroid (149.7, 58.3), r ≈ 7 px
Inter-ball distance 74.2 px (centres)

Physics model

1D elastic collision of two equal-mass objects on a frictionless horizontal plane:

  • Initial velocities: blue = +3.5 px/frame, yellow = −3.5 px/frame
  • Collision time: t = 8.76 frames (between frames 8 and 9)
  • Collision position: blue ≈ (106.7, 50), yellow ≈ (119.3, 58)
  • Post-collision: velocities exchange (elastic, equal mass)

Ball positions are computed analytically per frame; the collision is a discrete event where speed is instantaneously reversed. Vertical positions are constant (flat tabletop).

Background reconstruction (inpainting)

The ball footprints in first_frame.png are replaced with plausible table-surface pixels before compositing the moving balls. Approach:

  1. For each row in a ball's bounding box, reference pixels are sampled from immediately outside the footprint (left and right, ≥18 px margin).
  2. Horizontal linear interpolation between left-average and right-average fills the gap.
  3. Deterministic Gaussian dither (rng seed 42, std 1.8) modulated by distance from gap centre adds wood-grain texture and masks seams.
  4. Both ball footprints are inpainted sequentially into a single clean background used for all subsequent frames.

Ball compositing

  • Frame 0 is a direct copy of first_frame.png to guarantee bit-exact match.
  • Frames 1–19 start from the clean background.
  • Ball sprites (RGB + alpha mask) are extracted once from frame 0:
    • Alpha is computed from a feathered circular distance mask combined with a per-channel colour-confidence score (blueness / yellowness).
  • Sprites are alpha-blended onto the background at the computed (x, y) positions each frame, yellow rendered first (behind), blue second (in front).

All pixel operations are pure NumPy/PIL; no external engines, models, network access, or sub-processes are used.
