METHOD.md

METHOD.md — Implementation Details

Approach

Layer-based 2D compositing with shadow projection. All pixel operations use NumPy/PIL only — no external AI models, 3D engines, or network access.

Steps

1. Clean Background Generation

  • Build reference wall gradient from rows above the shadow region (y=35-43)
  • Fill shadow region using the reference wall profile
  • Fill mug region using linear interpolation from adjacent clean wall pixels per row
  • Fill platform region (y≥134) using inverse-distance-weighted interpolation from left/right samples
  • Feather boundaries with Gaussian blending (sigma=1.5)

2. Mug Extraction

  • Body: Color-based masking (yellow/orange tones, R>100, G>80, R-B>50, G-B>25)
  • Handle: Color-based masking with spatial constraints (dark orange, right side only, x=131-149, y=115-137)
  • Alpha: Core pixels receive alpha=1.0, edges feathered using distance transform (3px feather)

3. Mug Body Rendering

  • Mug body sprite is kept unmodified across frames (cylindrical symmetry — no visible change from rotation)
  • Placed at original bbox position for all frames

4. Handle Rotation

  • Handle orbits around mug center with radius derived from frame-0 offset
  • Orbit equation: x_offset = radius * cos(angle), y_offset = base + sin(angle) * 4
  • Horizontal flip applied when handle moves to left side (cos(angle) < 0)
  • Visibility fades during transition through front/back of mug
  • Subtle scale and shear for perspective effect

5. Shadow Generation

  • Per-row projection of mug silhouette extents onto wall
  • Shadow scale varies with rotation: SHADOW_SCALE + 1.0*max(0,cos_a) + 0.3*max(0,-cos_a)
  • Handle contribution adds extra shadow width when handle is on right side: max(0, cos_a) * 25
  • Soft edges using distance-based penumbra, then Gaussian smoothing (sigma=2.5)
  • Shadow strength: SHADOW_DARKNESS + 0.08*abs(cos_a)

6. Compositing

  • Pipeline: clean background → apply shadow → alpha-over mug body → alpha-over handle
  • Standard alpha blending: result = foreground * alpha + background * (1 - alpha)
  • Frame 0 preserved exactly from first_frame.png

Rotation Model

  • Full 360° rotation over 5 seconds (72°/s, 18°/frame, 20 frames at 4fps)
  • Clockwise rotation (viewed from above): handle starts on right at 0°, moves front → left → back → right

Known Limitations

  • Shadow variation is subtle (~2-3px) due to limited wall space for projection
  • Mug body treated as rotationally symmetric (visually imperceptible at this resolution)
  • Handle extraction limited to single orientation; flipped sprite may not perfectly match 3D appearance
