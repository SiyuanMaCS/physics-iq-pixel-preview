METHOD.md

Method

Approach

Local Python pixel operations only — no external engines, AI models, or network access. All 20 frames generated programmatically from first_frame.png and scene analysis.

Scene Analysis

The scene was analyzed via numeric RGB inspection of first_frame.png (144×256, uint8). Key measurements:

  • Pivot: (183, 65) — center of the warm-wood hinge structure visible on the black platform's upper-left edge.
  • Stick: 130 px long, 4 px wide. In frame 0, points straight down (-90°), hidden behind the black platform. Only the hinge base is visible.
  • Blocks: Yellow (x~48-68, y~48-58), orange (x~56-72, y~48-61), red cluster (x~64-88, y~49-97).
  • Background: Purple wall (~(60,60,60) in shadow, brightening to ~(180,175,185) at center), brown wooden table (~(135,100,75)), dark green/teal felt pad between blocks and platform (~(20,65,25) transitioning to ~(30,110,160)).

Stick Animation Model

The stick is parameterized by angle θ measured clockwise from straight down:

  • θ = 0°: pointing down (hidden behind platform)
  • θ increases clockwise, sweeping toward blocks on the left
  • dx = -sin(θ), dy = cos(θ) (in screen coordinates where y increases downward)

Angular profile:

  • Frame 0: θ = 0° (hidden)
  • Frames 1-5: ease-in acceleration to θ = 95.7° (impact with yellow block at frame 5)
  • Frames 6-19: ease-out deceleration to θ = 130° (past blocks, pointing up-left)

The stick is drawn as a thick anti-aliased line using PIL's ImageDraw.line() with rounded ends, colored warm wood (175, 145, 110) matching the hinge hue.

Block Motion Model

After impact at frame 5, blocks are displaced rightward with quadratic acceleration:

Block Start Frame Acceleration Horizontal displacement
Yellow 6 1.8 px/fr² d = 1.8·t² (t ≤ 10)
Orange 7 1.3 px/fr² d = 1.3·t² (t ≤ 9)
Red 8 0.9 px/fr² d = 0.9·t² (t ≤ 8)

Vertical displacement is minor (0.15-0.4 px/frame downward tilt).

Frame Generation

For each frame f ∈ [1, 19]:

  1. Start with a copy of first_frame.png
  2. If blocks have moved from original positions:
    • Fill original block bboxes with tiled table texture (sampled from y=90-140, x=20-30)
    • Paste block pixels at new displaced positions
  3. Draw the rotating stick on top using PIL's anti-aliased line rendering

Frame 0 is an exact byte-for-byte copy of first_frame.png, verified by array equality.

Limitations

  • Block displacement uses rigid translation of rectangular regions; no rotation, deformation, or physics simulation.
  • Background inpainting uses simple texture tiling, not Poisson blending.
  • The stick model assumes a constant-acceleration angular profile without conservation of angular momentum.
  • Block colors at boundaries may show artifacts where adjacent blocks overlap.
