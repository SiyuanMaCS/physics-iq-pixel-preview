Mirror Reflection

  • The mirror reflects the scene to its right (optical vertical mirror).
  • Mirror plane estimated at x ≈ 50 (center of mirror surface).
  • The kettlebell dark mass appears reflected in the mirror (visible as dark pixels within mirror region).
  • Reflection formula: x_reflect = 2 × mirror_x − x_object.
  • Ball at x=84.5 → reflection at x≈15.5 (visible in mirror, right portion).
  • As ball moves right → reflection moves left → exits mirror.

Table Surface Details

  • Wood texture with moderate grain variation (±10 RGB units locally).
  • Behind tennis ball: Table surface at x=70-105, y=90-120.
  • Table color at ball location: R≈130, G≈105, B≈65 (warm brown).

METHOD.md

Method

Overview

This is a pure pixel-manipulation approach to animate a tennis ball rolling across a wooden table toward a 30lb kettlebell, with a mirror on the left side. No external models, physics engines, or networks were used — only local Python pixel operations (NumPy, SciPy, PIL).

Scene Analysis (Frame 00)

Key objects were identified via RGB thresholding and spatial analysis of first_frame.png:

Object Measurement Method
Tennis ball Center (84.5, 102.7), radius 17 px Yellow-green color mask: G>R+12, G>B+15, G>70
Kettlebell Dark iron body primarily x=120–255, y=0–143 R<55, G<50, B<50 mask (right side only)
Mirror x=0–79, y=0–64 Bright gray: R>140, G>140, B>130
Wooden table Below y≈55, full width Warm brown tones: R≈130, G≈105, B≈68

Ball Extraction

  1. Color-based mask: Identified pixels where green dominates red and blue (tennis ball signature).
  2. Dilation: binary_dilation(iterations=4) to capture edge pixels.
  3. Soft alpha: Radial distance falloff from ball center: alpha=1.0 inside BALL_R-2, linear to 0.0 at BALL_R+5, multiplied by dilated mask.
  4. Gaussian smoothing: sigma=0.6 on alpha for anti-aliased edges.

Background Inpainting

The ball's original location must be filled with table surface before the ball is composited at new positions:

  1. Clean sample mask: Exclude ball region and kettlebell dark pixels from table samples.
  2. Global table model: Collect all clean pixels in a 5–40 px band around the ball region. Compute median color (R=130, G=104, B=69) and standard deviation for noise.
  3. Row-by-row fill: For each row in the ball region, take the median of clean left samples (x < ball_min) and right samples (x > ball_max). Interpolate linearly between left and right colors based on x position. Add noise scaled to 30% of table std for texture variation.
  4. Circular fill mask: Replace all pixels within BALL_R+3 radius of ball center, with 1.5-sigma Gaussian feather at edges.
  5. Quality: Frame 07 old ball area shows 3/1054 ball-colored pixels (0.3%), mean color (129, 103, 70) closely matching reference table (122, 100, 70).

Ball compositing: For each frame, the ball sprite (extracted from frame 00 with alpha) is composited onto the inpainted base at position (cx, cy) using target = base * (1-alpha) + sprite * alpha.

For the compressed impact frame (16), the source ball sprite is sampled with x-axis scaling: source_x = BALL_CX0 + (target_x - cx) / scale_x.

Kettlebell Interaction

Mirror

The mirror on the left (x=0–79, y=0–64) reflects the tall kettlebell body (which spans y=0–143 vertically). The tennis ball at y≈87–118 lies below the mirror's bottom edge in the 2D frame, so its direct mirror reflection is not composited. The mirror region remains unchanged throughout the animation, which is physically consistent given the geometry.
