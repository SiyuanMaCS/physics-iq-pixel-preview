METHOD.md

METHOD.md

Approach

The animation is generated entirely through local Python pixel operations on the single input frame.

Steps

  1. Mask extraction:

    • A diagonal band is defined along the match's known path (cx ≈ 70 + y1.25, half-width ≈ 8 + y0.12).
    • Warm-colored pixels (R > max(G,B) + 5) within this band are selected.
    • Morphological closing + dilation clean edges; the largest connected component touching y=0 (top of frame) is kept.

  2. Background inpainting: Match-area pixels are replaced using horizontal linear interpolation between nearest unmasked pixels in each row.

  3. Sprite extraction: The match+flame is extracted as an RGBA sprite. Flame pixels are distinguished from stick pixels by stricter criteria: R > 200, G > 140, R+G+B > 500.

  4. Frame animation (20 frames, 4 fps, 5 seconds):

    • Frame 00: unmodified first_frame.png.
    • Frames 01–19: The match translates down-right (Δx=1.2, Δy=3.0 px/frame).
    • Flame extinguishing: Extinction progresses from flame base upward as the flame enters the water. Bright pixels darken to red-orange embers then fade to transparent.
    • Water ripples (frames 6–16): Sinusoidal radial pixel displacement at the water entry point, with growing then fading amplitude.
    • Steam (frames 8–15): Gaussian-weighted white overlay biased upward from the water surface.
    • Refraction (frames 13–19): Subtle rightward pixel shift of submerged match region.

Methods

  • NumPy/SciPy for morphological operations and array handling.
  • PIL/Pillow for image I/O.
  • All pixel operations are pure Python/NumPy — no external AI models, engines, or network access.
