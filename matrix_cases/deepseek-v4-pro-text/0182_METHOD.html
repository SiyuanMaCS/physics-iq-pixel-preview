+    return np.clip(bg, 0, 255).astype(np.uint8)

METHOD.md — PixelWorld-Text Animation Method

Overview

20-frame RGB animation (256×144, 4 fps, 5 seconds) of a physics demonstration: yellow block balanced on red block (L-shape) tips when a blue wooden block is placed on top by an orange-black grabber tool.

Method: Layer-Based 2D Compositing with Affine Transforms

1. Background Extraction

  • Object mask defined by conservative bounding boxes around all objects.
  • Per-row boundary-anchored linear interpolation fills object gaps: for each contiguous object segment in a row, interpolate RGB between the nearest clean pixel to the left and nearest clean pixel to the right.
  • This guarantees C0 continuity at segment boundaries — no visible seams.

2. Object Segmentation

  • Each object (red block, yellow block, blue block, grabber tool) segmented via color-threshold alpha masks in the original first_frame.png:
    • Red block: R>110, G<85, B<55, R-G>40, R-B>60, y≈86-142, x≈112-160
    • Yellow block: R>135, G>125, B<35 (core); edge-adjacent dilation
    • Blue block: B>100, R<40, B-R>100 (core); B>55, R<80, B>G+15 (edge)
    • Grabber: Orange (R>155, G>45, B<85) + dark body (R<55, G<55, B<65)
  • Masks extracted as RGBA layers with 4px padding.
  • No external segmentation models or AI used — pure NumPy color thresholding.

3. Animation

  • Red block: Stationary throughout (stable base).
  • Yellow block: Tips clockwise about pivot at red support edge (world x≈142, y≈100). Quadratic angular acceleration (0→-30°) during tipping phase (frames 3–7), then linear continuation (-30→-45°) during separation (frames 8–12). After separation, slides right and down with quadratic translation. Settling vibration via damped sinusoid (frames 13–19).
  • Blue block: Drops onto yellow (frames 1–3), tips with it (frames 4–7), falls to table with quadratic acceleration (frames 8–14), settles with damped vibration (frames 15–19).
  • Grabber: Opens slightly (drops 4px, frames 1–2), holds (frames 3–7), retracts upward at 1 px/frame (frames 8–19).

All parameters ensure every frame transition (0→1 through 18→19) has non-zero pixel changes, and all objects remain visible within the frame.

4. Rendering

  • PIL Image.rotate with expand=True for affine rotation (BICUBIC resampling).
  • PIL Image.paste with alpha mask for compositing.
  • Layer order (back to front): red → yellow → blue → grabber.
  • Frame 0: exact copy of first_frame.png (verified pixel-identical).

5. Physics Model

Simplified 2D rigid-body animation:

  • Pivot-based rotation: yellow block rotates about its contact point with the red block.
  • Gravitational acceleration: quadratic displacement for falling objects.
  • Damped sinusoidal vibration for settling phases.
  • No collision detection between objects (layered compositing handles occlusion).
  • No external physics engine — all motion computed analytically in NumPy.
