+Scene (from prompt.txt): locked-off static camera, constant real-time frame

+5 seconds, so every output frame is an exact copy of first_frame.png.

+No pixels are drawn, warped or synthesised; the only operation is a byte-exact
+replication of the supplied first frame.

+import numpy as np
+from PIL import Image, ImageDraw

+import artifact_io

+CASE_DIR = Path(__file__).resolve().parent
+N_FRAMES = 20
+
+
+def build_frames():
+    first = np.array(Image.open(CASE_DIR / "first_frame.png").convert("RGB"))
+    assert first.shape == (144, 256, 3) and first.dtype == np.uint8, first.shape
+    # Stationary subject + fixed frame throughout => 20 identical frames.
+    frames = np.broadcast_to(first, (N_FRAMES, 144, 256, 3)).copy()
+    return frames
+

+def make_transition_check(frames, out_path):
+    """Visualise the 19 inter-frame changes as numeric diagnostics.
+
+    Layout (900x260): frame00 | frame19 | amplified |diff| x8 | change bars.
+    A stationary clip yields a black difference panel and zero-height bars.
+    """
+    W, H = 256, 144
+    packed = frames.astype(np.uint32)
+    packed = (packed[..., 0] << 16) | (packed[..., 1] << 8) | packed[..., 2]
+
+    diff_counts = [int(np.count_nonzero(packed[t] != packed[t - 1]))
+                   for t in range(1, N_FRAMES)]
+    diff19 = np.abs(frames[19].astype(np.int16) - frames[0].astype(np.int16))
+    amplified = np.clip(diff19 * 8, 0, 255).astype(np.uint8)

+    sheet = Image.new("RGB", (900, 260), (25, 28, 35))
+    draw = ImageDraw.Draw(sheet)
+    sheet.paste(Image.fromarray(frames[0]), (0, 20))
+    sheet.paste(Image.fromarray(frames[19]), (W, 20))
+    sheet.paste(Image.fromarray(amplified), (2 * W, 20))

METHOD.md

METHOD — case_0062 (vision-input)

Task interpretation

The prompt describes a locked-off, fixed-frame shot of a yellow rubber duck that sits stationary on a light-brown wooden table in front of a plain wall. No force, contact, agent, or lighting event occurs in the described 5 seconds. The physically correct continuation of a static, real-time recording under those conditions is therefore an unchanging frame for the entire clip: no object motion, no camera motion, no flicker, no animated noise.

Method (stated honestly)

The generator performs no pixel synthesis at all:

  1. first_frame.png is loaded once as an RGB uint8 array, shape (144, 256, 3).
  2. The array is replicated 20 times (np.broadcast_to(...).copy()), giving frames 00–19 that are bit-for-bit identical to the input. No drawing, warping, inpainting, shading, transforms, random noise, or temporal filtering are applied.
  3. The supplied artifact_io.save writes:
    • pixels.npz — pixels tensor of shape (144, 256, 20), dtype uint32, each element packed as 0xRRGGBB (R<<16 | G<<8 | B);
    • frames/00.png … frames/19.png at 256×144 RGB;
    • inspection.png — the provided 8-frame contact sheet;
    • index.html — the standalone 20-frame player (because the clip is static, every one of its 19 delta payloads is empty by construction).
  4. generate.py additionally renders transition_check.png: frame 00, frame 19, the amplified per-pixel absolute difference |f19−f00|×8, and a bar chart of changed-pixel counts for each of the 19 transitions.

Scene measurements that motivated the "no event" plan (wall/table edge at y≈44–45, duck lit-yellow bbox x115–141 / y51–98, beak x122–138 / y73–83, cast shadow to x≈180, lighting layout) are recorded in OBSERVATION.md and were obtained with numpy/PIL only.

Verification

.tmp/verify.py independently re-derives everything numerically (no image viewing):

  • frames/00.png is pixel-identical to first_frame.png;
  • frames 01–19 are pixel-identical to frame 00 (all 20 share one array);
  • pixels.npz unpacks from 0xRRGGBB uint32 (144,256,20) back to exactly the 20 PNG frames, with no bits set above bit 23;
  • the base64 data embedded in index.html reconstructs, via the player's own first-frame-plus-delta scheme, all 20 frames identical to the PNGs, its caption matches prompt.txt, and all 19 delta payloads are empty;
  • each of the 19 transitions changes 0 of 36,864 pixels; per-frame mean RGB and per-frame L2 magnitude are constant;
  • the |f19−f00|×8 panel in transition_check.png is entirely black.

Re-run: python3 generate.py then python3 .tmp/verify.py.

Known limitations / deliberate non-choices

  • Real camera sensors exhibit photon shot noise and subtle lighting fluctuation, but the prompt explicitly says "fixed frame throughout" and the subject is stationary; adding synthetic temporal variation would be an invented effect and is intentionally avoided.
  • No semantic edits (e.g., "fixing" the exposure of the grayish wall) are made: the input frame is the ground truth and is preserved exactly, including its grain, shading, and shadow.
