ball-hits-nothing · 生成方法

Task

Locked-off shot (256×144, 4 fps, 20 frames). Frame 0 (first_frame.png) shows an orange tennis ball that has just left a black pipe on the left of a light wood coffee table; the prompt says it rolls straight over the whole table toward the right side. Only that ball moves; the red ball, brown ball, sofa, pipe and table stay static.

All pixels are produced with local Python/NumPy/PIL operations only — no external models, engines, references or network. Frame 00 is stored as the untouched input file.

Measurements (OBSERVATION.md)

Orange ball centroid (54.2, 50.9), opaque radius 6.3 px (fuzz to ~8 px), smooth sphere shading, peak RGB ≈ (233,147,85). Soft contact/cast shadow around the ball, strongest to the lower right (luminance ≈ 0.66 of the local table). Table side edge along the ball's depth: x ≈ 226 + 0.875·(y−44). Horizontal illumination is nonlinear (steep dark-to-bright rise on the left) and rows brighten slightly toward the camera.

Motion

Constant-depth straight roll ⇒ purely horizontal translation, fixed y and diameter. Constant speed 8.779 px/frame (35.1 px/s, ≈0.19 m/s at tennis-ball scale) so the ball ends at center x = 221.0 on frame 19, i.e. right at the table's right side with all orange pixels still inside the sloping edge (verified numerically). A uniform fuzzy orange sphere carries no rotation cue, and frame-0's sphere shading is fixed by the static light, so the rendered ball keeps identical shading (frame 0 itself shows mild motion softness consistent with this speed); no friction decay is modeled, keeping the appearance constant over the clip.

Pipeline (generate.py)

  1. Background model. For rows 38–65, a horizontal illumination curve is learned from clean rows just above/below the footprint (medians per column, lightly denoised), normalised between anchor strips at x ≈ 28/93/165, then pinned through each row's own three anchor medians. The result matches the observed saturating gradient rather than a straight line.
  2. Inpainting frame 0's footprint. Fine grain (frame − model) from a same-row clean donor strip near x 92 is copied into the ball+shadow mask, feathered over 3 px at run boundaries. Under pure shadow pixels (fuzz alpha < 0.25) the hidden table is inferred as frame / shadow_factor, blended 60/40 with the model and gamut/brightness-clamped to local wood, so the revealed table keeps wood hue without cool overshoots.
  3. Ball sprite (RGBA patch x42–76, y42–63). Intrinsic sphere colour C is a least-squares fit on opaque core pixels: constant + Lambert n_z + small quadratic terms (per-channel RMS residual ≈ 2.4/1.9/3.8). Fuzz alpha is solved per pixel against the shadowed local table, a = ⟨I−Bs, C−Bs⟩ / ‖C−Bs‖², clipped to [0,1]; the core is forced opaque, alpha is zero outside r = 8.3, geometrically tapered beyond r = 6.3, and further suppressed over the darkest contact zone. Sprite colour is the observed pixel where alpha > 0.8, otherwise the fitted shade ramped toward the observation inside r = 6.6.
  4. Shadow layer (per-channel multiply, 0.58–1.0). Ratios per channel vs the model, binary coverage where luminance ratio < 0.975 inside a contact halo (r < 9) ∪ a cast ellipse centered (63.5,53) with radii (11.5,6.5); both are Gaussian-blurred (σ 0.7) and recombined via a support mask, with contact-strength restored under the rim.
  5. Compositing frames 1–19. Both layers are bilinear-splatted (4-tap weights) at sub-pixel x offsets, dy = 0: background → per-channel shadow multiply → premultiplied alpha ball blend. Destination pixels past the measured table edge (x ≥ 226 + 0.875·(y−44) − 0.5) or outside the frame receive nothing, so the cast shadow correctly clips at the table edge in the last frames while the ball stays fully on wood.
  6. Saving. artifact_io.save writes pixels.npz (uint32 0xRRGGBB tensor), frames/00.png…19.png, inspection.png and the standalone index.html. transition_check.png shows frames 00/04/09/14/19, all 19 amplified consecutive-difference maps, and a frame-19 trajectory overlay.

Verification (numeric, no image-viewing of outputs used for tuning)

  • frames[00] is byte-identical to first_frame.png; all 20 PNGs exactly match the repacked uint32 tensor in pixels.npz; shape (20,144,256,3) uint8.
  • Re-compositing the extracted layers at the original position reproduces frame 0 with RMS ≈ 1.9 levels and only 2 pixels differing by >10/channel (mixed fuzz/contact boundary).
  • Strict-orange centroid per frame: x advances 8.78 px/step (e.g. 53.83 → 220.67 for the thresholded blob, expected 54.2 → 221.0), cy ≈ 50.4 constant, pixel count 87–92 throughout.
  • Outside the y 42–63 corridor the difference vs frame 0 is exactly 0 for every frame (pipe, sofa, red/brown balls, front edge untouched); the red / brown ball region changes by 0.
  • After the ball passes, vacated pixels are static (no trails): differences 0 between later frames over the start region.
  • Last frame: ball pixels fully on the table; only 3 feathered shadow pixels sit within ~1 px of the analytic edge line; pixels beyond the edge keep their original dark values.
  • No 0/0/0 or 255/255/255 artifacts in the motion corridor on any frame.

Residual imperfections: ~2 px at the fuzz/contact-shadow seam where a single linear alpha can't perfectly separate sparse fibres from shadow; a faint (~3–5 level) tonal step where inferred table meets the smooth model. Both are sub-pixel-grain magnitude and static/transient respectively.
