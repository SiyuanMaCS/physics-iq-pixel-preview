METHOD — case_0023

Task: locked-off single shot, 20 frames, 256×144 @ 4 fps (5 s). The grey tennis ball rolls out of the left-end pipe across the light-wood table toward the right. Frame 00 shows the ball already mid-table (cx = 150), so frames 01…19 continue that roll across the right half of the table. Everything is produced with local Python pixel math (numpy + PIL); no external models, engines, references or image-viewing of later frames (all later-frame checks are numeric / ASCII maps printed to the terminal).

What moves

  • Ball centre x(t) = 150.0 + 4.3158·t, y = 116.5 constant (constant depth, constant speed); centre reaches x = 232.0 at t = 19, with the sphere staying inside the measured diagonal table corner.
  • Rolling without slipping: a tennis-ball seam drawn in material coordinates rotates clockwise by θ = −Δx/r radians (r = 8 px; ≈ 1.6 turns over 5 s).
  • The contact shadow translates with the ball (the lamp is fixed).
  • Nothing else changes: wall, sofa, pipe, nightstand/lamp and table grain outside the effect corridor are byte-identical to frame 00 in every frame.

Pipeline (generate.py)

  1. Measurements — pipe (x 0…16, y 102…126), ball circle (centre (150, 116.5), r = 8, from the cool-channel mask B−R > 14), and the light-wood/dark-furniture boundary per row (used to keep effects on the table).
  2. Lighting field B(x,y): per-row least-squares linear fit of RGB against x using only frame-0 columns known to be clean (26…119 and 172…229). This removes the frame-0 ball/shadow footprint bias while retaining the strong vertical brightening and the mild horizontal gradient of the wood.
  3. Shadow layer — inside a support box (y 107…127, x 118…169, excluding the sphere) the observed multiplicative shadow is L = observed/B, clipped to [0.6, 1] and feathered to 1 at the edge. This preserves the real diagonal down-left tail and the bright occlusion core under the ball.
  4. Clean background — the ball+shadow footprint (4×4 supersampled coverage of "sphere ∪ shadow") is filled with synthetic clean wood: B(x,y) plus fine RGB residuals (grain σ ≈ 3/255) remapped from pristine wood x = 40…111 with a decorrelated index, so no visible structure (e.g. the bright reflection patch near x ≈ 170) is duplicated. Patched-zone grain σ = 2.9 vs pristine 3.0; deviation from B matches pristine percentiles.
  5. Per frame —
    • shadow layer bilinearly resampled at sub-pixel offset Δx and multiplied onto the wood, masked by the measured per-row table boundary;
    • ball sprite = the frame-0 sphere itself (identical cool-grey shading and highlight), bilinearly resampled so material point u samples frame 0 at x − Δx; a faint two-arc felt seam is added in coordinates rotated clockwise by θ; an analytic 1-px anti-aliased rim (coverage = clip(r − d + 0.5, 0, 1), 5×5 quadrature per pixel) composites the sphere over the background.
  6. Frame 00 is written from first_frame.png untouched (and frames/00.png is replaced with the original bytes, so it is byte-identical, not merely equal).
  7. artifact_io.save writes the uint32 0xRRGGBB tensor (H×W×20), the 20 PNGs, inspection.png and the standalone index.html; the script additionally writes transition_check.png (2× view with per-frame ball centroids).
