+"""PixelWorld case_0068 generation.
+
+The prompt describes a strictly static locked-off shot: the beverage dispenser
+("stationary over the glass"), basket, and half-filled glass do nothing over the
+5 s window. The physically correct continuation is 20 frames identical to the
+given first frame. This script replicates frame 0, writes all required
+artifacts via artifact_io, re-verifies the packed uint32 tensor against the
+PNGs, and renders transition_check.png.
+"""
+from pathlib import Path
+import numpy as np
+from PIL import Image, ImageDraw
+
+import artifact_io
+
+CASE = Path(__file__).resolve().parent
+N = 20
+
+first = np.array(Image.open(CASE / "first_frame.png").convert("RGB"))
+assert first.shape == (144, 256, 3) and first.dtype == np.uint8, first.shape
+
+# Static scene: every frame is an independent copy of frame 0.
+frames = np.broadcast_to(first, (N, 144, 256, 3)).copy()
+assert np.array_equal(frames[0], first)
+
+artifact_io.save(frames, CASE)
+
+# ---- verification: PNGs vs packed 0xRRGGBB tensor -----------------------
+tensor = np.load(CASE / "pixels.npz")["pixels"]            # (144,256,20) uint32
+assert tensor.shape == (144, 256, N), tensor.shape
+flat = np.transpose(tensor, (2, 0, 1)).astype(np.uint32)
+recon = np.stack([
+    np.stack([((flat[t] >> 16) & 255),
+              ((flat[t] >> 8) & 255),
+              (flat[t] & 255)], axis=-1)
+    for t in range(N)], axis=0).astype(np.uint8)
+
+packed_rgb = frames.astype(np.uint32)
+packed = ((packed_rgb[:, :, :, 0] << 16) |
+          (packed_rgb[:, :, :, 1] << 8) |
+          packed_rgb[:, :, :, 2])
+assert np.array_equal(flat, packed), "tensor does not match in-memory frames"
+
+max_diff_vs0 = []
+changed = []
+for t in range(N):
+    png = np.array(Image.open(CASE / "frames" / f"{t:02d}.png").convert("RGB"))
+    assert png.shape == (144, 256, 3)
+    assert np.array_equal(png, recon[t]), f"PNG {t:02d} != tensor"
+    assert np.array_equal(png, first), f"frame {t:02d} not identical to first"
+    max_diff_vs0.append(int(np.abs(png.astype(int) - first.astype(int)).max()))
+for t in range(1, N):
+    changed.append(int((flat[t] != flat[t - 1]).sum()))
+
+print("max abs RGB diff vs frame00 per frame:", max_diff_vs0)
+print("changed pixels per 19 transitions:", changed)
+assert set(max_diff_vs0) == {0} and sum(changed) == 0
+
+# ---- transition_check.png ----------------------------------------------
+# Panel A: frame 00. Panel B: frame 19. Panel C: amplified abs difference
+# (0 -> black, as expected for a static shot). Bottom: per-transition changed
+# pixel counts as a bar chart (all zero).
+W, H = 1024, 330
+sheet = Image.new("RGB", (W, H), (25, 28, 35))
+draw = ImageDraw.Draw(sheet)
+f0 = Image.fromarray(frames[0])
+f19 = Image.fromarray(frames[-1])
+diff = np.abs(frames[-1].astype(int) - frames[0].astype(int)).astype(np.uint8)
+# amplify for visibility (any nonzero change would become bright)
+amp = np.clip(diff.astype(int) * 8, 0, 255).astype(np.uint8)
+diffimg = Image.fromarray(amp)
+draw.text((6, 4), "frame 00 (0.00s)", fill=(255, 255, 255))

METHOD.md

METHOD

Task interpretation

prompt.txt describes a static, locked-off, single-shot scientific-demo scene filmed at a constant framerate in real time: a glass beverage dispenser (red liquid, black tap with cyan collar) resting on a woven basket, stationary over a tumbler that is already half-filled with the same red liquid. No action is described — the tap is not operated, no liquid moves, nothing enters or leaves the frame, and the camera is fixed. Under these constraints the only physically and textually faithful continuation is a motionless scene for the full 5 seconds.

Method (honest description)

  1. Numeric scene analysis only. first_frame.png (256×144 RGB) was inspected exclusively with local Python/NumPy/PIL (threshold masks, bounding boxes, per-region mean colours, an ASCII class map). No image Read/View tools were used on outputs; no external models, engines, network, references, or subagents were used. Measurements and the 20-frame plan were recorded in OBSERVATION.md before generation.
  2. Generation. generate.py loads first_frame.png and replicates it into a (20,144,256,3) uint8 array — one identical frame per timestep (0.00–4.75 s at 4 fps). No pixels are synthesised, warped, or altered: frame 00 is the exact input image, and frames 01–19 are copies.
  3. Artifacts are written by the supplied artifact_io.save: compressed pixels.npz (packed as (144,256,20) uint32 0xRRGGBB, frame axis last), frames/00.png–19.png, inspection.png (8-frame contact sheet), and a self-contained index.html player (all 19 inter-frame delta payloads are empty).
  4. Verification performed in-script:
    • every saved PNG equals the reconstructed uint32 tensor channel-unpacking;
    • every frame equals first_frame.png exactly (np.array_equal);
    • max absolute RGB difference vs frame 00 = 0 for all 20 frames;
    • uint32 changed-pixel count = 0 for all 19 transitions.
  5. transition_check.png visualises frame 00, frame 19, the 8× amplified |f19−f00| map (entirely black), a bar chart of per-gap changed-pixel counts (all zero), and the numeric PASS summary.

Result

A fully static 5-second clip: 20/20 frames pixel-identical to first_frame.png, zero inter-frame change. This matches "stationary", "fixed frame", "constant framerate in real-time", and the absence of any described action. No visual-review image tool was used (verification is numeric, as required).
