METHOD.md

METHOD — case_0026 (blue tennis ball rolls from wooden table over clear glass)

All pixels were produced by local Python operations only (numpy, Pillow, OpenCV's TELEA inpainter, least-squares fitting). No external models, engines, images, or network access were used. generate.py is fully deterministic and regenerates every artifact.

1. Geometry measured from first_frame.png

  • Ball centre (104.0, 66.6), radius 9.9 px (blue-mask analysis).
  • Table: back edge y≈46, right depth edge x≈150.5.
  • Glass quad: left edge x≈149–151, far edge y = 49 + (x−152)/1.85, near rim y = 112 + 0.114·(x−151).
  • Motion: straight rolling track aimed through the glass quad, v = (7.0, 2.2) px/frame (dy/dx = 0.314), radius 9.9 + 0.035·t (slight approach). Frame 0 is fixed byte-exact; frames 1–19 use centre (104 + 7t, 66.6 + 2.2t). The table edge is crossed at t≈6.7 and the ball finishes at (237, 108.4), fully inside the measured glass quad.

2. Static background plate

  • The frame-0 ball and both shadow lobes are removed with cv2.inpaint (TELEA, radius 4–6) to make a clean wood/glass/wall plate.
  • Horizontally streaky synthetic grain (sigma measured from a clean wood strip, 1.29 luma levels) is added only inside the feathered repair mask, so the repaired patch matches surrounding grain. Every pixel outside the repair mask is byte-identical to frame 0; the wall, table edges, glass and support legs are never touched (verified: 0 changed pixels in those regions across all 19 transitions).

3. Analytic ball (shading fitted to the real ball)

  • For each pixel in the disk bounding box, sphere normals (nx, ny, nz = sqrt(1−nx²−ny²)) are computed.
  • Body colour is a fitted linear model of features [1, nx, ny, nz, nz², spec, ao] where spec = (n·L)^18 with L = normalize(−0.42, −0.48, 0.77) (upper-left-front), and ao = clip(1.35·ny + 0.12, 0, 1)² darkens the sphere at the table contact.
  • Coefficients come from least squares against the real frame-0 ball pixels; pale felt-seam outliers are rejected on positive green excess, then the ao column is solved separately from the lower front hemisphere so the measured bottom darkening is reproduced (fit RMS ≈ 11 RGB levels on kept pixels; rendered-at-pose-0 core mean RGB differs by ≤5/2/0 from the real ball).
  • A pale tennis-seam band |lat − (0.28 + 0.05·cos(2·lON))| < 0.15 (soft edge 0.06, 35% blend toward RGB(95,108,150)) is painted in body coordinates and rotated by the rolling angle θ = t·|v|/10.05 ≈ 0.73 rad/frame (about 2.2 turns over the clip).
  • Edge anti-aliasing uses a 1.8 px soft coverage ramp; motion blur is a 5-sample average over a 30%-shutter along-track interval (~2.2 px smear, matching the blur visible in frame 0).

4. Contact shadow (fitted to frame 0)

  • A clean-wood reference is made by inpainting ball + both shadow lobes.
  • Two smoothstep ellipses: a contact patch (offset (7,8), radii (11,7)) and a cast trail (offset (20,4), radii (15,10)). Per-channel amplitudes are solved by least squares on visible wood pixels outside the disk: contact ≈ (0.34, 0.32, 0.15), trail ≈ (0.17, 0.18, 0.16).
  • The shadow travels with the ball (same 3-sample motion averaging), at full strength on wood and 45% on the translucent glass; it is suppressed outside the two surfaces so it never spills onto wall or the support legs.
