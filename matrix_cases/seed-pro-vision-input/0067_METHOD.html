+exactly.
+"""
+from pathlib import Path

+import numpy as np
+from PIL import Image, ImageDraw
+
+import artifact_io
+
+CASE = Path(__file__).resolve().parent
+N_FRAMES, W, H = 20, 256, 144
+
+
+def load_first_frame() -> np.ndarray:
+    frame = np.array(Image.open(CASE / "first_frame.png").convert("RGB"))
+    assert frame.shape == (H, W, 3) and frame.dtype == np.uint8, frame.shape
+    return frame

+def build_frames(first: np.ndarray) -> np.ndarray:
+    """Stationary scene: every frame is the input frame."""
+    return np.repeat(first[None], N_FRAMES, axis=0)

+def make_transition_check(frames: np.ndarray, out: Path) -> None:
+    """Diagnostic panel: first vs last frame, amplified |delta|, and a bar
+    chart of mean absolute pixel change for all 19 transitions."""
+    pad, bar_h = 18, 26
+    panel = Image.new("RGB", (W * 3, H + pad + bar_h), (25, 28, 35))
+    draw = ImageDraw.Draw(panel)
+
+    f0, f19 = frames[0], frames[-1]
+    diff = np.abs(f0.astype(np.int16) - f19.astype(np.int16)).astype(np.uint8)
+    # Amplify so even sub-percent motion would be visible; zero stays black.
+    amplified = np.clip(diff.astype(np.int32) * 8, 0, 255).astype(np.uint8)
+
+    titles = ["frame 00 (0.00s)", "frame 19 (4.75s)", "|f19 - f0| x8"]
+    for i, img in enumerate((f0, f19, amplified)):
+        x = i * W
+        draw.text((x + 4, 3), titles[i], fill=(235, 240, 250))
+        panel.paste(Image.fromarray(img), (x, pad))
+
+    # Per-transition mean absolute change across all channels.
+    deltas = np.abs(frames[1:].astype(np.int32) - frames[:-1].astype(np.int32))
+    means = deltas.reshape(N_FRAMES - 1, -1).mean(axis=1)
+    base_y = H + pad + bar_h - 4
+    chart_w = W * 3 - 16
+    draw.text((4, H + pad + 2),
+              "mean |delta| per transition (01<-00 ... 19<-18), max = "
+              f"{means.max():.4f}", fill=(235, 240, 250))
+    for i, m in enumerate(means):
+        x0 = 8 + i * chart_w // (N_FRAMES - 1)
+        x1 = 8 + (i + 1) * chart_w // (N_FRAMES - 1) - 1
+        h = int(round(min(m, 3.0) / 3.0 * (bar_h - 12))) if m > 0 else 0
+        draw.rectangle((x0, base_y - h, x1, base_y), fill=(120, 200, 120))
+    draw.line((8, base_y, W * 3 - 8, base_y), fill=(150, 160, 175))
+
+    panel.save(out)
+

+def pack_rgb(frames: np.ndarray) -> np.ndarray:
+    p = frames.astype(np.uint32)
+    return (p[..., 0] << 16) | (p[..., 1] << 8) | p[..., 2]

METHOD.md

METHOD — case_0067

What the prompt asks for

prompt.txt describes a static, locked-off, fixed-frame single shot at a constant framerate: a ribbed glass beverage dispenser full of bright red liquid stands on a woven basket, with a half-filled glass of the same liquid in front, and states explicitly that the dispenser is stationary over the glass. No pouring, hand, camera move, or other event is described.

Decision: a frozen 5-second clip

Because every element is declared stationary and the camera is fixed, the physically and textually faithful continuation contains zero motion. Any invented ripple, pour, highlight flicker, or sensor-noise simulation would add a motion source the prompt does not provide (and would risk contradicting the ground truth of a static setup). Therefore all 20 frames are exact copies of first_frame.png. This also makes the mandated frame-00 identity exact rather than approximate.

Measurements (local Python only: PIL + numpy)

Recorded in OBSERVATION.md before coding, from numeric masks and edge profiles on the 256×144 input:

  • wall / table geometry (rear table edge ≈ y 77–89),
  • basket extent (x ≈ 63–183, y ≈ 45–86),
  • dispenser body (x ≈ 98–173), liquid level edge at y ≈ 33–35,
  • spigot cluster (x ≈ 145–181, y ≈ 35–60),
  • glass (x ≈ 143–181, rim y ≈ 64, base y ≈ 139) with liquid from y ≈ 93 to y ≈ 138, i.e. ≈ 61 % fill ("half-filled"),
  • representative colors (dispenser red ≈ (108,14,7), glass red ≈ (116,16,0), warm table wood ≈ (116,89,63), cool gray wall with light from the right).

These measurements confirm the prompt's layout and that no level change, stream, or displaced object is present; they drive the "no event" plan.

Generation (generate.py, honest method statement)

  1. Decode first_frame.png to a uint8 H×W×3 array and assert 144×256×3.
  2. Build the clip with np.repeat(first[None], 20, axis=0) — pure local pixel operation, no drawing, warping, inpainting, external model, engine, or network access. Nothing is altered: no colors, highlights, or edges change.
  3. artifact_io.save(...) writes:
    • pixels.npz — uint32 tensor of shape (144, 256, 20) packed as 0xRRGGBB (HWC, frame-major transpose of the RGB stack),
    • frames/00.png … frames/19.png (each the exact input frame),
    • inspection.png — 8-frame contact sheet at frames 0,2,5,8,11,14,17,19,
    • index.html — the self-contained player built from player_template.html; with zero changes every one of its 19 delta payloads is an empty packet.
  4. transition_check.png (768×188) is a diagnostic panel: frame 00, frame 19, and 8 × |f19 − f0| (which is entirely black), plus a chart of mean absolute change for all 19 transitions — all zero.

Verification (all numeric, no image viewing of outputs)

  • In generate.py: the saved pixels.npz tensor is unpacked from 0xRRGGBB back to RGB and compared element-wise with the in-memory frames; each of the 20 PNGs is re-decoded and compared to its frame; frames/00.png is compared to first_frame.png; every consecutive-frame difference is asserted empty.
  • Independently re-checked after generation: the JSON/base64 payload embedded in index.html was decoded exactly like the player's JavaScript (little- endian Uint32, sequential delta application). All 20 decoded frames match both the tensor planes and the PNG files; the caption matches prompt.txt; all 19 delta packets decode to zero bytes.
  • transition_check.png was checked numerically: panels 0 and 1 equal frame 00 and the amplified-difference panel contains only black pixels.

Result: 20/20 frames, 4 fps, 5.00 s; frame 00 equals the supplied frame exactly and the scene remains perfectly stationary throughout, as specified.
