duck-static · 生成方法

The sequence is a pixel-exact static continuation of first_frame.png.

The source PNG is loaded as an 8-bit RGB array and duplicated into 20 frames. This is intentional rather than an animation shortcut: the prompt states that the shot is locked off, the frame is fixed, the framerate is constant, and the rubber duck is stationary. With no described external force, illumination change, or camera movement, the physically consistent continuation is an unchanged scene for all five seconds.

artifact_io.save writes the 20 PNG files, packs them into the required height × width × time uint32 tensor using 0xRRGGBB, creates the inspection contact sheet, and embeds the lossless frame stream in the standalone HTML player. The generator separately creates transition_check.png, whose lower row shows 8×-amplified absolute pixel differences for representative adjacent frames. Each is black and labeled with zero changed pixels.

Finally, the script reopens every PNG and pixels.npz, reconstructs the expected packed representation, and asserts exact array equality. It also asserts that frame 00 is identical to the input.
