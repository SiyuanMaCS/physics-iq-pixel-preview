+"""Generate a five-second locked-off continuation from the supplied first frame.
+
+The scene is intentionally static.  All generated variation is an analytic,
+deterministic model of tiny sensor noise and sub-code-value lamp fluctuation;
+no object pixels are translated, warped, synthesized, or inpainted.
+"""
+

+import shutil

+from PIL import Image, ImageDraw

+ROOT = Path(__file__).resolve().parent
+SOURCE = ROOT / "first_frame.png"

+def make_frames(source: np.ndarray) -> np.ndarray:
+    """Return 20 RGB uint8 frames with exactly preserved scene geometry."""
+    assert source.shape == (144, 256, 3) and source.dtype == np.uint8
+    height, width, _ = source.shape
+    yy, xx = np.mgrid[0:height, 0:width]
+
+    # A broad, feathered illumination field.  Its peak effect is one digital
+    # code value, and it is zero in frame 0.  It changes brightness only, never
+    # the location or silhouette of any scene element.
+    lamp_field = np.exp(
+        -(((xx - 54.0) / 102.0) ** 2 + ((yy - 43.0) / 78.0) ** 2)
+    )
+    lamp_field *= 0.72
+
+    frames = np.empty((20, height, width, 3), dtype=np.uint8)
+    frames[0] = source
+
+    # Fixed seed makes every run reproducible.  Sparse one-code-value noise is
+    # enough to keep a real-time sensor texture without visible flicker.
+    rng = np.random.default_rng(187)
+    phases = np.sin(np.linspace(0.0, 2.0 * np.pi, 20, endpoint=False))
+    src16 = source.astype(np.int16)
+    for t in range(1, 20):
+        frame = src16.copy()
+
+        # Slow illumination breathing: at most +/-1, spatially feathered.
+        drift = np.rint(lamp_field * phases[t]).astype(np.int16)
+        frame += drift[..., None]
+
+        # Sparse, unbiased RGB sensor noise.  Most pixels do not change and no
+        # channel changes by more than one additional code value.
+        selector = rng.random((height, width, 1))
+        signs = rng.choice(np.array([-1, 1], dtype=np.int16),
+                           size=(height, width, 1))
+        grain = np.where(selector < 0.055, signs, 0)
+        # Slightly correlated color channels are more camera-like than three
+        # unrelated noise layers; apply the same tiny offset to R, G, and B.
+        frame += grain
+        frames[t] = np.clip(frame, 0, 255).astype(np.uint8)
+
+    return frames
+

OBSERVATION.md

Scene observation and event plan

Source measurements

  • Source: first_frame.png, RGB, 256 x 144 pixels. The entire source frame is the immutable camera view; there is no crop, pan, zoom, or camera shake.
  • Composition: a warm brown wooden tabletop occupies roughly y=77..143, with a diagonal rear edge from about (0, 94) to (181, 76) to (255, 96). A soft gray wall fills the background. A thin near-black horizontal strip crosses the top edge.
  • Yellow mug: body spans approximately x=117..144 and y=69..101; its base rests near y=101. The orange-yellow handle spans approximately x=143..152 and y=73..94. The handle remains visible to the right.
  • Kettlebell: black body spans approximately x=105..153 and y=24..74. Its lower face sits directly on the mug rim around y=69..74. The handle rises from the shoulders and is clipped by the top of frame, spanning about x=99..155 and y=0..45. A small teal 30LB marking is visible near x=137..148, y=50..56.
  • The load is visually centered over the mug body. No hands or other actors are present. The mug has no visible crack, deformation, or spill.
  • Lighting: soft illumination from the upper left produces broad pale patches on the wall and a diffuse shadow under/behind the mug and kettlebell. The scene has modest low-light grain and smooth tonal falloff.
  • Physics: a ceramic vessel can withstand a large static axial compressive load when the load is centered and the rim is intact. The prompt describes the kettlebell as already placed on top, so the faithful continuation is a stable hold rather than an invented impact, collapse, or removal.

20-frame event plan (4 fps, 5 seconds)

  • Frame 00 (t=0.00 s): exact source image, byte-for-byte pixel equality.
  • Frames 01-03 (t=0.25..0.75 s): locked-off hold. Mug, kettlebell, table edge, contact point, and shadows remain fixed. Only sub-visible-to-very-subtle sensor/lamp variation is permitted.
  • Frames 04-07 (t=1.00..1.75 s): same stable scientific demonstration; no cracking, sliding, rotation, or camera movement.
  • Frames 08-11 (t=2.00..2.75 s): same stable hold; very gentle deterministic luminance drift stays well below the level of an object change.
  • Frames 12-15 (t=3.00..3.75 s): same composition and contact geometry; low-amplitude grain evolves naturally without accumulating or crawling at edges.
  • Frames 16-19 (t=4.00..4.75 s): unchanged equilibrium through the end of the shot. Illumination variation eases back toward the source appearance for a seamless loop.

The continuation deliberately contains no new objects or actions. It depicts the requested static experiment for the full real-time duration.

METHOD.md

Method

This continuation is produced entirely with local deterministic pixel operations in generate.py.

The supplied first_frame.png is loaded as an RGB uint8 array and used directly as frame 00. The scene geometry is never moved, warped, redrawn, or inpainted. Frames 01-19 keep the same mug, kettlebell, contact point, table, wall, shadows, and fixed camera view. The only temporal changes are a feathered analytic illumination field and sparse monochromatic sensor grain. Both are limited to tiny integer code-value offsets; the random component uses a fixed seed (187) for reproducibility. This represents normal live-camera texture while leaving the requested static demonstration unchanged.

artifact_io.save writes the uint32 packed 0xRRGGBB tensor, the 20 PNG frames, the inspection sheet, and the standalone HTML player. The original source file is then copied over frames/00.png so frame 00 is also file-identical to the supplied PNG, not merely pixel-identical. transition_check.png shows representative frames, amplified frame-to-source differences, and a magnified timeline of the kettlebell/mug contact area.

The generator finishes by decoding every PNG and comparing it pixel-for-pixel with the in-memory frames, then independently reconstructs the packed tensor and compares it with pixels.npz. It also asserts frame 00 equality with first_frame.png.
