lit-candle · 生成方法

The continuation is made entirely with deterministic local pixel operations in generate.py.

  1. first_frame.png is decoded as RGB and used as the immutable photographic source.
  2. Frame 00 is copied byte-for-byte from that RGB source.
  3. For frames 01–19, a compact smooth inverse warp is applied around the burning left flame. The warp is anchored at the wick so the base does not slide. Per-frame vertical scale, upper-tip lean, and a smaller mid-flame bend simulate quiet buoyant flicker.
  4. The deformation fades continuously into the surrounding wall and reaches zero at the wick. It therefore reuses the actual photographed flame, blur, halo, and sensor texture rather than drawing or importing a new flame. The candle body, holder, unlit right candle, table, and camera framing remain unchanged.
  5. A very small warm luminance modulation (only a few RGB code values) is weighted by the source flame brightness and existing halo. This gives the local light a natural response without global exposure changes.
  6. Cubic sampling is performed with SciPy; array processing uses NumPy; Pillow writes the required images. No external model, asset, mask, reference, network service, or rendering engine is used.

artifact_io.save writes the PNG sequence, packed uint32 tensor, inspection sheet, and standalone player. The generator additionally creates transition_check.png, then reloads all artifacts and verifies shape, mode, exact frame-00 equality, PNG/tensor pixel identity, non-static transitions, and that all animated pixels stay inside the intended left-flame neighborhood.
