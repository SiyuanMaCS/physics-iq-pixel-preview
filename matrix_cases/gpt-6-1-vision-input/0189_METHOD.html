+def transition_sheet(frames):
+    """Write source pairs and literal absolute RGB differences, without viewing."""
+    transitions = [(0, 1), (1, 2), (9, 10), (18, 19)]
+    sheet = Image.new("RGB", (768, 4 * 172 + 28), (25, 28, 35))
+    draw = ImageDraw.Draw(sheet)
+    draw.text((8, 7), "Before | After | Absolute RGB difference (no amplification)", fill="white")
+    stats = []
+    for row, (before, after) in enumerate(transitions):
+        difference = np.abs(frames[after].astype(np.int16) - frames[before].astype(np.int16))
+        changed = int(np.any(difference != 0, axis=2).sum())
+        maximum = int(difference.max())
+        y = 28 + row * 172
+        draw.text((8, y + 3), f"Frame {before:02d} at {before / FPS:.2f} s", fill="white")
+        draw.text((264, y + 3), f"Frame {after:02d} at {after / FPS:.2f} s", fill="white")
+        draw.text((520, y + 3), f"Changed pixels: {changed}; max: {maximum}", fill="white")
+        sheet.paste(Image.fromarray(frames[before]), (0, y + 23))
+        sheet.paste(Image.fromarray(frames[after]), (256, y + 23))
+        sheet.paste(Image.fromarray(difference.astype(np.uint8)), (512, y + 23))
+        stats.append({"before": before, "after": after, "changed_pixels": changed,
+                      "max_rgb_difference": maximum})
+    sheet.save(ROOT / "transition_check.png")
+    return stats

METHOD.md

Actual method

This is a source-pixel hold of a static equilibrium, implemented with local Python, NumPy, and Pillow. Every output frame is an exact RGB copy of first_frame.png. No generative model, external engine, network, external reference, segmentation mask, image inpainting, or synthesized motion was used.

The initial attached image shows the kettlebell already contacting the upright mug, centered within its footprint. The prompt specifies placement but does not specify dropping, a crack, or a failure. The continuation therefore holds the loaded setup stationary. A 30 lb kettlebell supplies about 133.4 N, which an intact upright ceramic mug can plausibly support under centered loading. This is an interpretation of the visible setup, not a material-strength measurement or a mechanical simulation of an actual mug. The unknown material properties and initial motion cannot be recovered from one frame. No subpixel elastic deformation is rendered.

OBSERVATION.md was written before generate.py, with scene measurements, physical assumptions, and all 20 planned sample times. generate.py loads the source in RGB mode, repeats its uint8 pixel array 20 times, and calls the supplied output-only artifact_io.save helper. The helper writes the packed tensor, PNG frames, contact sheet, and standalone HTML player. The generator also writes transition_check.png and independently validates the saved outputs.
