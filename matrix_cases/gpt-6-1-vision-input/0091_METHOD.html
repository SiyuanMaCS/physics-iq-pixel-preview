+def smoothstep(lo, hi, values):
+    t = np.clip((values - lo) / (hi - lo), 0, 1)
+    return t*t*(3-2*t)

+def generate(original):
+    a = original.astype(np.float64)
+    yy, xx = np.mgrid[:144, :256].astype(np.float64)
+    anchor_x, anchor_y = 131.3, 30.0
+    # Feathered local support, fully covering the moving flame and its halo.
+    support = (1-smoothstep(9.0,19.0,np.abs(xx-anchor_x)))
+    support *= smoothstep(1.0,8.0,yy)
+    support *= 1-smoothstep(28.0,30.0,yy)
+    # A fitted wall plane supplies only the reference for varying emission.
+    # Sampling strips stay away from the flame, flare and candle tops.
+    wall_samples = (((xx>=149)&(xx<=175)&(yy>=2)&(yy<=29)) |
+                    ((xx>=80)&(xx<=101)&(yy>=16)&(yy<=29)))
+    design = np.stack([np.ones_like(xx),xx-anchor_x,yy-20],axis=-1)
+    coefficients = np.linalg.lstsq(design[wall_samples],a[wall_samples],rcond=None)[0]
+    ambient = np.einsum('hwk,kc->hwc',design,coefficients)
+    # Light support touches only the wall above the solid candle tops.
+    glow_support = np.exp(-0.5*((xx-anchor_x)/24)**2-0.5*((yy-20)/19)**2)
+    glow_support *= 1-smoothstep(28,31,yy)

+        # the base; the very lower flame is feathered into the original wick.
+        sy = anchor_y + (yy-anchor_y)/height

METHOD.md

Method

The continuation depicts the left candle continuing to burn with gentle flicker for five seconds. The right candle stays unlit. The camera, candles, holders, tabletop, wall geometry, and shadows remain stationary. No further interaction was inferred from the prompt.

Actual pixel construction

generate.py reads only first_frame.png as scene imagery and uses the event parameters recorded in OBSERVATION.md. It constructs frames with NumPy and SciPy, using bilinear inverse resampling of the original photographed flame. The transformation varies height by −7% to +11%, width by −7% to +9%, and tip lean by −1.30 to +1.35 pixels. Displacement diminishes toward the wick at approximately (131.3, 30). Smooth analytic masks feather the transformed region into the original wall and make all pixels at y ≥ 29 stationary.

For illumination variation, a least-squares RGB plane is fitted to two original wall strips away from the flame and flare. The positive difference from that plane estimates an emission residual. A gain between 0.967 and 1.029 adjusts that residual in the flame patch and an analytically feathered local halo. The plane is a photometric reference; it does not replace the wall. The photographed flame colors and original surrounding detail supply the resulting pixels.

Frame 00 is the untouched source array. The subsequent frames are rounded and clipped to RGB uint8. This is a local photographic pixel animation motivated by stable candle combustion, not a fluid simulation. No network, additional references, learned models, external engines, or subagents were used.
