METHOD.md

Method

Generated entirely within this workspace using Python, NumPy, SciPy, and Pillow. The only scene inputs were first_frame.png and prompt.txt. No external models, engines, reference imagery, network calls, or subagents were used. The attached initial frame informed the scene interpretation. Generated outputs were inspected using local code and numeric checks only; neither generated sheet was opened with an image viewing tool.

The tennis ball is approximated as an orthographically projected sphere with center (139.0, 64.4) and image radii (17.1, 17.5). Camera coordinates point right, up, and toward the viewer. Its upright axis is inclined 23 degrees toward the camera. Rodrigues rotation gives a constant clockwise turn, viewed from above the platform, at 9 degrees per second. The sequence samples 0 through 4.75 seconds at 0.25-second intervals, reaching 42.75 degrees in frame 19. Each frame displays for 0.25 seconds, giving five seconds of playback.

A robust smooth RGB lighting field is fitted to 656 unmarked felt pixels. A Gaussian normalized correction retains the photograph's broader shading. Dividing the supplied surface pixels by that field produces a color/albedo texture containing the original smiley, seam, and felt details. Every destination surface normal is inverse-rotated, projected into the original photograph, and sampled with bilinear interpolation. Pixel-center sampling avoids leaving a stationary blur residual around the original printed face. The light field stays fixed while the surface texture rotates.

The source texture is restricted to reliable interior pixels. At the original occluding contour it blends into estimated plain yellow-green felt with a deterministic, small-amplitude mathematical grain attached to the sphere. This fills newly revealed surface; its exact hidden appearance cannot be recovered from one photograph. The original visible seam and face are transported from the actual input pixels. This is an image-based mathematical continuation, not a recovered physical 3D model of the hidden ball.

The rendered surface change relative to its zero-angle reconstruction is composited onto the original photograph. A narrow fixed rim protects the original antialiasing, silhouette, and contact region. All changes are confined to x=122–156, y=47–81. The desk, wall, black platform, cable, and surrounding shadows retain their supplied pixels. Frame 00 is copied directly from the input PNG, preserving both decoded pixels and file bytes.
