+def segment_wrench(rgb: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
+    """Return a soft foreground alpha and an inpainted clean plate.
+
+    Segmentation is constrained to the measured wrench area so similarly cool
+    pixels elsewhere (platform and magnet) cannot enter the mask.
+    """
+    h, w = rgb.shape[:2]
+    yy, xx = np.mgrid[:h, :w].astype(np.float32)
+
+    # Support consists of the open-end/head and the diagonal metal handle.
+    head = ((xx - 147.5) / 9.5) ** 2 + ((yy - 53.5) / 7.5) ** 2 <= 1.0
+    ax, ay, bx, by = 149.0, 53.0, 177.0, 65.5
+    vx, vy = bx - ax, by - ay
+    t = np.clip(((xx - ax) * vx + (yy - ay) * vy) / (vx * vx + vy * vy), 0, 1)
+    distance = np.hypot(xx - (ax + t * vx), yy - (ay + t * vy))
+    support = head | (distance <= 6.0)
+
+    f = rgb.astype(np.float32)
+    lum = 0.2126 * f[..., 0] + 0.7152 * f[..., 1] + 0.0722 * f[..., 2]
+    cool = f[..., 2] - f[..., 0]
+    # Metal highlight seeds: substantially brighter/cooler than its platform.
+    seed = support & (((lum > 70) & (cool > 18)) | (lum > 96))
+    seed_u8 = seed.astype(np.uint8) * 255
+    seed_u8 = cv2.morphologyEx(seed_u8, cv2.MORPH_CLOSE, np.ones((3, 3), np.uint8))
+
+    # Encompass antialiasing, the dark metal rim, and its tiny source shadow.
+    removal = cv2.dilate(seed_u8, np.ones((5, 5), np.uint8), iterations=1)
+    removal = cv2.bitwise_and(removal, support.astype(np.uint8) * 255)
+    clean_bgr = cv2.inpaint(cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR), removal, 4, cv2.INPAINT_TELEA)
+    clean = cv2.cvtColor(clean_bgr, cv2.COLOR_BGR2RGB)
+
+    # Difference from the locally reconstructed plate supplies a natural soft
+    # alpha, retaining fine jaws/highlights without rotating a rectangular crop.
+    delta = np.linalg.norm(f - clean.astype(np.float32), axis=2)
+    alpha = np.clip((delta - 2.0) / 10.0, 0.0, 1.0)
+    alpha *= (removal > 0)
+    # Keep strong seed pixels opaque; softly include the antialiased boundary.
+    alpha = np.maximum(alpha, (seed_u8.astype(np.float32) / 255.0) * 0.96)
+    alpha = cv2.GaussianBlur(alpha, (3, 3), 0.48)
+    alpha *= cv2.dilate((removal > 0).astype(np.uint8), np.ones((3, 3), np.uint8))
+    return np.clip(alpha, 0, 1).astype(np.float32), clean

METHOD.md

Method

Source inspection

I inspected first_frame.png only through local numeric RGB operations: image metadata, channel statistics, quantized block maps, luminance maps, color-difference maps, gradients, connected spatial regions, and coordinate samples. I did not use an image Read/View tool and do not claim visual review.

Those measurements located the fixed pivot at (161.5, 58.5), the wrench around x=140–181/y=47–69 after soft-edge extraction, the stationary magnet to its left, and the dark platform behind it.

Pixel generation

  1. generate.py loads the supplied image as an 8-bit RGB array.
  2. Wrench segmentation is restricted to a measured elliptical head region plus a six-pixel-radius diagonal handle corridor. Within that support, cool high-luminance metal pixels seed the mask.
  3. A 5×5 dilation includes antialiased edges, the dark metal rim, and the tiny source contact shadow. OpenCV TELEA inpainting with radius 4 reconstructs only the platform under that footprint.
  4. The RGB difference between the source and reconstructed clean plate creates a soft foreground alpha; strong metal seeds remain nearly opaque. This avoids rotating a rectangular background patch.
  5. The source foreground is premultiplied by alpha and rotated around the fixed pivot with bicubic resampling. Screen-space clockwise rotation is implemented as a negative OpenCV angle.
  6. Angular progress follows smoothstep u²(3−2u) from 0° to 131° across frames 00–19. The pivot, camera, crop, platform, magnet, illumination, and all other pixels remain fixed.
  7. A blurred 20%-strength copy of the rotated alpha, offset one pixel downward, supplies a restrained contact shadow. The premultiplied foreground is composited over the clean plate.
  8. Frame 00 bypasses reconstruction/compositing and is the untouched source array.

Output and verification

  • Output is 20 RGB frames at 256×144 and 4 fps (5 seconds).
  • artifact_io.save packs the frames into a (144, 256, 20) uint32 tensor using 0xRRGGBB, writes all PNGs, creates the inspection contact sheet, and embeds the tensor deltas in the standalone player.
  • transition_check.png shows selected before/after frames and 5× magnified absolute RGB differences for numeric transition diagnosis.
  • The generator reloads every PNG and unpacks every pixels.npz value, asserting equality to the generated RGB tensor.
  • frames/00.png is pixel-identical and also byte-identical to first_frame.png (matching SHA-256: 8df87b069a40f4cbec2eeecb6dc12b367c71492941ea22fabc590a2bcf7be2d8).
  • Meaningful changes stay in the wrench motion region. The extracted wrench principal axis advances from 23.09° to 154.08° in screen coordinates, confirming 131° clockwise rotation. Successive transitions change 487–658 pixels, with smooth acceleration and deceleration and no dropped/static intermediate frame.
