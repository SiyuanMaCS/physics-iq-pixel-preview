lit-candle · 生成方法

What was generated

The sequence is a conservative continuation of the supplied locked-off scene. The left candle remains lit and its flame flickers naturally for 5 seconds. The right candle remains unlit. Both candle bodies, both holders, the tabletop, background, and framing remain fixed.

Pixel-generation method

  1. first_frame.png was loaded locally as an RGB uint8 array. No outside imagery, models, masks, engines, or reference cases were used.
  2. Scene geometry was determined through numeric RGB statistics, color masks, connected components, coordinate profiles, and text/ASCII summaries of pixel classes. The source image was not opened with an image viewing tool.
  3. Frame 00 is an exact pixel copy of the source array.
  4. For frames 01-19, a 34 x 29 pixel region around the existing left flame is resampled with a deterministic elastic warp:
    • the pivot is fixed at the flame/wick junction near (93.3, 30.2);
    • horizontal displacement increases smoothly from zero at the wick to at most about two pixels at the tip;
    • height and width vary by small, hand-authored amounts;
    • cubic interpolation preserves the photographed antialiasing and soft tonal transitions;
    • a feathered spatial mask blends the warped patch into the unchanged wall.
  5. A very small analytic radial illumination variation (generally below two RGB code values per channel) is applied around the flame. It is clipped above the candle top and never reaches the right candle or either holder.
  6. All resulting RGB values are rounded, clipped to 0-255, and stored as uint8.

The motion parameters are deliberately aperiodic over the 20 frames. Only ordinary combustion is animated because the prompt describes no person, ignition action, air source, camera movement, or interaction with the unlit candle.

Output and validation

artifact_io.save writes the 20 PNGs, packed uint32 0xRRGGBB tensor, inspection sheet, and standalone HTML player. generate.py additionally writes an amplified consecutive-difference atlas to transition_check.png.

The generator verifies all of the following after saving:

  • array shape is 20 x 144 x 256 x 3 and pixel type is uint8;
  • frame 00 exactly matches the source RGB pixels;
  • every saved PNG reloads to the generated RGB frame exactly;
  • pixels.npz has shape 144 x 256 x 20 and dtype uint32;
  • every tensor value exactly matches its corresponding PNG's packed 0xRRGGBB value.

Numeric inspection found each transition changes only 507-724 pixels. All changes from the source are contained within x=78-108 and y=6-33, confirming that the unlit candle, holders, tabletop, and rest of the scene stay locked.
