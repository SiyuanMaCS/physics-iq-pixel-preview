METHOD.md

Method

The sequence is a deterministic local pixel animation derived only from first_frame.png and the prompt.

  1. The source PNG is decoded to a 256 x 144 RGB uint8 array. Numeric color masks, connected-component extents, RGB samples, and row/column maps locate the glass, green level marking, liquid, grabber, and paper.
  2. A clean plate is estimated only where the top-entering grabber and paper hide the smooth wall. For each affected row, a quadratic RGB illumination profile is fitted from unobscured pixels on both sides. Soft measured removal masks blend that estimate into the source; the glass and all lower scene pixels remain sourced from frame 00.
  3. The two grabber parts use soft mattes derived from their RGB distance to that estimated wall inside measured geometric envelopes. The crumpled paper uses a soft hand-measured silhouette so both pale highlights and gray folds remain attached.
  4. Local affine warps animate the jaws opening and retracting upward. A gravity-shaped center path moves the paper downward with small rotations. On contact, vertical compression and a damped position curve make it crumple and bob rather than pass rigidly through the water.
  5. Analytic elliptical highlight/trough fields create a localized surface ripple. The submerged portion of the paper is depth-tinted toward the source liquid's cyan-blue and has slightly reduced opacity to model water filtering.
  6. Frame 00 is assigned directly from the decoded source array. artifact_io.save writes the PNG sequence, packed uint32 0xRRGGBB tensor, inspection sheet, and standalone player. A separate transition sheet shows selected before/after pairs and enhanced numeric delta maps.

No image Read/View tool, external model, external engine, network resource, other case, reference image, or subagent was used. The source was inspected numerically, so no claim of visual review is made.

Run with:

python3 generate.py

The script asserts source equality for frame 00 and verifies every saved RGB PNG against the packed uint32 tensor.
