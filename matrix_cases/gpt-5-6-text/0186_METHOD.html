+def ease(t: float) -> float:
+    t = max(0.0, min(1.0, t))
+    return t * t * (3.0 - 2.0 * t)
+

+def blend_rgb(dst: np.ndarray, color, alpha: np.ndarray) -> np.ndarray:
+    """Alpha blend a constant RGB color into a float32 RGB image."""
+    a = np.clip(alpha, 0.0, 1.0)[..., None]
+    return dst * (1.0 - a) + np.asarray(color, np.float32) * a
+
+
+def blend_image(dst: np.ndarray, src: np.ndarray, alpha: np.ndarray) -> np.ndarray:
+    a = np.clip(alpha, 0.0, 1.0)[..., None]
+    return dst * (1.0 - a) + src * a
+
+
+def hi_mask(draw_fn, blur=0.0) -> np.ndarray:
+    """Draw at 4x and return a smooth native-resolution 0..1 mask."""
+    canvas = Image.new("L", (W * SS, H * SS), 0)
+    draw = ImageDraw.Draw(canvas)
+    draw_fn(draw)
+    arr = np.asarray(canvas, np.float32) / 255.0
+    arr = cv2.resize(arr, (W, H), interpolation=cv2.INTER_AREA)
+    if blur > 0:
+        arr = cv2.GaussianBlur(arr, (0, 0), blur)
+    return np.clip(arr, 0.0, 1.0)
+
+
+def line_mask(points, width: float, fill=255, blur=0.0) -> np.ndarray:
+    pts = [(int(round(x * SS)), int(round(y * SS))) for x, y in points]
+    return hi_mask(
+        lambda d: d.line(pts, fill=fill, width=max(1, int(round(width * SS))), joint="curve"),
+        blur,
+    )

+    b = tuple(int(round(v * SS)) for v in box)

+        else:

OBSERVATION.md

PixelWorld-Text Observation and Event Plan

Numeric scene observations

Inspection method: local Python/Pillow/OpenCV array analysis only (RGB samples, color clustering, Canny components, and Hough line coordinates). The source image was not opened with an image viewing or image-reading tool.

  • Source: first_frame.png, RGB, 256 x 144.
  • Camera: locked-off landscape frame. All source pixels should remain fixed except the physically affected outlet-to-glass region.
  • Broad layout: a cool gray/light upper background transitions to a warm brown wooden support surface in the lower half. A dark dispenser body/edge occupies much of x=0–60. The active dispenser hardware lies in the central zone.
  • Outlet/hardware evidence: a connected dark fitting occupies approximately x=118–137, y=31–58. Its lower silhouette tapers leftward through x=118–125 and ends near (121,58), identifying the discharge point. Longer edges farther right belong to overlapping glass/dispenser structure and background detail rather than the nozzle tip.
  • Receiving glass evidence: a bright rim response occurs near y=75, the warm red/orange beverage begins around y=79–80, and the strong right wall continues near x=137 through y=119. Slanted lower/base responses run through x=108–139 near y=130–139. The receiving glass is therefore approximately x=96–139, y=74–139, with an active liquid interior conservatively bounded to x=101–136, y=78–130 so that the existing rim and wall edges remain visible.
  • Existing beverage: warm grapefruit/orange-red pixels dominate the lower glass region. The animation should increase the liquid level while slightly diluting/desaturating the upper mixture, never replacing the glass with a flat graphic.
  • Water appearance: a narrow, translucent, slightly wavering vertical stream, bright only at its specular core; local source pixels remain visible through it. Small splash/ripple highlights should remain inside the rim.
  • Lighting: subdued indoor light. The global RGB mean is approximately (120,100,86); upper regions are neutral gray, while the support and juice are warm. Added water highlights should therefore be neutral/cool, low-opacity, and no brighter than plausible source highlights.

Twenty-frame event plan (4 fps, 5 seconds)

  • Frame 00 (0.00 s): exact unmodified source frame; no synthetic pixels.
  • Frame 01 (0.25 s): a first small droplet forms at the outlet.
  • Frame 02 (0.50 s): droplet elongates and begins falling toward the rim.
  • Frame 03 (0.75 s): a thin intermittent stream bridges most of the gap.
  • Frame 04 (1.00 s): continuous narrow water stream reaches the glass; tiny impact glint.
  • Frame 05 (1.25 s): steady flow; first subtle surface ripple; level starts rising.
  • Frame 06 (1.50 s): steady flow; surface rises slightly and the upper juice band begins to lighten.
  • Frame 07 (1.75 s): stream wavers by about one pixel; two small ripple arcs appear.
  • Frame 08 (2.00 s): continued pour; mixture level rises; faint entrained bubbles near impact.
  • Frame 09 (2.25 s): steady pour; ripple phase advances; dilution band deepens.
  • Frame 10 (2.50 s): stream remains continuous; surface reaches the middle-upper interior.
  • Frame 11 (2.75 s): small specular pulse travels down the stream; bubbles descend/fade.
  • Frame 12 (3.00 s): continued pour; juice-water mixing is visible as a softly stratified gradient.
  • Frame 13 (3.25 s): liquid level rises again; ripple width gently expands.
  • Frame 14 (3.50 s): steady stream with subtle lateral wavering; restrained splash glints.
  • Frame 15 (3.75 s): glass is visibly fuller; mixture is a little lighter near the top.

The intended motion is continuous and causal: outlet onset -> falling water -> impact/ripples -> rising and diluted grapefruit juice -> shutoff and settling. There is no camera movement, cut, text overlay, or unrelated object motion.

METHOD.md

Method

The sequence is generated deterministically from first_frame.png by generate.py. I inspected the source only as local RGB arrays and numeric computer-vision measurements; I did not use an image viewing tool.

Construction

  • The source photograph is the immutable locked-camera plate. Frame 00 is copied directly, so both its decoded RGB pixels and its PNG file bytes exactly equal first_frame.png.
  • Measured nozzle and glass coordinates define a narrow active region. The stream is a supersampled antialiased path with translucent edge/core layers, a one-pixel refractive sample offset, a moving pin highlight, and staged onset/taper droplets.
  • The glass interior is a measured tapered mask. Water raises the visible surface from y=80.0 to y=75.2, adds a transparent amber band, and slightly lightens the original grapefruit-juice pixels with depth-dependent stratification while retaining source texture.
  • Meniscus, ripple arcs, an impact glint, and three tiny deterministic bubble paths communicate contact and mixing. The stream stops before the last frame, allowing residual ripples to settle.
  • No camera motion, crop, global grading, external assets, external models, masks, or engines are used.

Timing

Twenty RGB PNGs are written at 256 x 144 for playback at 4 fps (5 seconds): onset in frames 01–03, continuous impact and filling in frames 04–16, taper in frame 17, a final droplet in frame 18, and settling in frame 19.

Validation

The script decodes every output PNG, verifies RGB mode and 256 x 144 dimensions, packs it to uint32 0xRRGGBB, and compares it exactly with the tensor saved as pixels.npz under key pixels. It also verifies frame 00 against the source array. inspection.png is a labeled 20-frame contact sheet; transition_check.png pairs selected frames with amplified consecutive-frame difference maps.
