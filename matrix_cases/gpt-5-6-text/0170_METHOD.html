+def composite_rgb(dst, src, alpha):
+    """Alpha-composite float/uint8 RGB arrays and return uint8."""
+    a = np.clip(alpha[..., None].astype(np.float32), 0.0, 1.0)
+    out = dst.astype(np.float32) * (1.0 - a) + src.astype(np.float32) * a
+    return np.clip(np.rint(out), 0, 255).astype(np.uint8)
+

+def smooth_mask(mask, sigma=1.0):
+    arr = cv2.GaussianBlur(mask.astype(np.float32), (0, 0), sigma)
+    return np.clip(arr, 0.0, 1.0)
+
+
+def clean_plate(source):
+    """Replace only the pixels hidden by cord/basket using adjacent source RGB."""
+    plate = source.copy()
+
+    # The large occluded region is filled from a clean, same-row patch to its
+    # right.  Preserving rows retains the wall gradient, horizon, and wood tone.
+    target_l, target_r = 92, 177
+    sample_l, sample_r = 171, 256
+    donor = source[:, sample_l:sample_r].copy()
+
+    # The first donor columns touch the basket at a few rows. Blend toward a
+    # second clean donor from the left without destroying tabletop texture.
+    donor_left = source[:, 7:92].copy()
+    mix = np.linspace(0.36, 0.02, target_r - target_l, dtype=np.float32)[None, :, None]

Source observations

The source was inspected only by local Python numeric RGB analysis (array statistics, sampled RGB rows, color clustering, and edge/local-variance coordinates). No image viewer or image-reading tool was used.

  • Source dimensions: 256×144 RGB, matching the required output dimensions.
  • Camera: fixed, wide/landscape, with no evidence that a camera move is needed.
  • Background: a cool, low-contrast gray wall occupies the upper portion. Its mean tone varies gently from about RGB (145,145,155) at the left/top to roughly (160,157,164) around the center/right.
  • Table: the strongest full-width horizontal transition occurs at y=90–92. Below it is a textured warm brown tabletop with individual pixels and local bands in the approximate RGB (80–140, 50–105, 25–80) range.
  • Cord: a thin, high-contrast cord is centered around x=134–137 from y=0 to the basket attachment near y=60. Its measured high-local-variance run is generally x=130–140. It is very dark in shadow with small warm/orange-brown highlights.
  • Attachment/magnet: a compact dark attachment is present immediately above the basket top, around x=127–145 and y=45–66.

Alternating brown strands and dark gaps produce strong small-scale RGB variation. The body reaches the bottom crop, so a short continuation and bottom rim must be synthesized before the object can be lifted into view.

Planned construction

  1. Preserve frame 00 byte-for-byte at the RGB-array level.
  2. Derive a clean plate behind the basket and cord using adjacent source texture, row-wise color matching, smooth wall interpolation, and feathered boundaries.
  3. Paint the occluded orange tennis ball and its soft contact shadow onto that clean plate with analytic shading and a curved tennis-ball seam.
  4. Extract the cord/magnet/basket pixels from frame 00 with geometry matched to the measured extents. Extend the cropped woven body a short distance and build a dark elliptical lower rim from sampled basket colors and procedural weave.
  5. Composite the moving object at the offsets above. Resample the source cord so it always joins the fixed top anchor to the rising attachment.
  6. Add only subtle subpixel easing/edge feathering; the background, table, and ball remain fixed for a genuinely locked-off shot.

METHOD.md

Method

This continuation is a deterministic local pixel construction in Python using NumPy, Pillow, and OpenCV. No external model, external engine, network source, reference image, or visual image-reading tool was used.

The source frame was measured numerically through RGB samples, clustered colors, edge energy, and local-variance runs. Frame 00 is copied directly from first_frame.png and verified for exact array equality.

Frame 01 repeats the exact source for a brief covered hold. For frames 02–19, the generator constructs a clean plate only in the area hidden by the original cord and basket. Same-row RGB texture from clean portions of the source is color-matched and feathered into that region, retaining the original wall gradient, table horizon, and tabletop grain. A fixed orange tennis ball is drawn on this plate using analytic sphere normals, diffuse lighting, deterministic fine texture, two curved seam strokes, and a soft contact shadow.

The photographed basket/magnet pixels are extracted with a measured polygon. The basket continues below the initial crop, so its unseen last 17 rows are completed from sampled woven pixels plus a small shaded elliptical lower rim. This completed source-pixel layer is translated vertically with an eased sequence of integer offsets. The original cord is extracted by its RGB difference from the clean wall and vertically resampled so that it shortens between the fixed top anchor and the rising attachment. Layer order is clean plate and ball, cord, then basket, which makes the ball emerge naturally through occlusion.

The camera, background, table, and ball stay fixed for all 20 frames. The basket holds covered briefly, lifts upward, eases at the top, and leaves the ball revealed.

artifact_io.save writes the packed uint32 0xRRGGBB tensor, PNG frames, inspection contact sheet, and standalone HTML player. The generator also writes a key-frame/delta transition sheet and reloads every PNG and the tensor to verify pixel-for-pixel equality, shape, type, and the exact frame-00 invariant.
