+#!/usr/bin/env python3
+"""Generate a five-second, fixed-camera continuation from first_frame.png.
+
+The renderer is deliberately local and deterministic.  It preserves the source
+photograph, models a rising red liquid surface inside the measured receiving
+glass, and adds only small flow/ripple/bubble changes.  No external renderer or
+model is used.
+"""
+
+from pathlib import Path
+import math

+import numpy as np
+from PIL import Image, ImageDraw
+
+from artifact_io import save
+
+
+ROOT = Path(__file__).resolve().parent
+H, W = 144, 256
+
+
+def smoothstep(v: float) -> float:
+    v = max(0.0, min(1.0, v))
+    return v * v * (3.0 - 2.0 * v)
+
+
+def glass_edges(y: int) -> tuple[float, float]:
+    """Measured interior sides of the receiving glass at image row y."""
+    # The vessel narrows slightly toward its curved base.
+    q = max(0.0, y - 92.0)
+    return 100.2 + 0.054 * q, 143.0 - 0.096 * q
+
+
+def liquid_surface(t: int, x: int) -> float:
+    """Subpixel rising surface, with a small impact dimple and damped waves."""
+    progress = t / 19.0
+    # Near-linear volume increase with gently eased start/end.
+    rise = 18.0 * (0.84 * progress + 0.16 * smoothstep(progress))
+    mean_y = 111.0 - rise
+    phase = 0.83 * t
+    wave_amp = 0.70 * (1.0 - 0.18 * progress)
+    wave = wave_amp * math.sin((x - 101) * 0.30 + phase)
+    # The falling stream depresses the surface at x ~= 123.
+    impact = 0.82 * math.exp(-((x - 123.0) / 4.4) ** 2)
+    impact *= 0.72 + 0.28 * math.sin(phase + 0.9)
+    return mean_y + wave + impact
+
+
+def tint_as_red_drink(rgb: np.ndarray, depth: float, x: int, y: int, t: int) -> np.ndarray:
+    """Apply plausible red-liquid transmission while retaining source texture."""
+    src = rgb.astype(np.float32)
+    # Transmission is red-biased but still allows the woven support to show
+    # through the clear glass.  The transform was fitted to rows 111..124.
+    transformed = np.array(
+        [src[0] * 1.025 + 5.0, src[1] * 0.61 + 1.0, src[2] * 0.43 + 0.5],
+        dtype=np.float32,
+    )
+    # Optical tint reaches full strength just below the meniscus.
+    alpha = min(0.92, 0.46 + 0.23 * max(0.0, depth))
+    # Preserve unusually bright photographic glints in the glass.
+    if src.mean() > 125.0 and (src.max() - src.min()) < 45.0:
+        alpha *= 0.74
+    out = src * (1.0 - alpha) + transformed * alpha
+    # Low-amplitude moving caustic; this prevents a perfectly static fill.
+    shimmer = 1.6 * math.sin(0.42 * x + 0.57 * y + 0.74 * t)
+    out += np.array([shimmer, shimmer * 0.24, 0.0], dtype=np.float32)
+    return np.clip(out, 0, 255)
+
+
+def render_frame(base: np.ndarray, t: int) -> np.ndarray:
+    if t == 0:
+        return base.copy()
+
+    out = base.astype(np.float32).copy()

+    # Fill only the previously empty part of the glass.  The original liquid
+    # body (y >= 111) stays photographic instead of being repainted.

OBSERVATION.md

Observation and event plan

Numeric inspection of the supplied first frame

  • Source: first_frame.png, RGB, 256×144. All measurements below came from local array statistics, sampled RGB values, connected color masks, and luminance-gradient coordinates; no image viewer or image-reading UI was used.
  • The camera is locked. The upper half is a cool, pale gray background; the lower half is a warm woven/brown support surface. Nothing needs camera motion.
  • The glass beverage dispenser is centered toward the right. Its red reservoir is approximately x=133..194, y=35..68. Dark glass/spigot structure is concentrated around x=117..146, y=34..61.
  • The narrow pour path is near x=120..126, beginning below the outlet around y=61 and continuing toward the receiving vessel.
  • The receiving glass is approximately x=99..145, y=91..139, narrowing toward its bottom. Its rim/top transition is around y=91..98.
  • In the receiving glass, mean red-minus-green rises sharply below y=110: about 84 at row 110, 92 at row 111, and 93 at row 114. This marks the initial, unmistakably saturated liquid body at roughly y=111; its visible bottom curves away around y=134..139.
  • The existing scene is photographic and finely textured (17,479 exact colors), so additions should reuse sampled source texture, preserve the glass boundary, and avoid flat vector fills.
  • Important fixed geometry: the left glass boundary is near x=100..109 depending on height; the right boundary is near x=139..146; the red stream is already present in frame 00.

Twenty-frame event plan (4 fps, five seconds)

Frame 00 is copied exactly from the source. Motion remains confined to the red liquid and tiny optical effects inside the receiving glass.

METHOD.md

Method

Generation approach

I used a deterministic, local NumPy/Pillow pixel renderer in generate.py. No network service, external AI model, external rendering engine, mask, reference image, other case, or subagent was used.

The supplied image was inspected only through local code and numeric RGB data. Measurements came from pixel dimensions, exact-color counts, HSV-like masks, connected-component bounds, sampled RGB scanlines, luminance-gradient peaks, and coarse text-printed color/edge maps. I did not use an image Read/View tool and do not claim a visual review.

Frame 00 is a direct array copy of first_frame.png. For frames 01–19, the source photograph remains the base, so the locked camera, woven support, dispenser, background, glass edges, and fine photographic texture are preserved exactly outside the small liquid region.

The animated continuation consists of:

  • a measured glass-interior trapezoid (x≈100..143, y≈91..139), narrowing toward its base;
  • a subpixel meniscus rising from about row 111 to row 93 over the sequence;
  • a low-amplitude sinusoidal wave plus a localized depression under the measured stream center (x≈123);
  • red-biased optical transmission applied only to newly filled pixels, retaining the existing woven/glass texture beneath it;
  • a broken, partially reflective meniscus edge, faint moving caustic variation, and two tiny coherent bubbles;
  • highlight pulses restricted to already-red pixels in the existing pour stream (x=119..126, approximately y=59..110).

The established red body below row 111 is not repainted. The reservoir itself is held stable because its volume is much larger than the receiving glass and a multi-pixel drop over five seconds would be disproportionate at this scale.

Output construction

artifact_io.save packs each RGB pixel as uint32 0xRRGGBB, transposes the result to (144, 256, 20), writes pixels.npz, writes all 20 PNG frames, creates inspection.png, and embeds the same frame data in the standalone index.html player.

transition_check.png is generated separately as four selected adjacent-frame pairs (00→01, 05→06, 10→11, 18→19) with an amplified absolute RGB delta panel beside each pair. It is a diagnostic artifact, not an input to generation.

Verification

The generator verifies all of the following after saving:

  • source and generated frame arrays are RGB uint8 at 256×144;
  • frame 00 is pixel-identical to first_frame.png;
  • every saved PNG is pixel-identical to its in-memory frame;
  • every PNG, repacked as 0xRRGGBB, is identical to its pixels.npz tensor slice;
  • each adjacent pair contains motion but changes fewer than 2,500 pixels, guarding against scene-wide flicker.

The completed run changed 301–755 pixels per adjacent transition. A separate numeric locality check found all changes inside x=98..144, y=58..135, covering only the stream and receiving glass. The detected liquid top progresses from row 110 at frame 01 to row 93 at frame 19, stays below the rim, and never spills.
