+def smoothstep(x):
+    x = np.clip(x, 0.0, 1.0)
+    return x * x * (3.0 - 2.0 * x)

+def bilinear(image, x, y):
+    """Bilinearly sample an HxWxC image at floating point coordinates."""
+    x = np.clip(x, 0.0, image.shape[1] - 1.001)
+    y = np.clip(y, 0.0, image.shape[0] - 1.001)
+    x0 = np.floor(x).astype(np.int32)
+    y0 = np.floor(y).astype(np.int32)
+    x1 = np.minimum(x0 + 1, image.shape[1] - 1)
+    y1 = np.minimum(y0 + 1, image.shape[0] - 1)
+    fx = (x - x0)[..., None]
+    fy = (y - y0)[..., None]
+    a = image[y0, x0].astype(np.float32)
+    b = image[y0, x1].astype(np.float32)
+    c = image[y1, x0].astype(np.float32)
+    d = image[y1, x1].astype(np.float32)
+    return a * (1 - fx) * (1 - fy) + b * fx * (1 - fy) + c * (1 - fx) * fy + d * fx * fy
+
+
+def balloon_layer(source, growth, frame_index):
+    """Return rendered RGB, body alpha, and shallow exterior shadow alpha."""
+    yy, xx = np.mgrid[0:H, 0:W].astype(np.float32)
+

+    rx = 22.0 + 19.0 * growth
+    ry = 22.0 + 19.0 * growth
+    cx = 173.5 + 0.28 * np.sin(frame_index * 0.54) * growth
+    cy = 73.5 - 19.0 * growth

+    # never changing the camera or attachment point.

OBSERVATION.md

Numeric observation and event plan

Source measurements

  • Inspection method: local Pillow/NumPy RGB reads only. No image viewer, image-read tool, external reference, mask, model, or engine was used.
  • Source format: 256 x 144 RGB, uint8. Channel extrema are R 0-144, G 1-153, B 0-145; channel means are approximately (107.53, 114.19, 106.93).
  • Camera: fixed landscape frame. The broad background is a softly lit gray-green surface. Its brightness increases toward the upper/middle-left and falls toward the right edge, so all generated shading must retain that spatial light direction.
  • Balloon: the compact near-black body occupies approximately x=152..195, y=51..94. Its widest measured span is about 43 px near y=72..78. The crown is near (174, 51), the body center is near (174, 73), and the tapered lower end joins the neck at about (160, 93). Interior RGB is mostly 8..25 with subdued gray highlights; the left contour is slightly lighter and the right/lower body is very dark. Small nonuniform highlights around y=68..75 are part of the original rubber texture.
  • Hose: a narrow dark, slightly left-leaning run continues from approximately (160, 92) down through (152, 126), generally 3-6 px wide. It is partly occluded where it passes behind the table/setup near the bottom.
  • Table/setup boundary: the lower region begins around y=120 on the left/middle and rises/falls irregularly with perspective. Brown wood tones dominate the lower-right (about RGB 70-95 / 50-75 / 28-45). A saturated green existing setup region lies around x=112..153 below y=120. These source details remain untouched wherever not occluded by the growing balloon or its immediate neck.
  • The scene has low contrast and low spatial resolution. New balloon pixels therefore need soft antialiased boundaries, subdued highlights, fine deterministic grain, and no text, labels, hands, pump body, camera movement, cuts, or newly introduced objects.

Growth follows a smooth eased pressure curve, with tiny low-amplitude elastic breathing superimposed after inflation begins. The hose only flexes locally by a fraction of a pixel near the neck; the background and table stay locked.

METHOD.md

Method

The sequence is generated entirely with deterministic local Pillow and NumPy operations. No image viewer, image-read tool, network source, reference case, mask, external model, external engine, or subagent was used.

first_frame.png is loaded as an RGB uint8 array. Frame 00 is a direct array copy and bypasses every rendering operation. For frames 01-19, an analytic balloon silhouette expands from the measured source body (about 44 x 44 pixels) to about 82 x 82 pixels. The lower attachment height stays fixed while the balloon center moves upward, which produces inflation without sliding the hose connection.

The original balloon's pixels are bilinearly sampled in normalized material coordinates and stretched across the growing surface. This retains the source rubber texture. A weak analytic normal light, a soft upper-left highlight, and deterministic sub-pixel grain fill any imperfect elliptical corner samples. The outline uses an approximately one-pixel smooth alpha fringe. A small antialiased rubber neck connects the growing lower-left body to the original hose endpoint, which remains behind the table. The far-field source pixels, table, and camera remain fixed.

Growth follows an ease-out pressure curve with a very small tapered elastic oscillation. It is continuous across all 20 frames and ends at the planned maximum size. No new apparatus, hands, text, cuts, zoom, or camera motion are introduced.

artifact_io.save writes the uint32 0xRRGGBB tensor, individual PNG frames, inspection contact sheet, and standalone HTML player. generate.py additionally writes an adjacent-frame delta sheet and verifies all 20 decoded PNGs, the exact first frame, tensor shape/dtype, and every packed tensor value against the in-memory RGB frames.
