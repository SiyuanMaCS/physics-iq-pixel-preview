duck-static · 生成方法

The sequence is an exact temporal hold of the provided RGB source frame.

The prompt describes a locked-off real-time shot and explicitly requires the yellow rubber duck to remain stationary. It specifies no action, external force, lighting change, or camera motion. generate.py therefore loads first_frame.png, validates its RGB mode and 256 x 144 dimensions, and duplicates its uint8 pixel array into 20 frames without resampling or altering any pixel. This preserves the recorded wood texture, background, shadows, color variation, and duck silhouette exactly while obeying the requested physics.

artifact_io.save packs the RGB frames into the required uint32 0xRRGGBB tensor, writes the 20 PNG files, creates the inspection contact sheet, and embeds the packed sequence in the standalone HTML player. transition_check.png shows three representative source frames above their direct per-channel absolute differences; each tested transition has zero changed pixels.

No image viewer, image-reading interface, reference material, mask, external model, engine, or network resource was used. Scene inspection was performed only by local numeric RGB analysis with Pillow/NumPy, and generation uses only exact array duplication plus the provided output helper.
