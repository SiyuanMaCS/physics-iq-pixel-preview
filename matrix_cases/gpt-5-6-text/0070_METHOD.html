juice-in-water · 生成方法

What was generated

The result is a deterministic 20-frame, 256 x 144 RGB sequence at 4 fps. Frame 00 is pixel-identical to first_frame.png. The camera, background, table, dispenser, outlet hardware, glass outline, and original surface texture remain locked; generated changes are confined to the outlet-to-glass region.

Actual pixel method

generate.py uses only local Python pixel operations with NumPy and Pillow.

  1. It reads first_frame.png as the immutable base for every frame.
  2. It defines the receiving-glass interior from the numerically measured inset polygon. A softly antialiased mask prevents tint from crossing the glass walls.
  3. It derives a local luminance-gradient map and neutral-highlight map from the source. These reduce liquid-overlay opacity at existing edges and highlights, preserving the visible glass/refraction detail rather than painting an opaque shape over it.
  4. Grapefruit juice is represented by an analytic coral liquid field. A narrow, time-dependent plume sinks from the impact point, curls laterally with sinusoidal turbulence, and is gradually replaced by a more uniform concentration field. Depth changes the juice color slightly.
  5. The pour itself is an antialiased parametric stream from the measured outlet near (160, 80). It advances as a bead, becomes continuous, narrows, separates into a final drop, and stops.
  6. Surface oscillations are damped sine curves clipped to the glass. A few small ring masks represent entrained bubbles; a brief two-line crown accompanies the last drop.
  7. All overlays use alpha compositing against the unchanged source. No external assets, masks, models, engines, network calls, or image-view tools were used.

Timing
