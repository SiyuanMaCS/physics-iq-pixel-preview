+def reconstructed_table(source: np.ndarray) -> np.ndarray:
+    """Remove the source ball and its small contact shadow from the fixed plate."""
+    yy, xx = np.mgrid[0:H, 0:W].astype(np.float32)
+    ball = ((xx - BALL_X0) / 12.4) ** 2 + ((yy - BALL_Y0) / 11.8) ** 2 <= 1.0
+    shadow = ((xx - (BALL_X0 + 0.8)) / 13.0) ** 2 + ((yy - (BALL_Y0 + 8.0)) / 5.0) ** 2 <= 1.0
+    mask = ((ball | shadow).astype(np.uint8) * 255)
+
+    # Telea propagation works well here because the table is locally smooth.
+    filled = cv2.inpaint(source, mask, 4.0, cv2.INPAINT_TELEA)
+
+    # Re-introduce weak photographic grain borrowed from adjacent clean table
+    # rows so that the small repaired patch does not look synthetically flat.
+    repair = mask > 0
+    borrowed = np.roll(source, 15, axis=0).astype(np.int16)
+    borrowed_blur = cv2.GaussianBlur(borrowed.astype(np.float32), (0, 0), 2.2)
+    residual = borrowed - borrowed_blur.astype(np.int16)
+    textured = np.clip(filled.astype(np.int16) + np.round(residual * 0.28).astype(np.int16), 0, 255)
+    out = source.copy()
+    out[repair] = textured[repair].astype(np.uint8)

OBSERVATION.md

PixelWorld-Text observation and event plan

Source measurements

  • Source: first_frame.png, inspected only through local Python RGB/HSV arrays, block statistics, thresholds, and connected-component measurements. No image viewer or image-reading tool was used.
  • Canvas: 256 x 144 RGB pixels. The camera is locked off.
  • The light, low-saturation wooden tabletop occupies most of the frame from roughly y=20 downward. Its sampled tones generally rise from RGB values around (90, 85, 78) near the back to around (145, 138, 132) near the front, with natural grain and perspective shading.
  • The black pipe/mouth is at the left boundary, approximately x=0..20 and y=40..67. Its darkest core is around x=0..18, y=42..64.
  • The orange-brown tennis ball is the connected warm-colored component at x=63..82, y=43..59, centered near (72.5, 51.5), with an apparent radius of about 9.5 pixels. It is already clear of the pipe in frame 00.

  • Dark regions at the upper-right and lower-right edges are part of the fixed scene/background and are not moving objects.
  • Intended motion: the orange tennis ball rolls horizontally to the right at y about 52, across the tabletop and out through the right edge. The red ball and every other scene element stay fixed.

METHOD.md

Method

I inspected first_frame.png only with local Python numeric RGB/HSV arrays, block statistics, and connected-component measurements. I did not use an image viewing/reading tool, an external model, an external engine, the network, or any reference from another case.

The animation uses the supplied first frame as a locked photographic plate. Frame 00 is the source RGB array exactly. For later frames, I made one static clean plate by masking the measured orange ball and its small contact shadow and reconstructing that approximately 25 x 25 pixel tabletop region with OpenCV's local Telea inpainting. Weak high-frequency residual sampled from a neighboring clean tabletop row is added inside only that repair mask to retain photographic grain.

The moving ball is a soft-edged elliptical matte over the actual source pixels. For each frame, its source appearance is rotated clockwise by distance / radius (the rolling, no-slip relationship) and translated 9.7 pixels right. Cubic interpolation supplies subpixel motion and the frame boundary clips the ball naturally. A subtle analytic Gaussian contact shadow travels just beneath it. The remainder of every frame is unchanged, so the camera, red ball, pipe, and surrounding setup stay locked.

artifact_io.save writes the 20 RGB PNGs, the packed uint32 0xRRGGBB tensor, the inspection contact sheet, and the standalone HTML player. generate.py additionally writes transition_check.png, then reloads every output PNG and pixels.npz to assert exact agreement with the generated RGB tensor and exact equality of frame 00 with first_frame.png.
