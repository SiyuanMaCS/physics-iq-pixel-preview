+def smoothstep(edge0, edge1, value):
+    x = np.clip((value - edge0) / (edge1 - edge0), 0.0, 1.0)
+    return x * x * (3.0 - 2.0 * x)

+def estimate_flame_layers(source):
+    """Return a local wall plate and the additive photographed flame layer.
+
+    The flame lies in otherwise smooth wall. For each row, wall color samples
+    immediately to either side are robustly averaged and interpolated across
+    the flame. This keeps the existing illumination gradient and image grain.
+    """
+    src = source.astype(np.float32)
+    yy, xx = np.mgrid[0:H, 0:W]
+
+    # Local background plate: interpolate between narrow wall strips located
+    # outside the bright flame.  The vertical smoothing suppresses individual
+    # wall pixels but retains the scene's broad warm illumination gradient.
+    left = np.median(src[:, 113:119, :], axis=1)
+    right = np.median(src[:, 144:150, :], axis=1)
+    left = gaussian_filter(left, sigma=(1.0, 0.0), mode="nearest")
+    right = gaussian_filter(right, sigma=(1.0, 0.0), mode="nearest")
+    f = np.clip((np.arange(W, dtype=np.float32) - 118.0) / 26.0, 0.0, 1.0)
+    wall = left[:, None, :] * (1.0 - f[None, :, None]) + right[:, None, :] * f[None, :, None]
+
+    # Extract only the photographed luminous structure.  A feathered geometric
+    # window prevents distant wall grain from being interpreted as flame.
+    difference = src - wall
+    energy = np.sqrt(np.sum(difference * difference, axis=2))
+    support = smoothstep(3.0, 18.0, energy)
+    support *= smoothstep(116.0, 123.0, xx) * (1.0 - smoothstep(139.0, 146.0, xx))
+    support *= smoothstep(8.0, 14.0, yy) * (1.0 - smoothstep(30.0, 34.0, yy))
+    support = gaussian_filter(support, 0.55)
+    layer = difference * support[:, :, None]
+
+    # Plate replacement mask covers the original luminous core but fades to
+    # zero before reaching either candle body or the untouched surroundings.
+    replace = smoothstep(116.0, 123.0, xx) * (1.0 - smoothstep(139.0, 146.0, xx))
+    replace *= smoothstep(7.0, 13.0, yy) * (1.0 - smoothstep(29.0, 34.0, yy))

+    return wall, layer, np.clip(replace, 0.0, 1.0)

OBSERVATION.md

Numeric source-frame observation

The source was inspected only through local RGB-array statistics and coordinate queries. No image viewing tool was used.

Frame and scene measurements

  • first_frame.png is RGB, 256 x 144 pixels.
  • The camera is fixed. A softly varying neutral gray background occupies the upper part of the frame; the brown wooden tabletop begins at roughly y=99 and fills the bottom of the frame.
  • The lit left candle is centered near x=131. Its saturated red wax body runs approximately x=125..137, y=31..107. The body tapers slightly toward its bottom in perspective.
  • The left flame's high-luminance core is approximately x=124..136, y=15..30. Its warm transition pixels reach about y=39. A broader, already photographed warm halo extends approximately x=112..146, y=7..44.
  • The unlit right candle is centered near x=191. Its saturated red wax body runs approximately x=184..198, y=30..100. A small dark wick/top detail is present near x=192..196, y=29..32; it stays unlit.
  • Both holders are dark and partly merge with the tabletop shadows. The left holder is concentrated around x=122..139, y=104..128; the right around x=181..198, y=98..124. Neither holder nor either candle moves.
  • The scene has strong photographic texture and compression-level color variation, so the animation should reuse source pixels and avoid repainting static regions.

Physical continuation

There is no imposed interaction or new actor. During the five seconds, the left candle continues to burn. Its flame performs low-amplitude buoyant flicker: the base remains pinned to the wick while the narrow upper flame bends by a few pixels, changes height, and breathes slightly in brightness. The right candle remains unlit. The room, table, wax, holders, and camera remain exactly stationary.

20-frame event plan (4 fps)

  • 00 (0.00 s): exact supplied source frame; upright flame.
  • 01 (0.25 s): upper flame leans 1 px right and shortens slightly.
  • 02 (0.50 s): flame narrows and leans 2 px right.
  • 03 (0.75 s): returns toward center with a taller tip.
  • 04 (1.00 s): upright, moderately tall flame.
  • 05 (1.25 s): upper half drifts 1 px left.
  • 06 (1.50 s): brief leftward bend, slightly shorter.
  • 07 (1.75 s): left bend relaxes; core brightens subtly.
  • 08 (2.00 s): upright and tall.
  • 09 (2.25 s): small rightward ripple in the tip.
  • 10 (2.50 s): compact, centered flame.
  • 11 (2.75 s): short rightward lean.
  • 12 (3.00 s): tip grows and returns to center.
  • 13 (3.25 s): upper flame drifts 1 px left.
  • 14 (3.50 s): leftward bend reaches its local maximum.
  • 15 (3.75 s): flame narrows while straightening.

METHOD.md

Method

Actual generation method

The sequence is a deterministic local pixel animation built only from first_frame.png with NumPy, Pillow, and SciPy. No image viewing tool, external image, model, mask, renderer, or engine was used.

  1. The source PNG is decoded as an RGB uint8 array. Frame 00 is copied directly from this array without alteration.
  2. Numeric color thresholds and coordinate statistics locate the photographed flame around x=124..136, y=14..30. The two red wax bodies and the holders are deliberately excluded from the animation region.
  3. A local wall plate is estimated row by row from robust RGB medians in two wall strips at x=113..118 and x=144..149. Linear interpolation spans the flame neighborhood, and a small vertical Gaussian smoothing removes isolated grain from the estimate while retaining the photographed light gradient.
  4. Subtracting this plate from the source produces an additive, source-derived flame layer. An energy-based soft matte and feathered coordinate window keep only the luminous photographed structure.
  5. For frames 01 through 19, inverse bilinear mapping gently changes flame height and width and bends the upper flame by at most a few pixels. The transform displacement falls to zero at y=31 so the base remains attached to the left wick. A tiny analytic warm halo pulse changes only a few RGB levels around the flame. Everything outside the flame neighborhood is copied exactly from the source.
  6. artifact_io.save packs the frames as uint32 0xRRGGBB values with tensor layout [144, 256, 20], writes the PNG sequence, creates the inspection contact sheet, and embeds the lossless frame deltas in the standalone HTML player.
  7. transition_check.png contains four selected generated frames followed by six-times-amplified absolute differences from each preceding frame. It is a diagnostic artifact, not an input to generation.

Verification performed

  • Shape and type: exactly 20 frames, each 256 x 144 RGB uint8.
  • Source lock: frames/00.png is pixel-identical to first_frame.png.
  • Packed tensor: every PNG was decoded and compared pixel-for-pixel against pixels.npz; all 20 match the uint32 0xRRGGBB tensor.
  • Static scene: the union of all consecutive-frame changes is confined to x=115..147, y=5..35. Thus the candles, holders, table, right wick, background outside the glow, and camera framing remain unchanged.
  • Temporal continuity: every adjacent pair changes, with 516 to 812 changed pixels. The bright flame centroid ranges only from x=129.64 to x=131.08, and its detected bright top ranges from y=13 to y=15.

The deliverable was reviewed through numeric RGB statistics, threshold maps, coordinate samples, tensor equality tests, and temporal-difference metrics. No claim of visual/tool-based image review is made.
