Physics model

  • Release at t = 0 (frame 00 is the held instant, byte-exact with input); both objects fall straight down under constant gravity g = 48 px/s² with 4 fps (dt = 0.25 s).
  • Ball free-fall to pillow surface (cy 32 → 86, 54 px) → t_fall ≈ 1.50 s → contact at frame 06 (t = 1.50 s).
  • Block free-fall to right-pillow edge y≈90 (cy 47.5 → 77.4, ~30 px) → t_fall ≈ 1.12 s → contact during the frame-05 exposure (t = 1.00–1.25 s).
  • Pillows are soft: one short damped compression/rebound cycle (~1.5 frames) then rest. No bounce-off; objects stay where dropped.
  • Ball spins while falling (seam rotates at 100°/s, ≈150° by contact), then damped to rest. Block wobbles ≤4° at contact, settles upright.
  • Motion blur during descent: each frame composites 5 sub-step stamps across the 0.25 s exposure. Soft contact shadow grows on the pillow as the object approaches, deepens during compression, stays as a resting shadow.
  • Grabber claws remain static (release is read from the objects dropping out of them); background behind the flight corridors is reconstructed by per-row median interpolation of wall pixels on both sides of each corridor (wall is smooth/defocused). Inpaint mask is restricted to wall rows (ball ≤ y91, block ≤ y89) and excludes blue-grabber pixels; objects landing on pillow rows composite directly over the untouched pillow.

METHOD.md

METHOD

All 20 frames are produced by generate.py using only local Python pixel operations (NumPy + Pillow). No external models, engines or reference frames are used; first_frame.png is the sole image input.

Pipeline

  1. Sprite extraction (frame 0 only).
    • Ball: crop x67–100, y17–47; analytic disk alpha around center (84, 32), radius 11.5→13.8 feathered over 2.3 px; pixels that are bluer than red (blue claw fringe) are forced transparent. Preserves the real brown shading and beige seam.
    • Block: crop x208–223, y33–61; alpha is the max of an analytic rounded rectangle (5.7×12.2 half-extent, 2 px corner) and a redness statistic r − (g+b)/2; the wall-blended fringe is recoloured toward the median core red (with the original left-dark/right-light gradient) so no pink halo appears over the pillow.
  2. Background inpainting. Each flight corridor is swept into a soft mask (unions of disks / rounded rects along the fall path; blue claw pixels are excluded). Per row, wall colour is interpolated between medians of clear wall strips on each side (ball: x46–66 → x104–120; block: x186–206 → x226–242), Gaussian-blurred (1.4 px), and alpha-blended using a blurred, boosted mask. Inpaint is restricted to wall rows (≤ y91 ball, ≤ y89 block), so the pillows and both grabbers stay exactly as in frame 0.
  3. Physics (g = 48 px/s², dt = 0.25 s). Keyframed center tables follow constant-acceleration fall: ball cy 32→86 by t=1.50 s (contact), block cy 47.5→81 by t≈1.12 s (contact), then one damped sink/rebound cycle (~4 px ball, ~3 px block) and rest by frame 09. The ball seam rotates 100°/s during flight (PIL affine rotation about its center, bilinear) and damps out; the block tilts ≤4° on impact and re-centers.
  4. Motion-blur compositing. For frames 01–08 each 0.25 s exposure is six evenly spaced sub-step stamps (alpha-over at 50% weight), interpolating position and rotation between keyframes, yielding a vertical blur trail whose length grows with velocity, like the input frame's own motion fringe. Resting frames use one opaque stamp.
  5. Contact shadow. A soft Gaussian ellipse under each object (centered on the pillow edge, 13×4.4 ball / 7.5×2.8 block) fades in with proximity, peaks at compression, and remains as a constant ambient shadow frames 09–19.
  6. Output. artifact_io.save writes the uint32 0xRRGGBB packed tensor pixels.npz (shape 144×256×20), the 20 PNGs, inspection.png, and the standalone index.html player. transition_check.png is a 5×4 labelled contact sheet of all frames.
