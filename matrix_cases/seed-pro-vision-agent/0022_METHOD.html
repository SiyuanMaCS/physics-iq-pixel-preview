+Method (see METHOD.md / OBSERVATION.md):
+  1. inpaint the ball + its shadow out of first_frame.png -> clean table background
+  2. extract ball RGBA sprite and shadow multiply-ratio layer from frame 0
+  3. translate both layers (bilinear, subpixel) along the measured travel line
+Frame 0 is the decoded first_frame.png verbatim.
+"""
+from pathlib import Path
+import numpy as np
+import cv2
+from PIL import Image, ImageDraw
+from scipy.ndimage import map_coordinates
+import artifact_io
+
+ROOT = Path(__file__).parent
+first = np.array(Image.open(ROOT / 'first_frame.png').convert('RGB'))
+H, W, _ = first.shape
+assert (H, W) == (144, 256)
+
+BCX, BCY, BR = 161.5, 80.0, 7.5          # ball centre / radius in frame 0
+SHX, SHY, SRX, SRY = 149.0, 83.2, 26.0, 7.5   # shadow ellipse
+VX = 3.6                                  # px / frame, constant rolling speed
+SLOPE = -0.0301                           # dy/dx along pipe->ball line
+
+yy, xx = np.mgrid[0:H, 0:W].astype(np.float32)
+
+# ---------- 1. clean background (inpaint ball + shadow) ----------
+db = np.hypot(xx - BCX, yy - BCY)
+de = np.hypot((xx - SHX) / SRX, (yy - SHY) / SRY)
+mask = ((db <= BR + 1.1) | (de <= 1.06)).astype(np.uint8) * 255
+mask = cv2.dilate(mask, np.ones((3, 3), np.uint8), iterations=1)
+bg = cv2.inpaint(first, mask, 3, cv2.INPAINT_TELEA)
+
+# ---------- 2. extract layers ----------
+# ball alpha: solid core, 1.3 px feathered rim
+a_ball = np.clip((BR + 0.8 - db) / 1.3, 0, 1)
+# shadow coverage: feathered ellipse (ratio itself is ~1 where nothing was dark)
+a_sh = np.clip((1.05 - de) / 0.18, 0, 1)
+a_sh *= (1 - a_ball)                        # ball owns the overlap
+
+src = first.astype(np.float32)
+bgr = bg.astype(np.float32) + 1e-6
+ratio = src / bgr                           # per-channel darkening under the shadow
+
+# ---------- 3. trajectory + compositing ----------
+def warp(layer, dx, dy):
+    coords = np.array([yy - dy, xx - dx], dtype=np.float32)
+    return map_coordinates(layer, coords, order=1, mode='nearest')
+
+frames = np.empty((20, H, W, 3), np.uint8)
+frames[0] = first
+track = []

+    dx, dy = cx - BCX, cy - BCY

Observation — case_0022

Scene measurements (from first_frame.png, 256×144)

  • Locked-off living-room shot. Yellow velvet sofa across the background; dark wood dresser + lamp on the right. Foreground: light wood-plank coffee table with near-horizontal grain and faint horizontal plank tone bands.
  • Black launch pipe at the left edge: mouth rim ≈ x 28, centre ≈ y 84, vertical span ≈ y 68–98 (radius ~15 px). Static throughout.
  • Grey tennis ball already on the table right of the pipe:
    • centre (161.5, 80.0), radius ~7.5 px (diameter ~15 px).
    • cool grey-blue body; bright blue-white specular patch upper-right (e.g. RGB (115,140,166)); dark contact wedge at the bottom (RGB ≈ (80,80,89)). No visible seam/fuzz markings — surface reads uniform.
  • Soft contact shadow cast left of the ball (light from right): approximate ellipse centre (147, 83.5), axes (22, 7), warm darkening 5–25 %, strongest near the ball.
  • Tabletop along the ball's depth band extends essentially to the frame: at y≈78 the top ends near x≈242 (dark dresser behind), at y≈85 to x≈253. Far tabletop corner ≈ (197, 60).
  • World travel line (pipe mouth → ball, extended toward far corner): slope dy/dx ≈ (80−84)/(161.5−28) = −0.0301.

Physics / motion plan

  • Rolling ball, already in motion at frame 0; rolling resistance on polished wood over ~19 px of travel is negligible → constant velocity, v = 3.6 px/frame image-right along y(x) = 84 − 0.0301·(x−28).
    • frame 0: x 161.5, y 80.0 (identical to first frame)
    • frame 5: x 179.5, y 79.5
    • frame 10: x 197.6, y 78.9
    • frame 15: x 215.6, y 78.4
    • frame 19: x 230.0, y 77.9 (right edge 237.5, still on tabletop; ball never leaves frame/table)
  • No vertical bob (flat table). Ball radius constant (perspective depth change < 5 %). Surface has no visible markings, so spin is optically invisible; the fixed specular highlight is kept screen-relative (correct for a fixed light).
  • Shadow translates rigidly with the ball; multiply-style darkening so it adapts to the slightly darker wood toward the right.

Rendering method

  1. Build clean table background: mask ball disk (r 8.6) + shadow ellipse (26×7.5 semi-axes), 3×3 dilated; fill with a 50/50 blend of OpenCV Telea inpaint and per-row linear interpolation across the hole (Telea keeps 2-D texture, row-fill keeps the horizontal plank bands). Everything outside the hole stays byte-identical to frame 0.
  2. Extract from frame 0 vs background: ball RGBA sprite (analytic disk alpha, 1 px feather) and shadow layer (per-pixel darkening ratio RGB, feathered ellipse alpha excluding the disk).
  3. For each frame: background → bilinear-warped shadow ratio overlay → bilinear-warped ball alpha composite at subpixel offsets. Frame 0 = exact decoded first_frame.png.
  4. Save via artifact_io.save; additionally build transition_check.png (5×4 contact sheet + per-frame changed-pixel counts and centroid track).

METHOD.md

METHOD — case_0022

What happens

A grey tennis ball already on the light wood coffee table rolls at constant speed from in front of the black launch pipe (left) toward the right edge of the table. Locked-off camera; nothing else in the scene moves. 20 frames, 256×144, 4 fps (5 s). Frame 00 is the decoded first_frame.png, byte-exact.

Measurements from frame 00

  • Ball centre (161.5, 80.0), radius 7.5 px (cool grey-blue disk, blue-white specular patch upper-right, dark contact crescent at bottom).
  • Contact shadow: ellipse centre (149.0, 83.2), semi-axes 26 × 7.5 px, cast left of the ball (key light from the right).
  • Pipe mouth centre ≈ (28, 84), giving the world travel line y = 84 − 0.0301·(x − 28).
  • Tabletop right boundary measured per row (e.g. x≈241 at y=78, x≈251 at y=82); the ball's contact point stays on the table for all 20 frames, its upper arc silhouetted against the dresser at the very end (correct foreground occlusion).

Physics

The ball is a rolling sphere on a flat polished table; over the short visible run rolling resistance is negligible, so motion is uniform: v = 3.6 px/frame (14.4 px/s) along the measured line. Final position (230.0, 77.9). No bounce, bob, scale change, or camera motion. The sphere has no visible surface markings in frame 00, so spin has no optical signature; the fixed specular highlight is kept screen-relative (correct under a fixed light). The contact shadow translates rigidly with the ball.

Pixel construction (generate.py)

  1. Background plate. The union of the ball disk (r 8.6) and shadow ellipse is masked (3×3 dilated) and filled two ways:
    • OpenCV Telea inpainting (2-D texture continuation),
    • per-row linear interpolation between the mask edges (preserves the horizontal wood-plank tone bands). Their 50/50 blend is used only inside the hole; every other pixel is the untouched frame-00 image.
  2. Layer extraction from frame 00.
    • Ball alpha: analytic disk with a 1.3 px anti-aliased rim; RGB copied from frame 00 (retaining the real highlight/shading).
    • Shadow: per-pixel per-channel ratio frame00 / background inside a feathered ellipse, with the disk excluded.
  3. Compositing per frame t. Both layers are shifted to the trajectory position with first-order (bilinear) subpixel warps (scipy.ndimage.map_coordinates): the shadow ratio is multiplied onto the background first, then the ball sprite is alpha-composited over it. Using a ratio (rather than a flat patch) lets the shadow darken correctly against the slightly darker wood toward the right.
  4. Frame 00 is forced to the verbatim decoded first_frame.png; frames 01–19 are generated. artifact_io.save writes pixels.npz (H×W×20 uint32 0xRRGGBB), frames/00..19.png, inspection.png and index.html. transition_check.png is a 20-frame contact sheet with changed-pixel counts and changed-region centroids vs frame 00.

Verification performed

  • frames/00.png equals first_frame.png exactly (asserted in code, checked).
  • All 20 PNGs, when packed as 0xRRGGBB, match pixels.npz slice-for-slice.
  • Changed-region centroid advances monotonically rightward (~3.6 px/frame); changed-area stays bounded (ball + shadow footprint, ~930→1650 px as the trail accumulates against the reconstructed plate); no background drift.
  • Visual inspection (image tool) of the full sheet plus native-resolution crops confirmed: clean restoration of the vacated tabletop (no ghost), stable ball shading/highlight, shadow glued to the ball, and correct placement at the right table edge in the final frames.

Honest limitations

  • The background beneath the ball/shadow in frame 00 is unobservable; the plate there is a Telea/row-interpolation estimate, so vacated pixels are a plausible reconstruction, not ground truth.
  • Ball and shadow are rigid 2-D translations; a rolling sphere's true contact shading would vary microscopically, but at 15 px diameter and an unmarked surface the difference is sub-pixel/invisible.
  • No motion blur is added beyond the 1 px feather already present in frame 00 (4 fps sampling of a slow-moving, already-soft source).
