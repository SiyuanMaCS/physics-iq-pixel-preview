ball-and-block-fall · 生成方法

How generate.py turns first_frame.png into the 20-frame sequence. Everything is local Python pixel math (NumPy / SciPy / Pillow); no external models, no network, no other cases. Frame 00 is written byte-identical to first_frame.png.

1. Scene geometry from frame 0

  • Pillow top profile. Per column x, the first pixel with r−b > 10 in y 80–130 marks the warm pillow crest; gaps are interpolated and the profile is median-filtered (size 5). Result: y = 91 at the ball column (x≈71), y = 87 at the block column (x≈205).
  • Wall model. A smooth matte wall with a vignette. Per RGB channel a cubic 2-D polynomial (10 terms in normalised x,y) is least-squares fitted to clean wall pixels (greyness/brightness gates; claw, rail, yellow tab, object ROIs excluded). This captures the large-scale gradient but leaves a ±5–8 level smooth residual, handled later.
  • Object measurements (half-coverage crossings of the colour blend in frame 0): ball centre (70.6, 29.5), mid-edge radius 10.3; block centre (204.8, 43.4), mid-edge half-size 3.45 × 10.3, corner radius ≈2.2. Both silhouettes have symmetric ~3 px soft edges (lens/defocus look — verified top-vs-bottom profiles match), so there is no motion blur baked into the initial frame; motion blur is instead synthesised at render time.

2. Sprite cutting with true coverage alpha

A sprite pixel in frame 0 is the blend s = a·o + (1−a)·w of object colour and the wall behind it. Cutting a sprite correctly requires both the coverage a and the exact wall colour w at that pixel:

  • Local wall reference. Inside a margin patch around each object, an affine colour plane (1, x, y per channel) is fitted to pixels that agree with the global wall model within 10/channel-sum, excluding the object gate and blue claw pixels. This local plane absorbs the global model's residual.
  • Colour alpha. For each channel with strong wall/object contrast (|w−o| > 40), a_c = (w_c − s_c)/(w_c − o_c); the per-channel values are median-combined (object colours: ball (20,8,3), block (135,25,5); for the block only g and b qualify — its red channel nearly matches the wall).
  • Geometric alpha. A measured radial/SDF profile (ball: sampled coverage vs radius; block: coverage vs rounded-rect signed distance), 1 in the interior and ramping to 0 across the soft edge.
  • Combination: a = blur(max(a_colour, a_geom)) inside a slightly larger geometric gate. The geometric term guarantees the interior (the ball's lighter seam pixels would otherwise read as partial coverage), while the colour term extends edges where the real silhouette departs from the ideal shape (the block's slightly tilted/splayed lower edge). A 0.4 px Gaussian smooths the result.
  • Claw protection (ball only). Blue jaw pixels (b−r > 18) and pixels above y 23 outside radius 10.2 are removed from the ball sprite so no claw colour travels down with the ball.

3. Static base (objects removed)

The base frame is frame 0 with the two initial sprites erased:

  • Holes come from the coverage silhouettes, dilated (gaussian(σ=1.2) > 0.08–0.12) so even faint outer-edge pixels (a < 0.1) are removed — otherwise they remain "known" and produce a ghost outline at the release position. The ball hole is a geometric disc above y 23 (jaw-pixel and jaw-tip protections) and the full gate below; the block hole is its full silhouette.
  • Fill. The global wall polynomial plus a residual field: at known wall pixels the residual is frame0 − wall; holes/claws/pillows are unknown and the field is solved by 900 Jacobi diffusion sweeps (4-neighbour average). Dark object pixels are therefore unknown and cannot bleed into the fill.
  • The fill is blended into frame 0 through a feathered mask (gaussian(hole, 0.8) ramped 0.3–0.8). The cleaned patch at each sprite's original location is also saved as the exact per-pixel de-bleed reference used in compositing.

4. Physics

One-dimensional vertical motion only (objects hang and fall with no measured horizontal offset or rotation):

  • g = 60 px/s², integrated with dt = 0.002 s.
  • Pillow contact when the centre reaches surface − mid-edge radius (ball 80.7, block 74.65); two inelastic bounces with restitution ball (0.35, 0.25), block (0.28, 0.15).
  • After the bounces the object eases 1.5 px (ball) / 1.0 px (block) into the cushion (exponential settle, rate 8/s), standing in for pillow compression.
  • Sampled at frame times and shutter sub-times by linear interpolation.

5. Compositing

For each frame f > 0 the canvas starts as the static base. A soft dark contact ellipse on the pillow ramps in as the object approaches, then each object is composited:

  • 8 sub-samples evenly span the 0.12 s shutter ending at the frame time; each sub-sample bilinearly samples the sprite RGB, its alpha and its original- location background patch at that instant's centre.
  • Per sub-sample the original over-wall blend is undone and re-blended over the actual canvas: s + (1−a)·(C − w). Averaging the 8 sub-sample results gives the exposure-integrated image — near impact (v ≈ 75 px/s) this is a ~9 px vertical trail, and at rest all sub-samples coincide so the sprite is exactly its sharp self, blending correctly over both wall and beige pillow.
  • Block is rendered first, ball second. Frame 00 is the verbatim input frame.

artifact_io.save writes the (144,256,20) uint32 0xRRGGBB tensor (pixels.npz), the 20 PNGs, the 8-frame inspection sheet and the delta-coded standalone index.html player.

6. Verification performed

  • frames/00.png is byte-identical (sha256) to first_frame.png.
  • Every PNG decodes to the same packed 0xRRGGBB values stored in pixels.npz; tensor shape/dtype (144,256,20) uint32.
  • Settled frames are pixel-stable (frames 11→19 differ by ≤6/channel-sum; 18→19 identical; block identical from frame 8).
  • Visual review (image tool) of the inspection sheet, release frames, impact frames, resting crops and a frame0-vs-rest sprite comparison: object colour, seam texture and soft edges match the source; claws/rail/pillows are static.

7. Known approximations

  • The wall revealed behind the released objects cannot be known; it is a smooth, gradient-consistent diffusion fill. A very faint even disc-shading remains under the blue claw where the ball top met the jaw (consistent with the measured wall gradient, a few intensity levels).
  • Pillow response is modelled only by the small sink offset and the painted contact shadow; there is no mesh deformation.
  • Motion is 1-D with no rotation, spin or horizontal drift (none was measurable from the input); gravity and restitution are tuned to look physically plausible at 4 fps rather than measured from real footage.
